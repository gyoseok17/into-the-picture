## 설계 결정

### 001. HTTPS origin은 Compose에서 APP_DOMAIN으로 파생 (2026-09-18)

- 결정: EC2 HTTPS Compose에서는 `https://${APP_DOMAIN}`을 `APP_CORS_ALLOWED_ORIGINS`로 백엔드에 전달한다.
- 이유: CORS와 카카오 콜백 검증에 쓰이는 허용 출처를 Caddy의 공개 도메인과 분리해 중복 입력하면 배포 때 불일치가 발생한다.
- 검토한 대안과 선택하지 않은 이유: `.env`에서 CORS 주소를 별도 입력하는 방식은 동작하지만 두 주소를 지속적으로 동기화해야 한다. HTTP까지 포괄하는 공용 origin 변수는 현재 HTTPS 전용 Compose의 범위를 넓히므로 보류한다.
- 영향 범위: Docker Compose HTTPS 배포, Spring CORS 바인딩, Kakao callback URI 검증, 배포 문서.
- 후속 조건 또는 작업: HTTP 배포를 지원하면 scheme을 별도 계약으로 분리한다.

## 구현 변경

### 001. Compose origin 파생과 Spring 명시 바인딩 (2026-09-18 / 백엔드·통합)

- 변경 내용: HTTPS Compose가 `APP_DOMAIN`에서 `APP_CORS_ALLOWED_ORIGINS=https://<APP_DOMAIN>`을 만들어 backend에 전달한다. Spring YAML은 이 환경변수를 `app.cors.allowed-origins`에 명시적으로 연결하고, 쉼표 구분값의 `List<String>` 바인딩 테스트를 추가했다.
- 변경 이유: 기존 자동 환경변수 바인딩은 설정 출처가 코드에서 드러나지 않아 배포 도메인이 localhost 기본값으로 남는 문제를 발견·진단하기 어려웠다.
- 영향 범위: Docker HTTPS 배포의 CORS 필터와 Kakao callback origin 검증. 프런트 번들, API 응답, DB 스키마는 변경하지 않는다.
- 호환성·되돌림 메모: Compose 외의 로컬 Gradle/Vite 실행은 localhost·Capacitor 기본 목록을 유지한다. HTTP 배포는 지원하지 않으며 별도 결정이 필요하다.
- 관련 계약·설계·QA 근거: `_workspace/contracts/M8.5-deployment-origin.md`, `_workspace/backend/M8.5-origin-report.md`, `_workspace/qa/M8.5-origin-qa.md`.

## 역할별 결과

### 001. 백엔드 설정 (2026-09-18)

- 변경 범위: `application.yml`, CORS 바인딩 단위 테스트.
- 설계 결정과 이유: 환경변수 참조를 YAML에 명시하고 쉼표 구분 origin을 목록으로 바인딩해 SecurityConfig와 Kakao callback 검증이 같은 계약을 소비하도록 했다.
- 검증: CORS 바인딩 테스트 및 `bootJar` 통과.
- 발견·해결한 위험: Compose의 배포 domain과 backend 기본 localhost origin이 분리되어 카카오 로그인 POST가 `Invalid CORS request`로 거절될 수 있던 경로를 제거했다.
- 남은 위험 또는 후속 작업: 잘못된 도메인·scheme 값은 계속 거절되며, HTTP 지원은 별도 설계가 필요하다.

### 002. QA·보안 검토 (2026-09-18)

- 변경 범위: origin 계약, Compose·Caddy·Spring Security·Kakao callback 경계 교차 검토.
- 설계 결정과 이유: 단일 HTTPS origin을 CORS와 callback 검증에 공통 사용하고, Secure cookie·8080 비공개 정책을 유지한다.
- 검증: `docker compose config --quiet`, Compose resolved origin, 시크릿 전달 경계 및 포트 공개 범위 대조.
- 발견·해결한 위험: 프런트로 시크릿이 전달되지 않으며 backend만 DB·JWT·외부 키를 받는 기존 경계를 보존했다.
- 남은 위험 또는 후속 작업: 실제 EC2에서 DNS/TLS, 카카오 Redirect URI, 로그인 뒤 Set-Cookie를 확인한다.
