## 구현·검증

- DB 마이그레이션과 동기화 보정 목록을 함께 적용한다.
- 기존 좌표·집중률 매칭 캐시는 새 촬영지 기준으로 다시 생성한다.
- 백엔드 재기동과 데이터 보강 뒤 다섯 작품의 보정 촬영지·좌표를 API 응답으로 확인했다. 지도 핀은 95개를 유지한다.
- 새 촬영지 이름은 집중률 대상 관광지와 매칭되지 않아, 다섯 작품의 `crowdAvailable`은 현재 `false`다. 이는 오류가 아니라 상세 화면의 방문 타이밍 섹션을 숨기는 기존 graceful 동작이다.
