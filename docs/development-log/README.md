# 개발 진행 로그

마일스톤과 커밋별 구현 경과를 이 폴더에서 독립 문서로 관리한다.

## 작성 규칙

- 새 마일스톤은 `M<번호>-<주제>.md`를 만들고 작업 시작 시 `진행 중`으로 기록한다.
- 구현 범위, 설계 결정과 이유, 검증, 특이사항/다음 작업을 작업 중 갱신한다.
- 커밋 직전 최종 범위와 검증을 확정하고, 커밋 뒤 해시와 날짜를 기록한다.
- 시크릿, 토큰, 개인 정보는 기록하지 않는다. 상세 계약·API·QA는 `_workspace/`에 두고 이 문서에서 연결한다.
