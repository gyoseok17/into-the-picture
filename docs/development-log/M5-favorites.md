# M5 — 즐겨찾기 · 완료

- 커밋: 예정
- 시작일: 2026-08-04

## 목표

- 수상작에 하트를 눌러 저장하고, `마이`에서 저장한 수상작을 다시 열어 이후 포토 비교로 이어질 수 있게 한다.

## 구현 범위

- 수상작 상세의 즐겨찾기 추가·해제
- 마이 화면의 저장한 수상작 목록과 상세 이동
- 비로그인 사용자의 로그인 유도

## 설계 결정

- M6 포토 비교의 진입점을 저장한 수상작으로 삼기 위해, 비교 기능보다 즐겨찾기를 먼저 구현한다.

## 현재 반영

- 수상작 상세에서 로그인 사용자는 하트로 저장·해제할 수 있고, 비로그인 사용자는 로그인 후 원래 수상작으로 돌아온다.
- 마이 화면에서 저장한 수상작을 카드로 확인하고 해당 수상작 상세를 다시 열 수 있다.
- 서버는 수상작 ID를 기준으로 저장해 제목·이미지 스냅샷을 직접 생성한다.
- 수상작 목록 카드의 우측 상단에서도 바로 저장·해제할 수 있다. 비로그인 사용자가 상세·목록의 하트를 누르면 로그인 필요 안내와 로그인 버튼을 표시한다.
- 카카오 인가 콜백은 StrictMode 재실행 때 이미 소비한 `state`를 다시 검증하지 않게 해, 정상 로그인 중 잘못된 실패 문구가 뜨지 않도록 보정했다.
- 하트의 로그인 유도에서 카카오 콜백 URL이 기본 화면으로 먼저 이동하지 않도록, 콜백 완료 뒤 저장한 원래 수상작 주소로 복귀하게 보정했다.
- 하트 상태는 서버 저장·목록 재조회 완료를 기다리지 않고 화면에 먼저 반영하고, 실패하면 이전 상태로 되돌린다.
- 저장 실패 시 원복만 하지 않고 화면 하단에 재시도 안내를 표시해 사용자가 실패를 인식하게 한다.
- 마이의 저장한 수상작 카드에서도 하트로 즉시 저장 해제할 수 있다.

## 검증

- 백엔드 `./gradlew test` 통과.
- 프런트 `npm run build` 통과. 번들 크기 500 kB 경고는 기존 분할 개선 과제로 유지한다.
- 브라우저 수동 점검: 상세·목록·마이의 저장/해제, 로그인 유도·원래 수상작 복귀, 여러 작품 연속 저장, 저장 실패 안내 흐름을 확인했다.
