# M3 — 관광사진 키워드 검색 · 진행 중

- 커밋: 예정
- 시작일: 2026-08-03

## 목표

- 관광공사 관광사진 API를 키워드로 실시간 검색해 피드와 상세 화면으로 제공한다.
- 빈 검색어에서는 최신 사진 피드를 표시하고, 사진 카드에서 장소·촬영자·촬영월·연관 키워드를 확인할 수 있게 한다.

## 설계 결정과 이유

- 검색어는 사용자가 직접 입력하거나, 이후 실제 검색 데이터가 충분할 때 노출할 인기 검색어를 선택한다. 고정 추천 키워드 목록은 두지 않는다.
- 사진 데이터는 저장하지 않고 외부 API 어댑터를 거쳐 실시간으로 조회한다.
- Redis 인기 검색어와 access 토큰 즉시 무효화는 보류하며, `docs/09-nfr.md`의 후보 기록을 M3 완료 전 다시 검토한다.

## 구현

- 비로그인 방문자는 비밀값이 없는 세션 표시 쿠키가 없을 때 refresh 요청 자체를 생략하도록 해, 콘솔의 불필요한 401을 없앴다. 실제 인증 판단은 기존처럼 HttpOnly refresh 쿠키와 서버 검증이 담당한다.
- 관광공사 `PhotoGalleryService1` 목록·키워드 검색을 내부 DTO와 1-based 페이지 응답으로 변환했다.
- 검색 탭에서 최신 피드, 키워드 검색, 무한 스크롤, 빈 결과·오류 상태를 제공한다.
- 한 외부 응답 페이지 안의 같은 제목·촬영지 사진을 앨범 카드로 묶고, 상세 모달에서 해당 사진·촬영지·촬영자·촬영월·관련 키워드를 표시한다.
- 관련 키워드를 누르면 해당 키워드로 다시 검색한다. 페이지 사이의 같은 제목은 별도 앨범으로 유지한다.

## 설계 변경과 이유

- 외부 사진 전체를 동기화하지 않는다. 전체 규모와 변경량을 가정하지 않고 실시간 페이지 검색을 유지한다.
- 사진별 장소 후보 검색·길찾기 보강은 촬영지 텍스트의 정확도가 낮아 이번 범위에서 제외했다.

## 검증

- 외부 API 목록(6,118건 응답)과 `단풍` 키워드 검색을 실제 호출로 확인했다.
- 브라우저에서 검색, 앨범 상세, 키워드 재검색, 무한 스크롤과 단일 사진 레이아웃을 확인했다.
- 백엔드 테스트와 프런트 프로덕션 빌드를 통과했다.
