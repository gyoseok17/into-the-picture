# M1.1 — 공모전 지도 뷰 · 완료

- 커밋: `ea4564d` (`feat: M1.1 공모전 지도 뷰`)
- 기간: 2026-08-02

## 구현

- 목록/지도 전환과 `/contests/map` 경로를 추가했다.
- Kakao 지도에 공모전 마커 클러스터를 표시하고, 겹친 위치의 항목을 함께 고를 수 있는 우측 상세 패널을 구성했다.
- 목록과 지도에 동일한 필터 조건을 적용하고 좌표가 있는 항목만 지도에 표시했다.

## 설계 결정과 이유

- 확대·축소 시 개별 마커와 클러스터가 자연스럽게 전환되도록 지도 SDK의 클러스터링을 사용했다.
- 하단의 작은 팝업 대신 우측 패널에서 사진·상세 정보·겹친 항목을 충분한 크기로 제공한다.

## 검증

- 지도 전환, 필터 동기화, 마커/클러스터 선택, 경계 조건 5건을 통과했다.
- 지도 타일의 `307` 뒤 `(canceled)` 표시는 화면 전환·재렌더 중 발생할 수 있는 정상 요청 취소임을 확인했다.
