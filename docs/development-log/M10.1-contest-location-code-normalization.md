## 설계 결정

### 001. 신규 보정 마이그레이션 사용 — 2026-09-22

- 결정: 이미 적용된 V16은 수정하지 않고 후속 마이그레이션으로 수상작의 `SHINAN` 값을 `SINAN`으로 갱신한다.
- 이유: 적용 완료된 Flyway 이력을 바꾸지 않고 배포 DB를 안전하게 이관한다.
- 검토한 대안과 선택하지 않은 이유: V16 수정은 기존 환경의 checksum 불일치를 유발하므로 사용하지 않는다.
- 영향 범위: 수상작의 지역 필터·비교 사진 후보 매칭만 정규화하며, 사용자 사진·파일 데이터는 변경하지 않는다.
- 재검토 조건 또는 후속 작업: 지역 카탈로그가 추가될 때 수상작 정본과 앨범 카탈로그를 함께 대조한다.

## 구현 변경

### 001. 신안군 코드·기존 수상작 보정 — 2026-09-22 / 백엔드·프런트

- 변경 내용: 신규 수상작 동기화 정본을 `SINAN`으로 바꾸고, V22에서 기존 `contest_work.map_city_code='SHINAN'`을 `SINAN`으로 보정했다. 프런트 지역 선택·지도 마커 카탈로그도 `SINAN` 소비를 확인했다.
- 변경 이유: 수상작 지역 코드와 앨범 지도·비교 후보 지역 코드가 달라 신안군 매칭이 누락될 수 있었다.
- 영향 범위: 신안군 수상작 지역 필터와 비교 사진 후보 매칭. API 형식과 사용자 사진·파일 데이터는 변경하지 않는다.
- 호환성·데이터 이관·되돌림 메모: V16은 불변으로 유지한다. 구버전은 문자열 읽기 자체는 가능하지만 구·신 버전을 동시에 운영하지 않고 컨테이너 교체 배포한다.
- 관련 계약·설계·QA 근거: `_workspace/backend/M10.1-contest-sinan-normalization-report.md`, `_workspace/frontend/M10.1-location-code-contract-review.md`, `_workspace/qa/M10.1-sinan-normalization-qa.md`.
