## 설계 결정

### 001. `AGENTS.md`를 공통 기준으로 사용 — 2026-08-12

- 결정: 저장소 루트 `AGENTS.md`를 Codex·Claude 공통 하네스의 최우선 규칙으로 둔다.
- 이유: Codex는 새 실행 시 저장소의 `AGENTS.md`를 자동으로 읽고, Claude 전용 파일만으로는 다른 실행 환경에 규칙을 전달할 수 없기 때문이다.
- 검토한 대안과 선택하지 않은 이유: `CLAUDE.md`만 유지하는 방식은 Codex에서 자동 적용되지 않는다. 전역 사용자 지침만 사용하는 방식은 이 저장소에 함께 보존·공유되지 않는다.
- 영향 범위: 모든 구현 세션의 역할 분담, QA, 문서, 커밋 절차.
- 재검토 조건 또는 후속 작업: 새 실행 환경이 도입되면 해당 환경이 `AGENTS.md`를 읽는지 확인하고 필요한 연결 문서를 추가한다.

### 002. 버전당 단일 마일스톤 파일 — 2026-08-12

- 결정: `M<번호>-<주제>.md` 파일 하나에 계획·변경·결정·역할별 결과·QA·커밋을 날짜·번호로 누적한다.
- 이유: 기존 M1~M6 방식과 일관되고, 현재 상태와 전체 이력을 한곳에서 빠르게 찾을 수 있다.
- 검토한 대안과 선택하지 않은 이유: 목적별 폴더·파일 방식은 과거 이력 분리에는 유리하지만 파일 탐색 부담이 커 사용자 선호와 맞지 않는다.
- 영향 범위: 이후 M7부터의 진행 기록.
- 재검토 조건 또는 후속 작업: 마일스톤 하나가 지나치게 길어져 탐색성이 떨어질 때만 분리 방식을 다시 검토한다.
