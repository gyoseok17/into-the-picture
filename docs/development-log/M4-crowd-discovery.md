# M4 — 혼잡도 탐색 · 완료

- 커밋: `e870b49` (`feat: M4 혼잡도 관광지 탐색`)
- 시작일: 2026-08-04

## 목표

- 독립 탭에서 지역·시군구·관광지를 직접 선택해 향후 30일 관광지별 혼잡도를 확인하게 한다.

## 현재 반영

- 독립 탭의 사용자 노출 명칭을 `타이밍`에서 `혼잡도`로 변경했다.
- 수상작 상세의 `방문 타이밍`은 작품 촬영지의 자동 안내 기능이라는 의미를 유지한다.
- 시·도 → 시·군·구 → 관광지 선택 API와 독립 화면을 구현하고, 선택 관광지의 30일 캘린더·추천일을 표시한다.
- 실제 API에서 `경상남도 → 합천군 → 가야산국립공원(홍류동,청량동지구)`을 선택해 30일 데이터와 추천일 5개를 확인했다.
- 선택 관광지와 현재 촬영지·집중률 매칭값·키워드가 겹치는 수상작을 최대 3건 표시한다. 승인된 촬영지 보정값도 현재 위치명으로 이 매칭에 포함한다.
- 관련 수상작 API에서 가야산국립공원 1건과 보정된 죽산보(29번) 1건의 새 촬영지 표기를 확인했다.
- 기존 키워드 검색과 같은 관광사진 앨범 카드·상세 보기를 해당 관광지명으로 불러온다. 이름 검색 특성상 다른 지역 사진도 섞일 수 있어 촬영지 확인 안내를 함께 표시하며, 수상작·사진 결과가 각각 없을 때도 빈 결과 안내를 표시한다.
- 브라우저에서 지역 선택, 수상작·사진·집중률 표시 순서, 수상작 상세 이동, 사진 앨범 상세, 빈 결과 안내, 선택값 초기화를 모두 확인했다.

## 설계 결정·제약

- 수상작은 현재 DB의 촬영지·집중률 매칭명·키워드를 비교해 최대 3건만 표시한다.
- 관광사진은 관광지명을 기존 사진 검색 API에 전달해 첫 검색 페이지의 앨범을 재사용한다. 지역 필터가 없는 이름 검색이므로 다른 지역 사진이 섞일 수 있음을 화면에 안내한다.
- 집중률 관광지 목록은 한국관광공사 예측 API가 제공하는 대상만 표시한다. 목록에 없는 수상작 촬영지는 자동 연결하지 않는다.
