## 확정 결정 요약

- **백엔드**: Spring Boot + JPA + Supabase PostgreSQL
- **프론트**: React (웹) + Capacitor → 웹 + Android 앱(지금), iOS 추후. 모바일 우선 반응형.
- **인증**: 카카오 인가 코드 로그인 + access JWT / HttpOnly refresh 쿠키
- **외부 API**: 한국관광공사 관광사진/공모전, 관광지 집중률 예측, Kakao Map (키 발급 완료)
