# 00. 프로젝트 개요

> **TourSnap** — 사진으로 여행지를 발견하는 관광 추천 서비스

## 배경 / 컨셉

기존 여행 서비스는 *목적지를 먼저 정한 뒤* 정보를 찾는 방식이다.
TourSnap은 **역발상** — 사용자가 원하는 **분위기(단풍·설경·야경 등)를 먼저 검색**하면, 사진을 중심으로 여행지를 탐색하게 한다.

한국관광공사의 관광사진·공모전 수상작과 집중률 예측 데이터를 활용해 **신뢰성 있는 사진**과 **최적 방문 시기**를 함께 제공한다.

## 목표

- 사진 중심의 직관적인 여행 탐색 경험
- 검증된 관광 콘텐츠(공사 사진·수상작) 활용
- 혼잡도(집중률)를 고려한 방문 타이밍 추천
- 여행 이후 사진 비교로 추억 기록

## 주요 기능

1. **키워드 사진 검색** — 분위기 키워드로 관광사진 피드 탐색
2. **공모전 수상작 탐색** — 계절·키워드·수상등급 필터
3. **방문 타이밍 추천** — 관광지 30일 집중률 캘린더 + 추천 방문일
4. **촬영지 지도 안내** — 촬영지 위치·길안내 (집중률·주변 정보 연계)
5. **포토 비교** — 내가 찍은 사진 ↔ 수상작 나란히 비교

## 기대 효과

- 여행지 선택의 어려움 감소
- 사진 중심의 직관적 탐색
- 혼잡도를 고려한 일정 계획
- 여행 후 사진 비교의 재미 요소
