# 카카오 지오코딩 (촬영지 텍스트 → 좌표)

사진/수상작에 좌표가 없어 카카오 Local 검색으로 변환한다. **실측 검증 완료(수상작 8/8 성공).**

헤더: `Authorization: KakaoAK {KAKAO_REST_KEY}` (`.env`).

## 2단계 폴백 (이 순서가 검증됨)
1. **장소명 키워드 검색** — `GET https://dapi.kakao.com/v2/local/search/keyword.json?query={장소명}`
   - 촬영지 텍스트를 콤마/슬래시로 분리 → **마지막 조각(장소명)**으로 검색이 가장 정확.
   - 예: "경상남도 합천군, 가야산국립공원" → "가야산국립공원" → (35.80, 128.11)
2. 0건이면 **전체 문자열**로 키워드 재검색.
3. 그래도 0건이면 **주소 검색** — `/v2/local/search/address.json?query={행정구역}` (첫 조각, 예 "경상남도 합천군") → 시군구 중심 좌표.

응답 `documents[0]`의 `y`(위도), `x`(경도)를 사용. `place_name`/`address_name`도 함께 보관 가능.

## 적용
- 공모전 수상작: sync 시 또는 상세 최초 조회 시 지오코딩하여 `lat/lng` 캐시(보강 배치). 매번 호출 금지.
- 정확도: 장소명이 있으면 정확, "○○군"만 있으면 동/면 수준. 대부분 장소명 포함이라 양호.

## 주변 추천(향후)
- 카테고리 검색 `/v2/local/search/category.json?category_group_code=AT4|FD6|AD5&x=&y=&radius=` 로 좌표 주변 관광/음식/숙박. (위치기반 관광정보 API 추가 신청 시 그쪽 우선)
