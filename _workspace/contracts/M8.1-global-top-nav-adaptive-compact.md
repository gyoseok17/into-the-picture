# M8.1 전역 상단 내비게이션 적응형 축약 계약

## 대상과 범위

- 대상은 데스크톱 전용 `TopNav`의 가운데 주요 메뉴다.
- 768px 미만의 모바일 하단 탭 전환 규칙과 앨범 내부 전환부는 변경하지 않는다.

## 표시 규칙

- 메뉴명은 브랜드, 주요 메뉴, 로그인·사용자 영역이 한 줄에 모두 들어갈 때 표시한다.
- 필요한 전체 너비가 실제 컨테이너 너비를 넘는 순간에만 주요 메뉴를 아이콘 전용으로 축약한다.
- 창 너비, 글꼴 로드, 로그인 상태와 닉네임 길이 변화는 다시 측정한다.
- 아이콘 전용 상태에서도 `aria-label`과 `title`은 유지한다.

## 구현 제약

- 고정된 중간 화면 폭 구간(`md:max-lg`)만으로 축약하지 않는다.
- 측정용 확장 메뉴는 화면과 접근성 트리에서 숨기고, 실제 메뉴의 상태·라우팅과 분리한다.
- 상태 변경은 값이 달라질 때만 수행해 `ResizeObserver` 재측정 루프를 만들지 않는다.
