# M8.1 지도 위치 대표 기록 계약

## 목표

- 사용자는 지도상의 같은 위치에 있는 자신의 방문 기록 중 하나를 대표 기록으로 지정할 수 있다.
- 대표 지정이 없거나 대표 기록이 삭제되면 지도는 기존 최신 기록을 대표로 사용한다.

## 위치 기준

- 권역·시군이 저장된 기록은 `CITY:{mapRegionCode}:{mapCityCode}`를 위치 키로 쓴다.
- 기존 장소 기반 기록은 `PLACE:{latitude(소수 3자리)}:{longitude(소수 3자리)}`를 위치 키로 쓴다.
- 위치 키는 서버가 사진 기록에서 계산한다. 클라이언트가 임의 키를 전달하지 않는다.

## API

- `PUT /api/v1/me/photos/map/representative`
  - 요청: `{ "photoRecordId": number }`
  - 서버: 로그인 사용자가 소유하고 지도 위치가 있는 사진 기록만 대표로 지정할 수 있다.
  - 응답: `204 No Content`
- `GET /api/v1/me/photos/bundles/map`
  - 기존 각 방문 기록 항목에 `representative: boolean`을 추가한다.

## 데이터 안전성

- 대표 설정은 `(user_id, location_key)` 당 하나다.
- 대표 사진 기록이 삭제되면 외래 키의 `ON DELETE SET NULL`로 설정만 비우며 다른 사진·묶음은 삭제하지 않는다.
- 대표 설정이 비어 있으면 기존 지도 정렬의 첫 방문 기록을 기본 표시한다.
