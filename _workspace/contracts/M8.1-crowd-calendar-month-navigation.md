# 혼잡도 월 단위 달력·미지원 안내 계약

## 범위

- `CrowdPage`와 수상작 상세의 `CrowdCalendar`은 같은 예측 응답을 사용한다.
- 예측 일별 데이터가 두 달에 걸치더라도 한 번에 한 달만 표시한다.

## 표시 규칙

- 달력은 예측 일자가 포함된 첫 달에서 시작하며, 이전·다음 화살표로 예측값이 존재하는 인접 월만 이동한다.
- 예측 범위를 벗어난 월로는 이동할 수 없다. 날짜 선택과 혼잡도·추천일 표시는 기존과 같다.
- 선택한 관광지의 요청이 정상 완료됐지만 응답이 `null`(204)이거나 일별 예측값이 없으면 `방문 집중률 정보가 제공되지 않아요`를 표시한다.
- 로딩·통신 오류는 제공 불가와 구분해 기존 로딩·재시도 UI를 유지한다.

## 비범위

- API, 백엔드, DB, 예측 기간은 변경하지 않는다.
