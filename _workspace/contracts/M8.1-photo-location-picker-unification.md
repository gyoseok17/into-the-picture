# M8.1 사진 추가 장소 선택 UI 계약

- `PhotoAddSheet`는 닫기 아이콘을 제공하지 않는다. 배경 클릭과 `Escape` 키는 업로드 중이 아닐 때만 기존과 같이 시트를 닫을 수 있다.
- 모든 사진 추가 진입점은 `PhotoRegionField`의 권역 → 시·군 선택을 사용한다.
- 맵의 `RegionPicker`와 사진 추가 시트는 `RegionCityPicker`의 같은 검색·목록·선택 표시 규칙을 사용한다.
- 맵에서 전달한 `mapRegionCode`, `mapCityCode`는 사진 추가 시트의 초기 장소로 유지한다.
- 저장은 `mapRegionCode`와 `mapCityCode`가 모두 있을 때만 활성화된다. API DTO와 저장 값은 변경하지 않는다.
