# M8.1 저장 수상작 사진 놓기 계약

## 생성 권한

- `POST /api/v1/me/comparisons`는 요청 사용자가 해당 수상작을 즐겨찾기한 경우에만 허용한다.
- 즐겨찾기하지 않은 수상작은 `403 FORBIDDEN`으로 거부한다.
- 실제 비교 사진은 업로드 묶음이 아닌 사용자가 소유한 `PhotoRecord`다.

## 중복 규칙

- 한 사용자에게 하나의 수상작은 사진 놓기 기록 하나만 가질 수 있다.
- 같은 수상작으로 두 번째 생성을 요청하면 기존 기록을 새로 만들거나 덮어쓰지 않고 `409 CONFLICT`를 반환한다.
- 기존 기록의 사진 교체는 기존 `PATCH /api/v1/me/comparisons/{comparisonId}` 흐름을 사용한다.
