# M8.1 앨범 시·군 위치 선택 계약

## `GET /api/v1/me/photos/map-locations`

- 기존 `code`, `label`, `cities` 구조는 유지한다.
- 각 `cities[]` 항목은 `latitude`, `longitude`를 추가로 반환한다.
- 선택지는 `docs/11-city-county-count.md`의 161개 정책을 따른다.
  - 서울·부산·대구·인천·광주·대전·울산·세종은 도시 자체만 선택한다.
  - 광역시 소속 군 6개는 반환하지 않는다.
  - 제주는 제주시·서귀포시를 반환한다.
- 저장 요청의 `mapRegionCode`와 `mapCityCode` 검증도 같은 목록을 사용한다.
