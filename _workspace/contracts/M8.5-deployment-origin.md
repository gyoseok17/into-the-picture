# M8.5 HTTPS 배포 Origin 계약

## 입력과 파생값

| 입력 | 소유자 | 파생 또는 소비자 |
| --- | --- | --- |
| `APP_DOMAIN=intothepicture.duckdns.org` | EC2 `backend/.env` | Caddy 사이트 주소, Compose HTTPS origin |
| `https://${APP_DOMAIN}` | Compose | `APP_CORS_ALLOWED_ORIGINS` 환경변수 |
| `APP_CORS_ALLOWED_ORIGINS` | Spring 외부 설정 | `app.cors.allowed-origins`, CORS 필터, Kakao callback origin 검증 |

## 불변 조건

- 기본 Compose는 HTTPS 전용이며 `APP_AUTH_REFRESH_COOKIE_SECURE=true`를 유지한다.
- 공개 브라우저 origin, CORS 허용 origin, Kakao redirect origin은 모두 `https://${APP_DOMAIN}`이어야 한다.
- Kakao redirect path는 `/login`이고, API·DB 응답 계약은 바뀌지 않는다.
- HTTP 전환은 이 계약의 범위 밖이며, 별도의 scheme·cookie 보안 결정이 필요하다.
