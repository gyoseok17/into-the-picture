# M8.1 앨범 지도 PC 지역 선택창 경계 계약

## 표시 규칙

- PC(`sm` 이상)에서 지역 선택 dialog는 하단 trigger의 **위쪽**으로 열려 지도 하단 밖으로 나가지 않는다.
- dialog 최대 높이는 지도 컨테이너 높이(`100cqh`)에서 trigger·여백을 제외한 값으로 제한하고, 초과 내용은 dialog 내부 세로 스크롤로 본다.
- 지도 컨테이너는 size container여서 dialog의 `cqh` 기준이 viewport가 아니라 실제 지도 경계다.

## 불변 조건

- 모바일 기본 열림(`bottom-0`), trigger, 도시 선택, 사진 추가 enable 조건과 동작은 바꾸지 않는다.
- 지역 필터·marker 포커스·확대·API는 변경하지 않는다.
