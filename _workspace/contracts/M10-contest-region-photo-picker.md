# M10 수상작 지역 기반 앨범 선택 계약

## 목표

수상작 비교에서 `앨범에서 고르기`를 열면, 선택 대상은 해당 수상작의 표준 지도 지역 코드와 같은 사진 기록만 표시한다.

## API·데이터 계약

- 수상작 상세의 `mapRegionCode`, `mapCityCode`는 기존 값과 의미를 유지한다.
- 앨범 조회는 기존 API와 DTO를 유지한다. 프런트는 이미 받은 수상작 지역과 앨범 기록의 지역 코드를 비교해 선택 목록을 좁힌다.
- 수상작과 기록에 시군 코드가 모두 있으면 같은 시군만 후보로 둔다. 수상작 또는 기록에 시군 코드가 없으면 같은 권역까지 완화한다.
- 수상작에 표준 권역 코드가 없을 때는 기존처럼 전체 앨범을 표시한다. 현재 데이터는 표준 코드가 채워져 있으나 호환 경로를 유지한다.

## UI 계약

- 앨범 선택 화면에 현재 좁혀진 지역을 표시한다.
- 해당 권역의 사진이 없으면 선택 카드 대신 “이 지역에 기록한 사진이 없어요” 안내와 새 사진 추가 경로를 보여준다.
- 새 사진 직접 업로드 흐름, 비교 권한, 비교 저장 API 및 기존 사진 비율 편집 흐름은 바꾸지 않는다.

## 검증

- 수상작 지역 코드와 앨범의 bundle/legacy record 지역 코드 비교
- 후보 없음 안내와 새 사진 업로드 진입
- 지역 코드 누락 시 전체 목록 호환
- 비교 생성 및 기존 선택 불가 사진 규칙 회귀
