# M8 무한 스크롤 빠른 조작 계약

## 대상

- 수상작 목록 `/contests`
- 키워드 사진 검색 `/explore`

## 표시와 동작

- 페이지를 일정 거리 이상 스크롤한 뒤에만 고정 도구를 표시한다.
- `위로 가기`: 부드럽게 페이지 최상단으로 이동한다. 사용자의 모션 감소 설정에서는 즉시 이동한다.
- 검색: `다시 검색`을 누르면 상단으로 이동한 뒤 검색 입력에 포커스한다. 기존 키워드는 유지한다.
- 수상작: `조건 변경`을 누르면 상단으로 이동한 뒤 기존 필터 조작부에 포커스한다. 현재 필터·뷰는 유지한다.
- 모바일 하단 탭과 겹치지 않는 위치를 사용한다.

## 범위

- API 요청, URL 쿼리, 무한 스크롤 감시, 결과 데이터는 바꾸지 않는다.
- 버튼은 키보드·스크린리더로 조작 가능하며, 표시·숨김은 포커스를 빼앗지 않는다.
