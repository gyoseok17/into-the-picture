# M8.1 프런트엔드 Caddy 정적 배포 계약

## 목적

React 정적 산출물은 프런트엔드 컨테이너에서 제공하고, 브라우저는 같은 도메인의 `/api/*`를 통해 백엔드에 접근한다.

## 이미지 경계

- 빌드 단계는 `npm ci` 뒤 `npm run build`를 실행한다.
- 빌드 인자는 공개 클라이언트 설정인 `VITE_API_BASE`(기본 `/api/v1`)와 `VITE_KAKAO_JS_KEY`만 받는다.
- `.env`와 모든 환경별 비밀 파일은 Docker build context에서 제외한다. 서버 DB·JWT·OAuth 시크릿은 프런트 이미지에 넣지 않는다.
- 런타임은 Caddy가 빌드 산출물만 제공하며 Node·소스·의존성은 포함하지 않는다.

## 라우팅

- Caddy는 런타임 `APP_DOMAIN`을 Caddy 환경 치환 `{$APP_DOMAIN}`으로 사이트 주소에 사용한다. Compose가 실제 도메인을 주입하면 Caddy 자동 HTTPS가 80→443과 인증서를 관리한다.
- `/api/*`는 Docker 네트워크의 `backend:8080`으로 프록시한다.
- 업로드·이미지 응답 경로 호환성을 위해 `/files/*`도 같은 백엔드로 프록시한다.
- 그 밖의 경로는 정적 파일을 반환하고, 존재하지 않는 경로는 `/index.html`로 보내 React Router 새로고침을 지원한다.

## 범위 밖
