# M8 홈 이달의 대표 수상작 계약

## 목적

홈 대표 사진은 현재 달에 촬영된 수상작 중 하나를 선택하고, 목록용 썸네일이 아닌 상세 원본 이미지를 표시한다.

## 기존 API 사용

1. `GET /api/v1/contests?page=1&size=100`
   - 공개 API이며 기존 `ContestSummary`를 사용한다.
   - 후보 판단 필드: `id`, `filmMonth`, `thumbUrl`, `title`, `location`.
2. `GET /api/v1/contests/{id}`
   - 선택된 후보 한 건에만 추가 호출한다.
   - 히어로 이미지 필드: `imageUrl` (원본), 실패 시 목록의 `thumbUrl`.

## 선택과 폴백

- `filmMonth`에서 월을 안전하게 읽어 브라우저의 현재 월과 일치하는 후보만 사용한다.
- 후보 중 한 건은 목록 응답이 유지되는 동안 안정적으로 선택한다. 불필요한 재렌더마다 바뀌지 않는다.
- 월 값이 없거나 형식이 맞지 않으면 후보에서 제외한다.
- 해당 월 후보가 없으면 목록 첫 작품을 사용한다.
- 상세 호출·원본 이미지가 실패해도 제목·링크·썸네일을 유지한다.

## 범위 밖

- 백엔드 API·DB·권한 계약은 변경하지 않는다.
- 대표작 고정 편집, 서버 측 랜덤, 노출 통계는 이번 범위에 넣지 않는다.
