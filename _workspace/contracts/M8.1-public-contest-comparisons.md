# M8.1 Public contest comparisons contract

## Policy

- A personal album record remains private in every case.
- Only a `PhotoRecord` linked to one contest work can be shared as a comparison.
- New and existing linked comparisons default to `PUBLIC`.
- Only the record owner may change visibility. `PRIVATE` comparisons never appear in public lists or public file routes.
- The contest-detail public gallery shows every `PUBLIC` comparison returned by the public API, including the signed-in viewer's own public comparison. It must show its empty state only when that API returns an empty list.
- Public responses must not expose album/map/private-record fields: owner, filename, storage key, place, map location, memo, taken-at, archive state, or the `/me/**` file route.

## Owner API

`PATCH /api/v1/me/comparisons/{comparisonId}/visibility`

Request:

```json
{ "visibility": "PUBLIC" }
```

Allowed values: `PUBLIC`, `PRIVATE`. The owner-only response is the existing `ComparisonDto`, now with `visibility`.

## Public gallery API

`GET /api/v1/contests/{contestId}/comparisons`

Returns `200 []` when no public comparison exists. Each item is deliberately minimal:

```json
{
  "id": 123,
  "photoUrl": "/api/v1/contests/94/comparisons/123/file",
  "createdAt": "2026-09-12T12:00:00"
}
```

`GET /api/v1/contests/{contestId}/comparisons/{comparisonId}/file` serves only the matching, active `PUBLIC` comparison image. The returned `photoUrl` includes `/api/v1` because browsers render it directly rather than through Axios's API base URL. Any mismatched contest id, private comparison, archived comparison, or missing comparison returns `404`; it never falls back to a user-photo storage path. Responses use `Cache-Control: no-store` so a visibility switch does not leave a browser cache route valid.

## 수상작 상세 비교 화면 UI 계약

- 수상작 상세의 사진 아이콘은 화면 하단 시트가 아닌, 배경 위 중앙에 뜨는 모달을 연다. 바깥 배경 클릭과 `Escape`로 닫고, 열기 전 포커스로 되돌린다.
- 모달은 수상작 원본을 항상 왼쪽 기준 사진으로, 선택한 공개 비교 사진을 오른쪽에 같은 크기로 나란히 보여 준다. 원본은 기존 수상작 상세 데이터의 이미지 URL만 사용한다.
- 공개 비교 사진이 둘 이상이면 하단 썸네일에서 하나를 선택해 오른쪽 비교 사진만 바꾼다. 썸네일은 공개 API가 반환한 `id`, `photoUrl`, `createdAt`만 사용하며, 개인 앨범 메타데이터를 추가로 요청하거나 표시하지 않는다.
- 로딩·오류·0건 안내는 기존 공개 API 상태를 그대로 사용한다. 0건일 때는 비교판·썸네일을 그리지 않는다.
