# M8.1 앨범 상단 보기 전환부 축약 계약

## 대상

`PhotoRecordAlbum`의 스토리·맵·보관함 보기 전환부다. 사진 기록의 데이터, API, URL 상태는 바꾸지 않는다.

## 반응형 규칙

- 화면 폭이 540px 이하이면 스토리·맵·보관함의 보이는 텍스트를 숨기고 각 아이콘만 표시한다.
- 541px 이상에서는 기존 텍스트 레이블을 유지한다.
- 전환부는 어느 폭에서도 줄바꿈하지 않는다.

## 접근성·상태

- 아이콘 전용 상태에도 각 버튼은 `aria-label`, `title`, 스크린 리더용 텍스트를 유지한다.
- 현재 선택된 스토리 또는 맵의 기존 활성 스타일과 클릭 동작은 유지한다.
- 보관함은 현재 상태에 따라 기존의 앨범/보관함 전환 동작을 유지한다.
