# M8.1 수상작 상세 내부 비교 결과 보기 계약

## 목적

수상작 상세에서 이미 저장한 내 비교 사진을 확인해도 `/compare` 경로로 이동하지 않는다. 수상작 상세 오버레이 위에서 기존 비교 결과 창을 열고 닫은 뒤에는 같은 상세 화면을 유지한다.

## UI 계약

- 로그인 사용자가 저장한 비교가 있는 수상작 상세에는 내 사진 미리보기 버튼이 표시된다.
- 이 버튼은 공통 `PhotoComparisonResultDialog`를 열어 기존 `ComparisonPlacementPair` 비교판으로 수상작과 내 사진을 보여 준다.
- 한 수상작에 비교 기록이 여러 개면 결과 창 안에서 비교 대상을 전환할 수 있다.
- 결과 창은 상세 오버레이보다 높은 레이어에서 열리며 Escape·배경 클릭·닫기 버튼은 결과 창만 닫는다.
- 닫은 뒤에는 상세 화면의 내 사진 미리보기 버튼으로 초점을 되돌린다.
- 공개 비교 사진 모음과 새 비교를 시작하는 기존 버튼의 역할은 바꾸지 않는다. API·DB·라우트 계약도 변경하지 않는다.
