# M8.1 수상작 비교 명칭과 확대 원본 사진 트리거 계약

## 목적

사용자에게 보이는 비교 기능의 명칭을 `수상작 비교`로 통일하고, 앨범 사진 확대 보기의 텍스트 동작을 수상작 원본 썸네일로 대체한다.

## UI 계약

- 비교 결과 관리 화면, 수상작 상세·마이의 비교 진입, 사진 선택·자르기·결과 창의 사용자 문구는 `사진 놓기` 대신 `수상작 비교`를 사용한다.
- URL(`/compare`)과 컴포넌트·도메인 내부 명칭은 호환성을 위해 바꾸지 않는다.
- 비교 연결 사진을 확대하면 사진 아래에 트로피, 수상작 제목·지역, 클릭 가능한 수상작 원본 썸네일을 표시한다.
- 원본 썸네일을 누르면 현재 확대 보기 위의 인라인 비교 결과 창을 열며, 경로 이동은 하지 않는다.
- 여러 수상작이 연결된 경우 대표 원본 썸네일에 연결 수를 배지로 알리고, 비교 결과 창 안에서 비교 대상을 전환한다.

## 접근성·반응형

- 원본 썸네일 버튼은 수상작 제목과 비교 열기 목적을 포함한 `aria-label`을 갖는다.
- 제목·지역은 한 줄 말줄임으로 유지하고, 원본 썸네일은 고정 크기로 줄어들지 않아 좁은 화면에서도 동작 영역을 보장한다.
