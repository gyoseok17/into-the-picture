# 지도 큰 사진 수상작 비교 트로피 계약

- 대상: 지도 모드에서 선택한 방문 기록의 현재 큰 사진.
- 표시: 해당 사진 ID와 연결된 비교 기록이 하나 이상일 때만 사진 좌측 상단에 아이콘 전용 트로피를 표시한다.
- 동작: 트로피를 누르면 페이지 이동이나 사진 확대 없이 현재 화면 위의 `PhotoComparisonResultDialog`를 열고, 여러 비교 기록은 그 창에서 전환한다.
- 분리: 큰 사진 본문을 누를 때만 사진 확대 보기를 연다. 트로피 클릭은 이벤트 전파를 막아 확대 동작을 유발하지 않는다.
- 제외: 기존 사진 아래의 `비교 연결` 텍스트 영역은 표시하지 않는다. API·DB·비교 연결 판정 계약은 변경하지 않는다.
