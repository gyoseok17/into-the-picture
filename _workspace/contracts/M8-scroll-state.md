# M8 키워드 검색 앨범 스크롤 계약

## 사진 앨범 모달

- 앨범 안의 사진 목록은 모달 안에서만 스크롤한다.
- 모달 스크롤이 처음 또는 끝에 닿아도 배경 검색 결과 목록으로 스크롤이 전파되지 않는다.
- 모달을 연 동안 배경 문서 스크롤을 잠그고, 닫을 때 원래 위치를 복원한다.
- 배경 클릭·닫기 버튼으로 닫아도 같은 복원 규칙을 적용한다.

## 제외 범위

- 수상작 상세의 목록 복귀는 이 계약이 아니라 `M8-contest-detail-overlay.md`를 따른다.
- API, 검색 URL, 앨범 묶기, 무한 스크롤 데이터 요청 계약은 바꾸지 않는다.
