# M8.1 수상작 비교 구도 계약 초안

## 목적

수상작 원본의 실제 가로세로비를 비교 틀로 사용한다. 사용자는 비교에 연결할 사진을 선택할 때 확대와 위치를 조절하며, 저장한 구도는 내 비교 화면과 공개 비교 화면에서 동일하게 사용한다.

## 비교 구도

```ts
interface ComparisonCrop {
  aspectRatio: number // 수상작 원본 naturalWidth / naturalHeight, 0보다 큼
  zoom: number        // 1 이상, 프런트 편집기 범위 1~3
  offsetX: number     // -1~1, 잘려 나가는 가로 여백 안의 정규화 위치
  offsetY: number     // -1~1, 잘려 나가는 세로 여백 안의 정규화 위치
}
```

- `aspectRatio`는 편집 당시 수상작 원본의 실제 비율이며, 공개 목록을 포함한 모든 소비자가 동일한 비교 틀을 재현할 수 있도록 비교 레코드에 보관한다.
- 기존 비교 기록은 `crop: null` 또는 기본값 `{ aspectRatio: 4 / 3, zoom: 1, offsetX: 0, offsetY: 0 }`으로 호환한다.

## 필요한 API 변경

- `POST /me/comparisons`: `{ userPhotoId, contestId, crop }`
- `PATCH /me/comparisons/{id}`: `{ userPhotoId, crop }`
- 소유자 `ComparisonDto` 및 공개 `PublicComparisonDto`에 `crop: ComparisonCrop | null` 포함

공개 DTO에는 구도 외에 개인 사진의 장소·메모·파일명·소유자 정보를 추가하지 않는다.
