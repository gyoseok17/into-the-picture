# M8.1 앨범 지도 반응형 좌표 상자 계약

## 목표

- 앨범 지도 SVG 도형과 방문 기록 마커가 데스크톱·모바일의 모든 표시 크기에서 같은 2:3 좌표 상자를 사용한다.

## 표시 규칙

- 지도 뷰포트의 사용 가능 너비를 `W`, 높이를 `H`라고 한다.
- 지도 stage의 크기는 `stageWidth = min(W, H × 2 / 3)`, `stageHeight = stageWidth × 3 / 2`이다.
- SVG는 `viewBox="0 0 1024 1536"`, `preserveAspectRatio="xMidYMid meet"`로 stage를 정확히 채운다. stage와 SVG의 종횡비가 모두 2:3이므로 letterbox 영역은 생기지 않는다.
- `albumMapCityPositions.ts`의 `left`·`top` 백분율은 이 stage를 기준으로 absolute 배치한다. SVG와 마커는 같은 transform wrapper 안에 있어 확대·집중 보기에도 함께 변환된다.

## 범위 밖

- 161개 시·군 좌표 값, 지도 SVG path, 방문 기록 묶음 기준, API 응답은 변경하지 않는다.
- 지도 하단 지역 선택·사진 추가 패널은 뷰포트 기준을 유지하며 stage 크기 변경에 관여하지 않는다.

## 반응형 검증 기준

- 375px, 390px, 430px 폭과 짧은/긴 viewport 높이에서 `stageWidth / stageHeight = 2 / 3`이어야 한다.
- SVG의 rendered viewport와 marker absolute containing block의 좌표 원점·너비·높이가 동일해야 한다.
- 마커 선택 후 `scale`/`translate`가 SVG와 marker wrapper 모두에 적용되어 상대 위치가 변하지 않아야 한다.
