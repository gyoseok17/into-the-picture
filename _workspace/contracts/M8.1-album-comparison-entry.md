# M8.1 앨범 기반 사진 놓기 UI 전환 계약

## 경로와 진입

- 하단 내비게이션의 `내 앨범`은 `/me/album`으로 이동한다.
- 새 사진 놓기는 수상작 상세와 마이의 수상작 카드에서 `/me/album?contestId=<수상작 ID>`로 이동한다.
- `contestId`가 있고 같은 수상작의 비교 결과가 이미 있으면 새 선택 모드를 열지 않고 기존 결과로 연결한다.
- `/compare`는 기존 저장 결과 목록·변경·삭제 전용으로 남긴다. 새 작성 UI와 수상작 선택 UI는 렌더링하지 않는다.

## 앨범 UI 상태

- 기본 스토리·맵·보관함은 사진 기록 탐색만 담당한다. 비교를 만들기 위한 선택 UI는 기본 화면에 노출하지 않는다.
- `contestId`가 유효하고 기존 비교가 없을 때만 앨범의 비교 선택 모드가 열린다.
- 비교 선택 모드에서는 기존 개별 사진을 하나 선택하거나 새 사진을 추가한 뒤, 선택된 사진과 고정 수상작으로 비교를 생성한다.
- 생성 성공 후 비교 결과는 `/compare?contestId=<수상작 ID>`에서 확인한다.

## 연결 표시와 데이터 경계

- 비교 연결 여부는 `PhotoComparison.userPhoto.id`와 앨범 `PhotoRecord.id`를 비교해 화면에서 파생한다. 새 API 필드는 요구하지 않는다.
- 기본 앨범의 카드·맵에서는 연결된 사진에만 작은 상태 표시를 보인다.
- 사진 상세에서는 연결 수상작 제목과 결과로 가는 링크를 제공한다. 연결되지 않은 사진에는 비교 CTA를 표시하지 않는다.
- 비교 결과의 사진 변경·결과만 삭제·사진도 삭제 계약은 기존 `/compare`에 보존한다.

## 오류와 제한

- 비교 목록 또는 앨범 사진을 불러오지 못하면 각 기존 오류 상태를 표시하고, 선택·생성은 필요한 데이터가 준비될 때까지 비활성화한다.
- 한 장의 앨범 사진이 여러 비교에 연결될 수 있으므로, 상세에는 연결된 결과를 모두 나열한다.
- 촬영일 출처 enum은 서버 응답 `BUNDLE_START_FALLBACK`을 프런트 타입에도 그대로 사용한다.
