# 공모전 지도 뷰 — 계약 시드 (리드 게시, 2026-07-31)

> 목적: 공모전 목록을 리스트/지도 2뷰로. 지도 뷰는 필터 걸린 작품 전체를 카카오맵에 마커로.
> backend↔frontend 이 시드를 기준으로 구현, 경계 변경 시 SendMessage 합의 후 api-shapes 갱신.

## 신규 엔드포인트: `GET /api/v1/contests/map`
- **페이지네이션 없음** — 필터 조건에 맞는 작품 **전체**를 배열로 반환(지도는 한 번에 다 찍어야 하므로). 좌표(lat/lng)가 **둘 다 non-null 인 작품만** 포함(지오코딩 안 된 건 지도에 못 찍으니 제외).
- **필터 파라미터 = 목록과 동일**: `season` `grade` `division` `sido` `keyword` (정확일치 4 + keyword 부분일치). **`sort`/`page`/`size` 없음.** 기존 `ContestSpecifications` 재사용(중복 로직 금지 — 목록과 같은 필터 규칙).
- 이미지 URL은 목록과 동일하게 `http→https` 치환.

### 응답 shape (배열 직접, 200)
```ts
type ContestMapPin = {
  id: number;
  title: string;
  thumbUrl: string;    // https 치환됨 (미리보기 카드 썸네일)
  lat: number;         // non-null 보장(응답에 포함된 건 항상 좌표 있음)
  lng: number;
  awardGrade: string;  // 마커/미리보기 뱃지용 ("대상"·"입선" 등)
  sido: string | null; // 미리보기 보조 표기
}
// 응답: ContestMapPin[]
```
- 데이터 없으면 `[]`.

## 프론트 UX
- 목록 페이지 상단에 `[ 리스트 | 지도 ]` 토글. 필터 바는 두 뷰 공유(같은 필터 상태 → 리스트/지도 동시 반영).
- 지도 뷰: 카카오맵 `MarkerClusterer`로 현재 줌 레벨에서 가까운 핀을 묶고, 핀 전체가 보이도록 bounds를 맞춘다. 확대하면 클러스터는 자동으로 개별 핀으로 분리된다.
- **개별 핀 클릭**은 1개, **숫자 클러스터 클릭**은 그 클러스터의 모든 작품을 선택한다. 데스크톱에서는 지도 우측의 큰 사진·정보 패널, 모바일에서는 지도 아래 패널에 선택 작품 카드를 표시한다.
- 카드에는 썸네일·제목·등급·지역을 표시하며, 클릭 시 상세(`/contests/{id}`)로 이동한다. 필터·줌·지도 이동 시 현재 상태와 맞지 않는 선택은 비운다.
- 좌표 없는 작품은 지도에 제외되지만 리스트 뷰에는 남는다. 현재 실데이터는 좌표 95/95건이 적재되어 있다.
- 키 없을 때 graceful("지도 준비중")는 이미 있음 — 유지.
