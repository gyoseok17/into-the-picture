# M8.1 사진 묶음 수동 촬영일 multipart 보완 계약

작성일: 2026-09-08

## 요청 규칙

- `manualTakenAts`는 선택적 반복 multipart 필드다.
- 사용자가 사진별 촬영일을 하나도 직접 지정하지 않으면 프런트는 필드 자체를 전송하지 않는다.
- 하나 이상 직접 지정했으면 프런트는 `files`와 같은 길이·순서의 값을 전송한다.
- 직접 지정하지 않은 사진은 예약값 `__AUTO__` 슬롯으로 전송해 EXIF → 수동값 → 묶음 시작일의 서버 우선순위와 파일별 위치를 유지한다. 빈 문자열 슬롯은 multipart 바인딩 중 축약될 수 있어 사용하지 않는다.

## 서버 해석

- 필드가 없으면 서버는 각 파일의 수동 촬영일을 `null`로 해석한다.
- 필드가 있으면 파일 수와 같은 수의 슬롯이 반드시 있어야 한다. `__AUTO__`는 해당 파일에 수동 촬영일이 없다는 뜻으로 `null`과 같이 해석한다.

이 규칙은 빈 날짜만 가진 요청이 multipart 바인딩 과정에서 축약되어 발생하는 `manualTakenAts must contain one value for each uploaded file` 오류를 막는다.
