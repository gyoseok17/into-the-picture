# M8.1 사진 기록 묶음 업로드 한도 계약

## 적용 경로

`POST /api/v1/me/photos/bundles`

## 한도

- 사진 기록 묶음은 한 요청에 1~3장만 허용한다.
- 각 이미지 파일은 최대 10MB다.
- HTTP multipart 요청 전체는 최대 32MB다.

32MB 요청 한도는 세 장이 각각 10MB일 때 파일 합계 30MB와 multipart 경계·텍스트 필드의 작은 오버헤드를 함께 허용하기 위한 값이다. 파일 수는 서비스 계층이, 파일별 크기와 형식은 이미지 검증기가, 전체 요청 크기는 Spring multipart 설정이 각각 방어한다.

## 실패 계약

- 0장 또는 4장 이상: `400 INVALID_REQUEST`, `files must contain between 1 and 3 images.`
- 파일 하나가 10MB 초과 또는 지원하지 않는 이미지: `400 INVALID_REQUEST`
- multipart 전체가 32MB 초과: 요청 파싱 단계에서 거절되며 기존 글로벌 multipart 예외 응답을 따른다.

## 호환성

- 응답 DTO와 저장 모델은 바뀌지 않는다.
- 이전의 4~20장 묶음 업로드만 더 이상 허용하지 않는다. 아직 커밋 전 M8.1 동작 정책을 사용자 확인 기준인 최대 3장으로 정렬한다.
