# M8.1 Supabase Docker Compose 계약

## 목적

백엔드 컨테이너는 DB를 기동하지 않고 `backend/.env`가 제공한 PostgreSQL/Supabase 연결값으로 외부 DB에 연결한다.

## 입력과 경계

- Compose의 유일한 `env_file`은 `backend/.env`다. 이 파일은 저장소에 포함하지 않는다.
- `DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USERNAME`, `DB_PASSWORD`, `JWT_SECRET`, 외부 API 키 등 Spring 설정이 요구하는 값은 `.env` 또는 배포 환경변수로 주입한다.
- Docker에서는 `.env` 파일을 이미지에 복사하거나 마운트하지 않는다. Spring의 선택적 파일 import는 로컬 Gradle 실행만 보조한다.

## 데이터 보존

- `LocalFileStorage` 경로는 `/app/uploads`이며 named volume `itp-uploads`에 연결한다.
- DB와 업로드 파일의 영속 운영 저장소 전환(S3/Supabase Storage)은 이번 범위 밖이다.

## 호환성

- 로컬 개발은 계속 `cd backend; .\\gradlew.bat bootRun`을 사용한다.
- Compose 시작은 `cd backend; docker compose up --build`다.
