# M10 비교 결과 수정 계약

## 진입과 행동

- 로그인한 본인의 비교 결과 확대 팝업에서 `수정`을 누르면 현재 사진의 크롭 편집 화면을 바로 연다.
- 크롭 편집 화면에는 현재 구도 저장, 사진 변경, 삭제를 함께 둔다.
  1. 사진 변경: 앨범의 선택 가능한 사진 또는 새 업로드 사진을 고르고, 수상작 비율 기준의 크롭을 함께 확정한다.
  2. 현재 구도 저장: 현재 연결된 사진을 유지한 채 크롭만 저장한다.
  3. 삭제: 이 행동을 누를 때만 결과만 삭제 또는 사진까지 삭제를 선택한다.

## API 계약

- 사진 변경은 `PATCH /me/comparisons/{id}`에 새 `userPhotoId`와 확정한 `crop`을 보낸다.
- 크롭 변경은 `PATCH /me/comparisons/{id}/crop`에 확정한 `crop`만 보낸다.
- 두 PATCH는 기존처럼 서버에서 비교 소유권과 선택한 사진의 소유권·수상작 연결 가능 여부를 검사한다.
- 성공 뒤에는 현재 팝업의 비교 결과와 앨범·비교 관리 관련 캐시를 갱신한다. 실패 시 수정 화면을 유지하고 사용자용 오류를 표시한다.

## 정리 대상

- 소비자가 없는 `useUserPhotos`, `useDeleteUserPhoto`, 해당 API 함수와 `['user-photos']` 무효화는 제거한다.
- `BatchPhotoUploadPanel`의 `showLocationField`가 호출처 없이 기본값만 쓰인 것이 확인되면 옵션·조건 분기를 제거한다.
- 단일 사진 업로드·앨범 묶음 선택·비교 중인 사진의 선택 불가 규칙은 유지한다.
