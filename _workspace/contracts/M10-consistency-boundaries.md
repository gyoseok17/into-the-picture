# M10 일관성 경계 정리 계약

## 목적

사진 기록의 지역 입력 규칙, React Query 캐시 키, 모달 공통 상호작용을 각각 한 경계에서 관리해 이후 기능 추가 시 규칙 복제를 막는다.

## 범위

- 백엔드: 단건 업로드·묶음 업로드·사진 수정이 같은 지역 코드 정규화 및 `MapLocationCatalog` 검증 경로를 사용한다.
- 프런트엔드: 캐시를 쓰는 각 도메인이 자신의 query key 모듈을 통해 key를 생성한다.
- 프런트엔드: Esc 닫기·포커스 복귀·스크롤 잠금 중 실제로 같은 동작만 공통 훅으로 제공한다.

## 비범위

- API URL, DTO, DB 스키마, 기존 사용자 화면의 동작 및 모달 디자인 변경
- 서로 다른 모달을 하나의 범용 UI 컴포넌트로 통합

## 검증

- 백엔드 테스트와 프런트엔드 빌드
- 단건/묶음 업로드 및 사진 수정의 지역 검증 계약 대조
- 기존 모달의 Esc 닫기, 포커스 복귀, 스크롤 잠금 회귀 대조
- 캐시 key 직접 배열 작성과 무효화 경로 점검
