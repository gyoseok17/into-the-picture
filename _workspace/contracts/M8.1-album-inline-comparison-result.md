# M8.1 앨범 내부 비교 결과 보기 계약

## 목적

앨범 스토리·지도에서 사진 확대 보기 중 연결된 수상작 원본을 선택해도 `/compare`로 화면을 이동하지 않는다. 현재 앨범의 사진 확대 보기 위에 비교 결과 창을 열고, 닫으면 원래 사진·지도·스토리 상태를 유지한다.

## UI 계약

- 비교 연결이 있는 사진의 원본 미리보기와 연결 수상작 항목은 비교 결과 창을 연다.
- 결과 창은 수상작과 내 사진을 기존 `ComparisonPlacementPair` 표현으로 보여 준다.
- 사진 한 장에 비교가 여러 건이면 창 안에서 비교 대상을 바꿀 수 있다.
- Escape·배경 클릭·닫기 버튼은 가장 위의 비교 결과 창만 닫는다. 닫은 뒤에는 열기 버튼으로 초점을 돌린다.
- 비교 결과 창은 사진 확대 창보다 높은 z-index를 사용하고, API·DB·비교 저장 데이터는 바꾸지 않는다.
