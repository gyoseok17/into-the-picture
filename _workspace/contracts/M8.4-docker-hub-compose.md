# M8.4 Docker Hub Compose 계약

- `backend/docker-compose.yml`은 `gyoseok/into-the-picture-backend:${APP_IMAGE_TAG}`와 `gyoseok/into-the-picture-frontend:${APP_IMAGE_TAG}`를 사용한다.
- `APP_IMAGE_TAG`는 `.env`에 명시하며 최초 기본값은 `m8.3`이다.
- 배포 Compose에는 `build:`, 로컬 AWS 프로필, Access Key·Secret Key, 로컬 `.aws` 마운트를 두지 않는다.
- backend는 `.env`를 읽고 8080만 Compose 내부에 노출한다. frontend(Caddy)만 80·443을 외부에 공개한다.
- `APP_DOMAIN`은 실제 도메인만 허용한다. `localhost`는 EC2 배포 값이 아니다.
- `VITE_KAKAO_JS_KEY`는 이미지 빌드 시점 값이므로 Hub 이미지 실행용 `.env`에 넣지 않는다.
