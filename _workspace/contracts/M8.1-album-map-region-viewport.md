# M8.1 앨범 지도 권역 뷰포트 계약

## 좌표와 경계

- `albumMapRegionViewport.ts`의 `albumMapRegionBounds`는 `albumMapCityPositions`와 같은 0–100 stage 좌표계를 사용한다.
- 여섯 권역 경계는 선택 가능한 SVG path 전체를 포함한다. 전라·경상의 분리 도서 path도 경계에 포함한다.
- 경계는 지도 SVG를 다시 그릴 때 함께 재보정한다. 화면 컴포넌트에는 권역별 좌표를 직접 두지 않는다.

## 상태 우선순위

1. 마커를 선택하면 기존 1.38배 마커 focus 뷰포트가 권역 framing보다 우선한다.
2. 마커 focus를 닫으면 선택한 권역 framing으로 돌아간다.
3. 같은 권역을 다시 누르거나 지도 빈 곳을 누르면 권역·도시·마커 선택을 모두 해제하고 전체 지도(배율 1)로 돌아간다.
4. 권역 안에서 도시를 선택해도 권역 framing은 유지한다.

## 화면 규칙

- SVG와 마커는 같은 transformed stage 안에서 함께 이동·확대한다.
- 권역 frame은 전체 권역이 보이도록 12% 여백을 더해 계산하며, 배율은 1~2.2로 제한한다.
- transform에는 500ms ease-out 전환을 사용한다. 지도 stage의 2:3 비율과 PC·모바일 컨트롤의 위치는 바꾸지 않는다.

## Transform 원점과 검증식

- transformed stage는 반드시 `transform-origin: 0 0`을 명시한다. CSS 기본값인 중앙 원점에 의존하지 않는다.
- 중심 좌표 `C`, 배율 `S`의 transform은 `translate(50 - C × S) scale(S)`이다. 따라서 `C`의 화면 좌표는 `S × C + (50 - S × C) = 50`이 되어 stage 중앙에 정확히 온다.
- bounds의 폭·높이에 12% 여백을 더해 `S ≤ 100 / (span + 12)`로 계산하므로, scale clamp가 적용되지 않는 권역은 전체 bounds가 stage 안에 남는다. clamp된 권역도 기존 bounds 폭·높이보다 작은 최대 배율을 사용하지 않으므로 잘리지 않는다.
