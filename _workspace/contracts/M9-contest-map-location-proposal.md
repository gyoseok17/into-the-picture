## 적용 방식

1. 새 Flyway 마이그레이션으로 `contest_work.map_region_code`, `contest_work.map_city_code`를 추가한다.
2. 위에서 승인된 ID별 값을 명시적 `UPDATE`로 넣는다. 추측 파서나 외부 지오코딩은 사용하지 않는다.
3. `ContestDetailDto`에 읽기 전용 지도 코드(또는 라벨)를 노출한다.
4. 수상작 비교의 새 사진 추가 시에는 승인된 수상작 위치를 기본 제안으로 보여 주되, 사용자가 기존 지역 선택기에서 바꿀 수 있게 한다. 기존 앨범 사진 위치는 덮어쓰지 않는다.
