# M8.1 비교 공개 관리 화면 계약

## 목적

수상작 비교 결과의 공개 여부를 결과 상세가 아닌 마이의 전용 관리 화면에서 변경한다. 개인 앨범과 사진 기록은 이 화면에서 노출하거나 변경하지 않는다.

## 경로와 접근

- `GET /me/comparisons` 데이터는 기존 `GET /api/v1/me/comparisons`를 그대로 사용한다.
- 프런트 경로 `/me/comparisons`는 인증이 필요하다.
- 마이의 `공개 관리` 항목은 이 경로로 이동한다.
- 하단 내비게이션의 `내 앨범` 경로 `/me/album`은 개인 기록 화면으로 유지한다.

## 화면 계약

- 항목별로 내 사진 썸네일, 수상작명, 현재 공개 상태와 상태 변경 버튼을 표시한다.
- `PUBLIC`이면 `공개 중` 상태와 `비공개` 전환 버튼을, `PRIVATE`이면 `비공개` 상태와 `공개` 전환 버튼을 제공한다.
- 변경은 기존 `PATCH /api/v1/me/comparisons/{id}/visibility`와 `visibility: PUBLIC | PRIVATE` 요청을 사용한다.
- 요청 중에는 해당 항목만 비활성화한다. 실패는 해당 항목에서 안내하고 다른 항목의 조작은 막지 않는다.
- 비교 결과 상세 화면에는 공개 상태 변경 UI를 두지 않는다.

## 비범위

- 공개 API, 사진 파일 접근 권한, 기본 공개값, 비교 생성/교체/삭제 계약은 바꾸지 않는다.
- 앨범의 개인 사진·장소·메모·촬영일은 공개 관리 화면에 노출하지 않는다.
