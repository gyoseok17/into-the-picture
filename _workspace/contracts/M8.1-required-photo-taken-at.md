# M8.1 사진 촬영일 필수 저장 계약

## 규칙

- 새 사진 기록은 최종 `takenAt`이 있을 때만 저장한다. 기존 기록의 null 촬영일은 이 규칙으로 수정하거나 삭제하지 않는다.
- 요청의 `takenAt`이 있으면 그 값을 단건 사진과 묶음의 모든 사진에 사용한다.
- 요청값이 없으면 서버가 각 파일의 EXIF 촬영일을 읽는다. 묶음에서는 파일마다 별도로 읽으며, 한 파일이라도 최종 촬영일이 없으면 묶음 전체를 저장하지 않는다.
- 서버 EXIF가 없거나 읽기에 실패한 최종 null은 `400 INVALID_REQUEST`, 메시지 `촬영일을 확인할 수 없습니다. 촬영일을 직접 지정해 주세요.`로 응답한다.

## 안전성

- 묶음은 모든 파일의 촬영일을 검증한 뒤에만 묶음 레코드나 파일을 만든다.
- 이 변경은 기존 레코드, DB 마이그레이션, 파일 형식·소유권 규칙을 바꾸지 않는다.
