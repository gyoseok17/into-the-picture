# M8.1 앨범 지도 부산·양산 좌표 보정 계약

## 범위

- `albumMapCityPositions.ts`의 시각 좌표만 보정한다.
- 부산: `BUSAN` `70,72` → `68,69`
- 양산: `YANGSAN` `70,73` → `69,67`

## 목적

- 6권역 지도 일러스트에서 부산이 남동쪽 섬·해안에 치우쳐 보이는 인상을 줄이고, 양산은 부산의 북쪽 내륙 위치로 분리한다.

## 불변 조건

- SVG, 2:3 반응형 stage, API, 방문 기록 묶음 기준, marker 클릭·선택·확대 동작은 변경하지 않는다.
- 모든 161개 시·군 코드가 계속 하나의 좌표를 가지며, 변경한 두 좌표도 경상권 SVG 도형 안에 있어야 한다.
