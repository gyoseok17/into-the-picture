# M8.1 단일 도메인 Compose 계약

## 서비스 경계

- `frontend`(Caddy)만 호스트의 `80`과 `443`을 공개한다.
- `backend`는 Compose 기본 네트워크에서 `backend:8080`으로만 접근하며 호스트 `ports`를 갖지 않는다.
- Caddy는 `/api/*`를 `backend:8080`으로 프록시하고, 나머지는 정적 프런트 화면을 제공한다.
- Supabase PostgreSQL은 Compose 밖의 외부 서비스다.

## 환경 변수·시크릿

- `backend/.env`만 `env_file`로 백엔드 컨테이너에 주입한다. DB·JWT·외부 API 시크릿은 프런트 이미지·컨테이너로 전달하지 않는다.
- `APP_DOMAIN`은 Compose 변수 보간과 프런트 컨테이너의 Caddy 도메인 설정에만 전달한다.
- `VITE_KAKAO_JS_KEY`는 공개 웹 클라이언트 키이므로 프런트 빌드 인자로만 전달할 수 있다. REST 키·클라이언트 시크릿은 전달하지 않는다.
- Compose에서는 `APP_AUTH_REFRESH_COOKIE_SECURE=true`를 강제한다. HTTP 로컬 Gradle 실행에는 영향을 주지 않는다.

## 영속 볼륨

- `itp-uploads`: 현재 LocalFileStorage의 `/app/uploads`.
- `caddy_data`, `caddy_config`: Caddy TLS 인증서와 설정 보존.
- 업로드의 다중 서버 영속성은 S3/Supabase Storage 후속 범위다.
