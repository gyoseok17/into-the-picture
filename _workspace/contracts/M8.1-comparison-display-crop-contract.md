# M8.1 수상작 비교 표시 구도 계약

## 목적

수상작마다 원본 이미지 비율을 기준으로 비교 사진의 표시 구도를 저장한다. 원본 업로드 파일은 변형하지 않으며, 비교 화면과 공개 갤러리에서만 같은 구도를 적용한다.

## 데이터

비교 기록(`photo_record`, `contest_id`가 있는 행)에 다음 표시 메타데이터를 둔다.

| 필드 | 의미 | 유효 범위 |
| --- | --- | --- |
| `aspectRatio` | 수상작 원본에서 계산한 비교 틀의 가로/세로 비율 | 0.25~4.0 |
| `zoom` | 비교 사진 확대 배율 | 1.0~4.0 |
| `offsetX` | 확대된 사진의 가로 표시 위치(왼쪽 끝 -1, 가운데 0, 오른쪽 끝 1) | -1.0~1.0 |
| `offsetY` | 확대된 사진의 세로 표시 위치(위쪽 끝 -1, 가운데 0, 아래쪽 끝 1) | -1.0~1.0 |

기존 비교 기록은 저장값이 없어도 API에서 `4:3`, `1.0`, `0`, `0` 기본 구도로 응답한다.

프런트는 `offsetX`, `offsetY`를 픽셀 이동량으로 그대로 쓰지 않는다. `zoom`을 적용한 뒤 사진이 비교 틀 밖으로 넘치는 이동 가능 거리 안에서 `-1`은 해당 축의 시작 끝, `0`은 중앙, `1`은 반대 끝을 뜻하도록 변환한다. 확대해도 넘침이 없는 축은 위치값과 무관하게 중앙으로 표시한다. 이 규칙을 목록 썸네일, 중앙 비교판, 공개 갤러리에 동일하게 적용한다.

## API

- `POST /api/v1/me/comparisons`, `PATCH /api/v1/me/comparisons/{comparisonId}`
  - 생성·사진 교체 요청에 선택 `crop`을 받을 수 있다. 없으면 기존 수상작 비율 또는 기본 구도로 처리한다.
- `PATCH /api/v1/me/comparisons/{comparisonId}/crop`
  - 본인 비교 기록만 수정할 수 있다.
  - 본문: `{ "aspectRatio": 1.5, "zoom": 1.2, "offsetX": 0.1, "offsetY": -0.2 }`
- `GET /api/v1/me/comparisons`, 생성·교체·구도 수정 응답
  - `crop`을 포함한다.
- `GET /api/v1/contests/{contestId}/comparisons`
  - 공개 비교 사진을 렌더링하는 데 필요한 `crop`만 추가한다. 소유자·앨범·장소·메모·촬영일은 포함하지 않는다.

## 교체와 공개 규칙

- 비교 사진 교체 시 공개 상태는 유지한다.
- 교체된 사진에는 기존 수상작 비율만 유지하고, 확대·위치는 중앙 기본값으로 초기화한다. 새 사진의 잘라낼 위치는 소유자가 다시 정한다.
- 공개/비공개 및 공개 파일 접근 검사는 기존 서버 경계를 그대로 사용한다.
