# M8.1 Local dotenv configuration contract

## Scope

- Applies only when Spring Boot uses the `local` profile.
- `backend/.env` is an ignored, Java-properties-compatible `KEY=value` file.
- No secret values, token values, or connection values are recorded here.

## Required keys

| Key | Consumer |
| --- | --- |
| `JWT_SECRET` | `app.jwt.secret` |
| `DB_HOST` | local datasource URL |
| `DB_PORT` | local datasource URL |
| `DB_NAME` | local datasource URL |
| `DB_USERNAME` | local datasource username |
| `DB_PASSWORD` | local datasource password |

## Rules

- 이 계약은 후속 단일 설정 전환으로 대체됐다. 현재 `application.yml`이 `backend/.env`를 `.properties` extension hint와 함께 import한다. 상세 계약: `M8.1-single-backend-config.md`.
- Local DB and JWT settings have no YAML fallback values.
- The common and non-local profile configuration does not import `.env` or provide secrets.
- Missing or invalid values fail startup rather than silently selecting a different database or signing key.

## Relocation note (2026-09-07)

- The ignored local backend configuration moved from the previous shared location to `backend/.env` so backend and frontend configuration files are each owned by their module.
- `backend/.env.example` lists the required key names without values. `DB_PORT` and `DB_NAME` remain required even when absent from an existing local file; no replacement values were created.
