# M8 결과 화면 인라인 빠른 조작 계약

## 공통

- 스크롤 보조의 검색·필터 조작 버튼은 아이콘만 표시한다. 접근 가능한 이름은 `aria-label`로 제공한다.
- 아이콘을 누르면 현재 위치에 작은 조작 패널을 열며, 상단으로 이동하지 않는다.
- 위로 가기 아이콘은 별도로 유지한다.
- 패널은 Escape·바깥 클릭으로 닫히고, 모바일 하단 탭과 겹치지 않는다.

## 키워드 사진 검색

- 패널에는 현재 키워드를 초기값으로 한 입력과 적용 동작이 있다.
- 적용은 기존 검색과 동일하게 URL·결과를 변경하고 패널을 닫는다.
- 적용 전후 현재 스크롤 위치는 강제로 상단으로 이동하지 않는다.

## 수상작

- 패널에서 기존 필터 상태를 보고 계절·등급·부문·지역·키워드를 수정하거나 초기화할 수 있다.
- 적용은 기존 필터 변경과 동일한 상태·목록 조회 경로를 사용하고 패널을 닫는다.
- 필터 UI와 변환 규칙을 두 곳에 복제하지 않는다.

## 범위

- API·권한·라우팅 계약과 무한 스크롤 감시 방식은 변경하지 않는다.
