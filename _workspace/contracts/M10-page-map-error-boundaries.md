# M10 상세·지도·전역 오류 경계 계약

## 유지할 사용자 계약

- 수상작 상세: 목록 복귀, 즐겨찾기, 비교 진입·결과 보기, 공개 비교 보기, 혼잡도 표시
- 앨범 지도: 권역/시군 선택, 사진 추가 진입, 마커·대표 기록, 방문 기록, 사진 확대
- 라우트: 기존 URL 및 인증 보호 규칙

## 내부 책임

| 영역 | 분리 기준 |
| --- | --- |
| Contest detail | 페이지 조율, 상세 본문, 목록 복귀 오버레이, 공개/저장 비교 다이얼로그 |
| Album map | 지도 stage·마커, 지역 선택, 선택한 방문 기록, 확대 보기, 순수 marker 계산 |
| Route error | 공통 오류 UI, 다시 시도, 홈 이동. 원래 오류는 개발 로그에 유지 |

## 오류 경계 동작

- 라우트 렌더 예외 시 앱 디자인의 오류 화면을 표시한다.
- 다시 시도는 현재 라우트를 다시 렌더한다.
- 홈 이동은 `/`으로 이동한다.
- HTTP 요청 실패처럼 각 화면이 이미 처리하는 오류 상태를 대체하지 않는다.
