# M8.1 앨범 지도 시·군 마커 좌표 계약

## 목적

앨범 지도는 실제 위경도 투영 지도가 아니라 여섯 권역으로 단순화한 SVG 일러스트다. 따라서 위도·경도를 화면 비율로 환산하지 않고, 사용자가 고른 시·군 코드별로 이 일러스트에 맞춘 정규화 좌표를 사용한다.

## 입력과 출력

- 입력: 기존 `PhotoRecordBundleMapPin.mapRegionCode`, `mapCityCode`, `lat`, `lng`
- 우선순위: `mapCityCode`가 있으면 `mapCityCode -> { left, top }` 좌표표를 사용한다.
- 출력: SVG 컨테이너 기준 백분율 좌표 (`left`, `top`, 0~100)
- 기존에 저장된 장소 미선택/구형 기록은 `lat`, `lng`의 제한된 fallback 좌표로만 표시한다.

## 범위와 불변 조건

- `koreaRegions`에서 선택 가능한 모든 시·군 코드에 좌표를 둔다.
- 서버 API, DB 값, 기존 지역 필터 및 동일 시·군의 마커 묶음 식별자는 변경하지 않는다.
- 같은 시·군의 여러 방문 기록은 기존처럼 하나의 마커 그룹으로 유지한다.
- 좌표표는 지도 컴포넌트와 분리된 프런트 라이브러리에 두어 SVG 교체 시 그 파일만 보정할 수 있게 한다.

## 검증

- 좌표표 키 집합이 `koreaRegions`의 모든 시·군 코드와 일치하는지 개발 시 검증한다.
- `npm run build`, `git diff --check`를 실행한다.
