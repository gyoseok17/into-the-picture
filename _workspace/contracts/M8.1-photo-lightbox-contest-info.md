# M8.1 사진 확대 수상작 정보 계약

## 목적

앨범 스토리·지도에서 수상작과 비교한 사진을 확대할 때, 사진 위를 가리던 수상작 썸네일 대신 사진 아래에 비교 정보를 표시한다.

## UI 계약

- 비교 연결 사진의 확대 보기에는 사진 아래에 트로피, 첫 연결 수상작 제목, `location` 값과 `비교 보기` 버튼을 표시한다.
- 연결이 여러 건이면 첫 수상작을 대표로 보이고, 버튼에 연결 건수를 함께 알려 준다. 비교 결과 창 안에서는 기존처럼 다른 비교를 선택할 수 있다.
- `비교 보기`는 현재 확대 보기 위에 기존 인라인 비교 결과 창을 열며, 경로 이동·API·DB 변경은 없다.
- 비교 연결이 없는 사진에는 이 영역을 렌더링하지 않는다.

## 레이어와 접근성

- 비교 결과 창은 사진 확대 창보다 위 레이어에서 열리고, 닫으면 비교 보기 버튼으로 초점을 복귀한다.
- Escape는 최상위 비교 결과 창만 먼저 닫고, 사진 확대 창은 유지한다.
