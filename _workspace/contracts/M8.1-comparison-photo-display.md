# M8.1 수상작 비교 내 사진 표기 계약

## 목적

수상작 비교 화면에서 기기 파일명이 아닌 여행 맥락으로 내 사진을 식별한다.

## 공통 표기 규칙

- 제목은 `placeName`을 우선 사용한다.
- 장소가 없으면 `takenAt`의 날짜를 사용한다.
- 장소와 촬영일이 모두 없으면 `내 사진`을 사용한다.
- 제목이 장소인 경우에만 촬영일을 보조 정보로 표시한다.
- 메모는 비교 화면의 제목·보조 정보에 포함하지 않는다.

## 적용 범위와 제외

- 적용: 수상작 비교 생성·앨범 사진 선택·결과 목록·결과 비교판과 비교 결과 창.
- 제외: 이미지 `alt`, 원본 파일명 저장·API·DB, 일반 앨범·사진 기록 UI.
- URL과 비교 도메인 내부 식별자는 바꾸지 않는다.
