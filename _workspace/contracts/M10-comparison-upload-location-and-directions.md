# M10 비교 새 사진 위치와 길찾기 계약

## 비교 새 사진

- 수상작 비교에서 새 사진을 추가할 때 프런트는 해당 수상작의 `mapRegionCode`, `mapCityCode`를 업로드 요청에 함께 보낸다.
- 업로드가 성공한 사진 기록과 묶음은 전달받은 표준 지역 코드를 저장한다. 기존 앨범 사진 선택과 수상작 비교 생성 API 계약은 바꾸지 않는다.
- 지역 후보가 0건인 앨범 선택기에서 `사진 추가`를 누르면, 선택기를 다시 열지 않고 같은 수상작 위치가 미리 선택된 업로드 화면으로 직접 전환한다.

## 길찾기

- 수상작 상세의 길찾기 목적지는 작품 제목이 아니라 수상작 DB의 실제 장소 문자열을 사용한다.
- 실제 장소 문자열이 비어 있으면 길찾기 링크를 노출하지 않는다. 좌표가 있다고 해서 임의의 장소명을 생성하지 않는다.

## 검증

- 새 사진 업로드 뒤 앨범 DTO의 지역 코드와 수상작 대상 코드가 일치한다.
- 빈 후보 → 사진 추가는 반복 빈 상태 없이 업로드 화면으로 이동한다.
- 장소가 있는 수상작의 카카오 길찾기 URL에 그 장소가 인코딩되어 포함되고, 장소가 없으면 버튼은 없다.
