# M8.3 선택형 사진 저장소 계약

## 선택 규칙

| 환경값 | 구현체 | 기본값 |
| --- | --- | --- |
| `APP_STORAGE_TYPE=local` 또는 미설정 | `LocalFileStorage` | 예 |
| `APP_STORAGE_TYPE=s3` | `S3FileStorage` | 아니오 |

S3를 선택하면 `AWS_REGION`, `APP_STORAGE_S3_BUCKET`이 필수다. AWS SDK 기본 자격 증명 체인을 사용한다. 로컬에서는 사용자의 AWS CLI/SSO 자격 증명, EC2에서는 IAM 역할 임시 자격 증명을 사용하며 장기 키를 프로젝트 환경 파일에 추가하지 않는다.

## 불변 계약

- 저장 키: `u/{userId}/{uuid}.{extension}`
- 업로드·조회·삭제 서비스와 API DTO는 변경하지 않는다.
- S3 버킷은 비공개다. 사진 조회는 기존 백엔드 권한 검사 경로를 유지하며 S3 URL을 브라우저에 직접 노출하지 않는다.
- 저장 실패 시 DB 레코드를 만들지 않으며, DB 저장 실패 뒤에는 이미 저장된 객체를 삭제하려 시도한다.

## 필요한 S3 객체 권한

`u/*` 접두어에 `s3:PutObject`, `s3:GetObject`, `s3:DeleteObject`만 필요하다. 목록 조회, 버킷 설정 변경, 공개 ACL은 사용하지 않는다.
