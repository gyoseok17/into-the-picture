# M8 수상작 상세 오버레이 라우팅 계약

## 목록 진입

- 수상작 목록 카드에서 작품을 열면 목록 화면은 언마운트하지 않고, 상세를 그 위의 오버레이로 표시한다.
- 주소는 `/contests/:id`를 유지해 새로고침·공유가 가능해야 한다.
- 브라우저·기기 뒤로가기는 상세 오버레이만 닫고 기존 목록의 스크롤·필터·무한 목록 상태를 그대로 보인다.

## 독립 상세

- 주소 직접 진입과 홈·혼잡도·마이·즐겨찾기 등 목록 외 진입은 기존 독립 상세 화면을 사용한다.
- 독립 상세의 목록 복귀는 `/contests`로 안전하게 이동한다.

## 접근성·표면

- 오버레이는 배경 스크롤을 잠그고, 닫기·Escape·뒤로가기 후 원래 카드 또는 목록 조작부로 포커스를 복귀한다.
- 목록을 덮는 상세는 팝업 창이 아니라 일반 페이지 표면으로 보인다. 어두운 배경·둥근 외곽·그림자·배경 클릭 닫기는 사용하지 않는다.
- 데스크톱에서는 상단 내비게이션 아래, 모바일에서는 하단 탭 위에 표시하며 상세 안의 지도·즐겨찾기·로그인 흐름은 기존과 동일하다.
