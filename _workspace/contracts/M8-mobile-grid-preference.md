# M8 모바일 사진 열 수 설정 계약

## 대상

- 수상작 목록 `/contests`
- 키워드 사진 검색 `/explore`

## 동작

- 모바일 너비에서 사진 결과의 표시 열 수를 `1`, `2`, `3` 중 선택한다.
- 기본값은 `2`다.
- 두 화면은 하나의 사용자 설정값을 공유한다.
- 선택값은 브라우저 `localStorage`에 보관해 새로고침 뒤에도 유지한다.
- 저장소를 읽거나 쓸 수 없으면 `2`열로 안전하게 동작한다.
- 데스크톱의 기존 열 수와 API·URL 쿼리·무한 스크롤 계약은 바꾸지 않는다.

## 접근성

- 1열/2열/3열 전환은 현재 선택 상태를 전달하는 실제 버튼으로 제공한다.
- 키보드 포커스와 충분한 클릭 영역을 유지한다.
