# M8.1 지도 사진 확대 보기 계약

## 사용자 흐름

1. 지도 마커를 누르면 기존 방문 기록 패널(`MapFocus`)을 연다.
2. 패널의 현재 큰 사진을 누르면 전체 화면 사진 보기(라이트박스)를 연다.
3. 라이트박스는 해당 방문 기록 묶음의 사진만 대상으로 하며, 이전·다음과 썸네일로 사진을 바꿀 수 있다.
4. 닫기, 배경 누르기, Escape는 라이트박스만 닫고 지도 마커·방문 기록 패널·선택한 사진 위치는 그대로 복귀한다.

## 범위와 비범위

- 지도 사진 보기와 스토리의 사진 묶음 보기는 같은 표시 수준(큰 사진, 여러 사진 탐색, 비교 연결 표시)을 제공한다.
- 대표 기록 설정, 이전 방문 기록 선택, 비교 결과 연결은 기존 동작을 바꾸지 않는다.
- 원본 파일, 사진 묶음 데이터, 지도 위치, API·DB 계약은 바꾸지 않는다.

## 접근성과 레이어

- 라이트박스는 `role="dialog"`, `aria-modal`을 갖고 화면 전체를 덮는다.
- 모바일·PC 모두 지도 패널과 하단 내비게이션보다 위 레이어에 표시하며, 배경 클릭은 지도 클릭으로 전파되지 않는다.
- Escape와 닫기는 라이트박스 하나만 처리한다. 지도 방문 기록 패널은 유지된다.

## 검증 경계

- 한 장/여러 장 사진, 썸네일 선택, 이전·다음 순환을 확인한다.
- 이전 방문 기록에서 다른 기록을 선택한 뒤 확대했을 때 그 기록의 사진만 보이는지 확인한다.
- 비교 연결 사진의 배지·링크가 유지되고, 확대 보기 뒤 지도 포커스가 초기화되지 않는지 확인한다.
