# M8.1 공통 사진 추가 패널 UI 계약

## 목적

스토리, 지도, 보관함에서 사진을 추가할 때 동일한 입력 흐름을 사용한다. 사진 묶음은 촬영일과 장소를 함께 기록하며, 장소는 저장 전 필수로 선택한다.

## 입력과 상태

- 공통 패널의 입력은 사진(1~3장, 파일당 10MB 이하, 요청 전체 32MB 이하), 촬영일/선택 종료일, 장소(권역+시·군), 선택 메모다.
- 사진 정보(EXIF)에서 촬영일을 읽지 못한 사진이 있으면 공통 촬영일은 필수다.
- 장소는 모든 경우 필수다. `mapRegionCode`와 `mapCityCode`가 모두 있어야 저장 버튼이 활성화된다.
- 장소 선택은 패널 위의 오버레이에서 수행한다. 선택 또는 닫기 뒤에는 원래 패널과 스크롤 위치를 유지한다.

## 진입 규칙

| 진입 화면 | 초기 장소 | 완료 뒤 |
| --- | --- | --- |
| 스토리 | 없음, 장소 선택 필요 | 패널을 닫고 스토리 유지 |
| 보관함 | 없음, 장소 선택 필요 | 패널을 닫고 보관함 유지 |
| 지도 | 사용자가 선택한 시·군 | 같은 패널을 열고 선택값 표시; 패널을 닫고 지도 유지 |

## API 경계

- 기존 `uploadPhotoRecordBundle` 계약을 재사용한다.
- `mapRegionCode`, `mapCityCode`를 기존 multipart 필드로 전달한다. API 형식은 바꾸지 않는다.
- 업로드 완료 시 기존 사진 기록/묶음/지도 관련 쿼리를 무효화한다.

## 오류·접근성

- 장소 또는 필수 촬영일이 비어 있으면 저장 버튼은 비활성화하고 필요한 이유를 안내한다.
- 업로드 실패 시 선택 사진과 입력값을 유지해 재시도할 수 있다.
- 장소 선택 오버레이는 dialog 역할, 닫기 동작 및 버튼 레이블을 제공한다.

## 현재 업로드 정책 정정 (2026-09-12)

통합 추가 패널은 한 번에 사진 1~3장을 하나의 방문 묶음으로 전송한다. 파일당 10MB, multipart 요청 전체 32MB를 적용하며, 20장 선택 후 동시 전송 UI는 현재 계약 범위가 아니다.
