# M8.1 백엔드 단일 환경설정 계약

## 결정

- 백엔드 설정 파일은 `backend/src/main/resources/application.yml` 하나만 사용한다.
- `application-local.yml`은 사용하거나 배포하지 않는다.
- `application.yml`은 `backend` 모듈 작업 디렉터리 기준 `file:.env[.properties]`를 필수 import한다.

## 환경변수 계약

| 키 | 소비 위치 |
| --- | --- |
| `DB_HOST`, `DB_PORT`, `DB_NAME` | Supabase PostgreSQL JDBC URL |
| `DB_USERNAME`, `DB_PASSWORD` | datasource 인증 |
| `JWT_SECRET` | JWT HMAC 서명 |

- 로컬에서는 Git 제외 파일 `backend/.env`에 값을 둔다.
- 배포에서는 동일 키를 배포 시크릿/환경변수로 제공한다.
- YAML에 비밀값·DB 기본 접속값·공개 JWT fallback을 두지 않는다.
