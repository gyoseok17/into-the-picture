# M8.1 사진별 촬영일 출처 API 형태

## POST /api/v1/me/photos/bundles

기존 `files`, `takenAt`, `endedAt`에 반복 multipart 문자열 `manualTakenAts`를 추가한다.

```text
files: [a.jpg, b.heic, c.png]
manualTakenAts: ["", "2026-08-29", "2026-08-30T14:25:00"]
takenAt: "2026-08-29T00:00:00"
endedAt: "2026-08-31T00:00:00"
```

각 파일은 서버 EXIF를 먼저 사용하고, EXIF가 없을 때만 같은 위치의 수동값, 그마저 없을 때만 `takenAt`을 사용한다.

- 수동값 배열 수가 파일 수와 다름: `400 INVALID_REQUEST`
- 수동값 형식 오류: `400 INVALID_REQUEST`
- EXIF·수동값·묶음 시작일이 모두 없음: `400 INVALID_REQUEST`

## 응답

사진 DTO의 `takenAtSource` 필드를 추가한다.

```json
{
  "takenAt": "2026-08-29T00:00:00",
  "takenAtSource": "EXIF"
}
```

값은 `EXIF`, `MANUAL`, `BUNDLE_DEFAULT`이며, 기존 사진은 `null`일 수 있다. 묶음과 지도 응답의 `takenAt`/`endedAt`은 여행 기간을 계속 뜻한다.
