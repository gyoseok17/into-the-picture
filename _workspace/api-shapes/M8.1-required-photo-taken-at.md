# M8.1 사진 촬영일 필수 저장 API 형태

## `POST /api/v1/me/photos`

- `takenAt`이 있으면 저장한다.
- 없으면 서버 EXIF `DateTimeOriginal`/`DateTime`을 읽어 저장한다.
- 둘 다 없으면 `400 INVALID_REQUEST`:

```json
{ "code": "INVALID_REQUEST", "message": "촬영일을 확인할 수 없습니다. 촬영일을 직접 지정해 주세요." }
```

## `POST /api/v1/me/photos/bundles`

- 공통 `takenAt`이 있으면 모든 `files`에 해당 값을 쓴다.
- 공통값이 없으면 각 파일의 서버 EXIF를 읽는다.
- 파일 하나라도 촬영일을 확정할 수 없으면 `400 INVALID_REQUEST`이며 bundle·사진·파일은 만들지 않는다.
