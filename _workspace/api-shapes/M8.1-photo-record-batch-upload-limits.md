# M8.1 사진 기록 묶음 업로드 크기 형태

`POST /api/v1/me/photos/bundles`의 `files` multipart part는 1~3개다.

| 항목 | 한도 | 적용 지점 |
| --- | --- | --- |
| 파일 개수 | 1~3 | `PhotoRecordBundleService` |
| 파일 하나 크기 | 10MB | Spring multipart + `ImageUploadValidator` |
| 요청 전체 크기 | 32MB | `spring.servlet.multipart.max-request-size` |

성공 시 기존과 동일하게 `201 Created`와 `PhotoRecordBundleDto`를 반환한다. DTO 필드 추가·삭제는 없다.
