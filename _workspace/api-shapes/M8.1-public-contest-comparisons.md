# M8.1 public comparison API shapes

| Route | Auth | Result |
| --- | --- | --- |
| `PATCH /me/comparisons/{id}/visibility` | owner | existing comparison DTO + `visibility` |
| `GET /contests/{contestId}/comparisons` | public | `[{ id, photoUrl, createdAt }]` only; `photoUrl` begins `/api/v1/` |
| `GET /contests/{contestId}/comparisons/{id}/file` | public | image bytes only when public and active |

The public DTO intentionally omits `UserPhotoDto`; that type contains private photo-record metadata and authenticated `/me/photos/{id}/file` URLs.
