# M8.1 사진 묶음 기간 API 형태

## 업로드

`POST /api/v1/me/photos/bundles`의 multipart 요청에 아래 선택 필드를 추가한다.

| 필드 | 형식 | 의미 |
| --- | --- | --- |
| `takenAt` | ISO local datetime | 묶음 시작일 |
| `endedAt` | ISO local datetime | 묶음 종료일, 선택값 |

날짜 선택 UI는 날짜만 고르더라도 자정으로 변환해 `2026-08-31T00:00:00` 형식으로 보낸다.

- `endedAt`만 보내면 `400 INVALID_REQUEST`
- `endedAt < takenAt`이면 `400 INVALID_REQUEST`
- `endedAt == takenAt`은 허용

## 묶음 응답

`GET /api/v1/me/photos/bundles`와 묶음 업로드 응답의 각 항목에 `endedAt`을 추가한다.

```json
{
  "id": 42,
  "legacy": false,
  "takenAt": "2026-08-30T00:00:00",
  "endedAt": "2026-08-31T00:00:00",
  "photos": []
}
```

기존 묶음과 레거시 단일 사진의 `endedAt`은 `null`이다. 지도 API의 핀에도 표시용 `endedAt`이 추가되지만, 위치·대표 사진·정렬과 사진 하위 항목의 `takenAt` 기준은 바뀌지 않는다.
