## GET /api/v1/contests/map

### 요청
- 쿼리 파라미터(모두 선택, 목록과 동일): `season` `grade` `division` `sido` `keyword`
  - season·grade·division·sido = 정확일치, keyword = title/location/keywordsRaw 부분일치(대소문자 무시)
  - 필터 로직은 목록(`GET /contests`)과 **동일 Specification 재사용** — 같은 조건이면 목록·지도 결과 집합 일치(단 지도는 좌표 없는 건 제외)
- **`sort`/`page`/`size` 없음** (지원 안 함, 넘겨도 무시)

### 응답 200 (배열 직접, 페이지네이션 래핑 없음)
```jsonc
[
  {
    "id": 12,
    "title": "가야산 설경",
    "thumbUrl": "https://x/thumb.jpg",  // http→https 치환됨
    "lat": 35.8043935,                   // number, non-null 보장
    "lng": 128.1083354,                  // number, non-null 보장
    "awardGrade": "입선",
    "sido": "경상남도"                    // string | null (미파싱 시 null)
  }
]
```
- **lat·lng 둘 다 non-null 인 작품만 포함** — Specification 에 `isNotNull(lat) AND isNotNull(lng)` 조건 추가(DB 레벨 필터). 응답의 lat/lng 는 항상 값 존재(primitive double).
- 데이터 없으면 `[]`.
- sido 는 record 필드 그대로 직렬화 — 파싱 안 된 경우 `null`.

### 프론트 TS 타입 (계약과 일치)
```ts
type ContestMapPin = {
  id: number;
  title: string;
  thumbUrl: string;
  lat: number;

  awardGrade: string;
  sido: string | null;
};
// 응답: ContestMapPin[]
```
