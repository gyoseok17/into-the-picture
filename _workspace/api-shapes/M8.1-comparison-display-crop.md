# 비교 표시 구도 API 형태

```json
{
  "id": 10,
  "userPhoto": { "id": 7, "url": "/api/v1/me/photos/7/file" },
  "contest": { "id": 94, "title": "..." },
  "displayMode": "WITH_CONTEST",
  "visibility": "PUBLIC",
  "crop": {
    "aspectRatio": 1.5,
    "zoom": 1.2,
    "offsetX": 0.1,
    "offsetY": -0.2
  },
  "createdAt": "2026-09-13T12:00:00"
}
```

공개 목록 요소는 아래처럼 개인 기록 필드 없이 사진 URL·식별자·생성 시각·표시 구도만 반환한다.

```json
{
  "id": 10,
  "photoUrl": "/api/v1/contests/94/comparisons/10/file",
  "crop": {
    "aspectRatio": 1.5,
    "zoom": 1.2,
    "offsetX": 0.1,
    "offsetY": -0.2
  },
  "createdAt": "2026-09-13T12:00:00"
}
```
