# M8.1 저장 수상작 사진 놓기 API 형태

## POST /api/v1/me/comparisons

요청 본문은 기존과 같다.

```json
{ "userPhotoId": 51, "contestId": 94 }
```

서버는 `userPhotoId`가 현재 사용자의 `PhotoRecord`인지 확인하고, `contestId` 즐겨찾기 여부와 사용자·수상작 중복 비교 기록 여부를 확인한다.

| 상황 | 응답 |
| --- | --- |
| 즐겨찾기하지 않은 수상작 | `403 FORBIDDEN` |
| 동일 수상작의 기존 기록 존재 | `409 CONFLICT` |
| 정상 | 기존 `ComparisonDto` |

기존 기록은 자동 교체·삭제하지 않는다. 클라이언트는 409 시 기존 기록 수정 흐름으로 안내한다.
