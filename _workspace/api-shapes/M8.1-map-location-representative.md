# M8.1 지도 위치 대표 기록 API 형태

## PUT `/api/v1/me/photos/map/representative`

Request:

```json
{ "photoRecordId": 301 }
```

Response: `204 No Content`.

The server resolves the location from the owned, active photo record. It accepts only `CITY:{region}:{city}` or `PLACE:{latitude-3dp}:{longitude-3dp}` locations; an unlocated or archived record returns `400`, and another user's/missing record returns `404`.

## GET `/api/v1/me/photos/bundles/map`

Every existing visit-record item adds:

```json
{ "representative": true }
```

`representative` is true for the explicitly selected record at its location. If none is selected, it is true for the first server-sorted visit record at that location. A selected photo deletion clears the database reference with `ON DELETE SET NULL`, so the next GET returns the fallback representative without deleting other records.
