# `GET /api/v1/me/photos/map-locations` 응답 형태

```json
[
  {
    "code": "JEOLLA",
    "label": "전라",
    "cities": [
      {
        "code": "JEONJU",
        "label": "전주",
        "latitude": 35.8242,
        "longitude": 127.148
      }
    ]
  }
]
```

`latitude`와 `longitude`는 해당 시·군의 앨범 지도 기본 마커 좌표다. 사진에 실제 장소 좌표가 있으면 그 좌표가 우선한다.
