# M8.1 수상작 공개 비교 목록 조사 - API 형태

## 공개 목록

`GET /api/v1/contests/{contestId}/comparisons`

- 인증 없이 호출 가능하다.
- 응답: `200 OK`와 `PublicComparisonDto[]`
- 항목: `{ id, photoUrl, createdAt }`
- `photoUrl`: `/api/v1/contests/{contestId}/comparisons/{comparisonId}/file`

## 서버 조회 조건

`PhotoRecordRepository.findAllByContestIdAndComparisonVisibilityAndArchivedAtIsNullOrderByContestLinkedAtDesc`로 다음을 모두 만족하는 기록만 반환한다.

1. 요청한 `contestId`와 연결됨
2. `comparisonVisibility = PUBLIC`
3. `archivedAt is null`

파일 조회도 같은 수상작 ID·`PUBLIC`·활성 기록 조건을 다시 확인한 뒤에만 파일 저장소를 읽는다.

## 조사 결과

- 로컬 서버에 `GET http://localhost:8080/api/v1/contests/94/comparisons`를 호출해 `200 []`를 확인했다. 따라서 라우팅·보안 차단이 아니라 해당 조건을 만족하는 공개 비교가 현재 없다는 의미다.
- 프런트 갤러리는 로그인 사용자의 `ownComparisonId`를 의도적으로 제외한다. 따라서 같은 계정에서 직접 만든 공개 비교는 수상작 상세의 “다른 사람이 비교한 사진” 목록에 표시되지 않는다.
- 다른 계정의 활성 `PUBLIC` 비교가 있어야 같은 목록에 표시된다. 로그아웃 상태에서는 본인 제외 값이 없으므로 공개 비교 전체가 표시된다.
