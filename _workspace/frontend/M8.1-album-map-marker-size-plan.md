# M8.1 앨범 지도 마커 시각 크기 조정 — 작업 계획

- 날짜: 2026-09-08
- 담당: 프런트엔드
- 대상: `frontend/src/features/photo-record/components/PhotoRecordMapView.tsx`

## 목표

- 앨범 지도 위 방문 기록 마커의 보이는 원을 줄여, 지도·인접 시군 좌표를 덜 가리게 한다.

## 변경 경계

- API, 좌표 카탈로그, 마커 그룹화/숫자 기준, 선택·확대 상태는 바꾸지 않는다.
- 버튼의 실제 누름 영역은 기존 `36px`을 유지하고, 내부에 그려지는 원·아이콘 또는 숫자만 줄인다.

## 검증

1. 선택 전/후 마커의 배경 원과 테두리가 축소되며, 선택 ring과 hover 확대는 유지되는지 코드로 확인한다.
2. 숫자 묶음과 단일 위치 아이콘이 동일한 터치 영역에서 동작하는지 확인한다.
3. `npx tsc -p tsconfig.app.json --noEmit`, `npx vite build`, `git diff --check`를 실행한다.

## 위험과 대응

- 버튼까지 함께 축소하면 모바일 터치가 불편해질 수 있으므로 외부 button 크기는 보존한다.
- 선택 상태의 ring이 과도하게 커지지 않도록 내부 visual에만 상태 색상·확대 효과를 적용한다.
