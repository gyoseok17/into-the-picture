# M8.1 비교 공개 관리 - 프런트엔드 보고

## 변경 범위

- `ComparisonManagementPage`와 `ComparisonVisibilityManager`를 추가했다.
- 마이의 기존 `내 앨범` 진입 항목을 `공개 관리`로 바꾸고 `/me/comparisons`로 연결했다.
- 하단 탭의 `/me/album`은 변경하지 않았다.
- 비교 결과 상세의 공개/비공개 전환과 관련 오류 경로를 제거했다.

## 설계 결정

- 항목 행마다 독립적인 mutation hook을 사용해 한 사진의 상태를 바꾸는 동안에도 다른 사진의 공개 여부를 계속 바꿀 수 있게 했다.
- 기존 비교 조회와 공개 상태 변경 API·React Query 무효화 정책을 재사용해 API 계약을 추가하지 않았다.
- 관리 화면은 공유 결정을 위한 최소 정보(내 사진, 수상작명, 현재 상태)만 보이며 앨범 메타데이터는 표시하지 않는다.

## 검증

- `npm run typecheck` 통과
- `npm run build` 통과 (기존 500kB 청크 권고만 남음)
- `git diff --check` 통과

## 남은 확인

- QA에서 공개/비공개 전환 성공·실패, 긴 수상작명, 모바일 폭의 실제 브라우저 확인이 필요하다.
