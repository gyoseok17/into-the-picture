# M8.1 앨범 지도 마커 시각 크기 조정 — 프런트엔드 결과

- 날짜: 2026-09-08
- 담당: 프런트엔드
- 변경 파일: `frontend/src/features/photo-record/components/PhotoRecordMapView.tsx`

## 변경 범위와 결정

- 각 지도 마커를 **36px 클릭 버튼**과 **24px 표시 원**으로 분리했다.
- 버튼: 기존과 동일한 `h-9 w-9`(36px). 마커를 누르는 영역과 포커스 링은 줄이지 않았다.
- 표시 원: 기존 버튼 자체의 `h-9 min-w-9`(36px)에서 내부 `h-6 min-w-6`(24px)으로 축소했다.
- 단일 위치 아이콘: `h-4 w-4`(16px)에서 `h-3 w-3`(12px)으로 축소했다.
- 숫자: `text-xs`에서 `text-[10px]`으로 축소했다.
- 선택 상태: 표시 원의 `ring-4`를 `ring-2`로 줄였다. 선택/hover 확대는 표시 원에만 적용한다.

## 유지한 동작

- `groupPins`의 같은 시·군 묶음 기준, 숫자 기준, 선택·확대 상태, 좌표 카탈로그 및 API는 변경하지 않았다.
- 단일·다중 방문 기록 모두 같은 36px 누름 영역으로 클릭된다.
- 키보드 focus-visible ring은 외부 버튼에 남겨 접근성을 유지한다.

## 검증

- 코드 검토: button의 36px 영역과 내부 24px 원이 분리되어, 시각 크기 축소가 터치 영역·클러스터 묶음에 영향을 주지 않음을 확인했다.
- `npx tsc -p tsconfig.app.json --noEmit`: 34초 동안 종료되지 않아 실행 환경 시간 제한으로 중단됐다. 오류 출력은 없었다.
- `npx vite build`: 타입 검사와 이어 실행했으나 64초 제한 안에 종료되지 않아 중단됐다. 오류 출력은 없었다.
- `git diff --check`: 같은 작업 환경에서 10초 제한을 넘겨 결과를 확정하지 못했다.

## 남은 위험·후속 확인

- 실제 360px 모바일 및 데스크톱에서 단일 마커·두 자리 숫자 마커를 각각 눌러, 작아진 24px 표시 원 주변의 36px 클릭 영역이 충분한지 수동 확인이 필요하다.
- CI 또는 유휴 로컬 환경에서 타입 검사·프로덕션 번들·diff check를 다시 실행해 최종 게이트를 통과시켜야 한다.
