# M8.1 수상작 비교 명칭·확대 원본 사진 트리거 프런트엔드 결과

## 변경 범위

- `ComparePage`, 수상작 상세·마이 진입 버튼, 앨범 선택창, 자르기·결과 창, 접근성 문구의 사용자 표시를 `수상작 비교`로 통일했다.
- `/compare` URL, 컴포넌트명, 훅·타입 등 내부 계약은 변경하지 않았다.
- 사진 확대 정보 영역의 텍스트 `비교 보기` 버튼을 수상작 원본 썸네일 버튼으로 바꿨다.

## 설계 결정

- 원본 썸네일은 고정 48px 버튼으로 두고 제목·지역은 남은 영역에서 말줄임 처리해 좁은 화면에서도 사진을 가리지 않는다.
- 연결 비교가 여러 건이면 대표 수상작 원본에 건수 배지를 표시한다. 클릭 뒤 열리는 기존 인라인 결과 창에서 다른 수상작을 선택할 수 있다.
- 원본 썸네일은 제목과 행동을 포함한 접근성 이름을 갖고, 기존 초점 복귀 흐름을 그대로 사용한다.

## 검증

- `npm run typecheck` 통과
- `npm run build` 통과 (기존 500KB 번들 경고만 존재)
- `git diff --check` 통과
