# 수상작 상세 오버레이 하단 경계 구현 보고

## 변경 범위

- `frontend/src/features/contest/pages/ContestDetailPage.tsx`의 목록 진입 상세 오버레이만 수정했다.

## 설계 결정

- 오버레이의 모바일 하단 경계를 기존 고정 탭 높이에서 화면 끝으로 변경했다.
- 하단 탭은 기존 `z-40`을 유지하므로 계속 노출·조작 가능하지만, 탭 뒤에는 오버레이의 불투명 배경이 있어 목록이 비치지 않는다.
- 상세 내용의 하단 여백은 `6rem + safe-area-inset-bottom`으로 확보해 탭과 홈 인디케이터에 마지막 내용이 가려지지 않도록 했다.

## 영향과 위험

- API·라우트·상태 계약은 변경하지 않았다.
- 일반 상세 직접 진입은 오버레이를 사용하지 않아 영향이 없다.
- 모바일 및 데스크톱 반응형 경계에서 같은 전체 높이 덮기 규칙을 사용한다.
