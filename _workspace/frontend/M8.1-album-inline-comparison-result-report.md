# M8.1 앨범 내부 비교 결과 보기 프런트 결과

## 변경 범위

- `PhotoComparisonLinks`의 수상작 항목을 경로 이동 링크에서 앨범 내부 결과 보기 버튼으로 변경했다.
- `PhotoComparisonOverlay`의 우측 하단 수상작 원본 미리보기도 같은 결과 보기 창을 연다.
- `PhotoComparisonResultDialog`를 추가해 기존 `ComparisonPlacementPair`로 수상작·내 사진 비교판을 재사용했다.

## 설계 결정

- 비교 저장·수정 기능은 기존 `/compare`의 책임으로 유지하고, 앨범에서는 저장된 결과를 확인하는 읽기 전용 창만 제공한다.
- 다중 비교는 창 안의 수상작 썸네일 선택으로 전환한다.
- 결과 창은 사진 확대 창보다 높은 `z-[100]`으로 포털 렌더링한다. Escape는 capture 단계에서 소비해 하위 사진 확대 창을 유지하며, 닫은 뒤 열기 버튼으로 초점을 돌린다.

## 검증

- `npm run typecheck` 통과
- `npm run build` 통과 (기존 Vite 청크 크기 경고만 발생)
- `git diff --check` 통과 (기존 줄바꿈 경고만 발생)

## 영향 및 남은 위험

- API·DB·라우트 계약 변경 없음.
- 브라우저 실제 동작 확인 시 스토리·지도 각각에서 결과 창 닫은 뒤 기존 사진 확대 창과 선택 위치가 유지되는지 확인이 필요하다.
