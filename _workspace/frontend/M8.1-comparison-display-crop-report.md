# M8.1 수상작 비율 기반 비교 화면 결과

## 구현 범위

- 수상작 원본 이미지를 읽어 비교 틀 비율을 결정하는 편집기를 추가했다.
- 비교용 사진은 드래그와 확대를 통해 보이는 위치를 정하고, 원본 파일을 바꾸지 않은 채 비교별 `crop` 값만 저장한다.
- 새 비교 생성, 비교 사진 교체, 앨범에서 기존 사진을 골라 비교하는 흐름에 같은 편집기를 연결했다.
- 수상작 상세 공개 비교창은 원본·선택 사진 비교판을 유지하고, 공개 사진 선택 목록만 최대 높이 안에서 독립 스크롤한다.

## 표시 규칙

- `aspectRatio`, `zoom`, `offsetX`, `offsetY`를 모든 비교 화면에서 같은 계산으로 적용한다.
- 공개 사진 목록은 선택한 사진만 크게 렌더링하므로 사진 수가 늘어도 비교판의 높이와 위치가 늘어나지 않는다.
- 기존 비교의 `crop`이 없으면 4:3·1배율·중앙을 사용한다.

## 검증

- `npm run typecheck` 통과.
- `npm run build` 통과. Vite 청크 크기 권고만 기존 비차단 항목이다.
- `git diff --check` 통과.
