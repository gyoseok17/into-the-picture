## Design decision

- A management list must preserve the visual basis for a publishing decision. A thumbnail alone made it hard to understand which award image each personal photo was paired with.
- The common exhibit has a one-column narrow layout and two columns at the existing medium breakpoint. The management consumer disables duplicate personal metadata; it does not change what is stored or exposed publicly.

## Public image URL correction

- The public comparison file API returns root-relative `/api/v1/...` paths.
- `resolvePublicComparisonImageUrl` now joins those paths to the origin when `VITE_API_BASE` is an absolute URL containing `/api/v1`; this prevents `.../api/v1/api/v1/...` URLs in deployed environments. Local relative `/api/v1` development behavior is unchanged.
