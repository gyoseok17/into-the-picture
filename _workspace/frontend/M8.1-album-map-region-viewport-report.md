# M8.1 앨범 지도 권역 중심 확대 프런트엔드 보고

## 변경 범위

- `albumMapRegionViewport.ts`를 추가해 여섯 권역의 SVG artwork 경계, padding 기반 scale, clamped transform을 한 곳에서 관리한다.
- `PhotoRecordMapView`는 권역 선택 시 helper viewport를 적용하고, 도시 선택은 같은 권역 frame을 유지한다.
- 선택 마커는 기존 1.38배 focus viewport를 유지해 권역 확대보다 우선하며, 닫으면 권역 frame으로 자연스럽게 복귀한다.

## 설계 결정

- 마커와 SVG가 동일한 stage transform을 공유하므로 확대·이동 중에도 marker 좌표가 어긋나지 않는다.
- 권역 bounds는 marker 위치의 합집합이 아니라 그려진 SVG path 전체 기준이다. 전라·경상의 분리 도서도 frame에서 사라지지 않는다.
- 같은 권역 재선택 및 빈 지도 클릭은 기존 `clearSelection` 경로를 재사용해 전체 지도 복귀 동작을 하나로 유지한다.

## 검증

- `npx tsc -p tsconfig.app.json --noEmit` 통과
- `npx vite build` 통과
- Vite 500 kB chunk 경고만 기존과 동일하게 남음

## Transform 원점 보정

- stage에 `transformOrigin: '0 0'`을 명시했다. 기존 translate 식은 좌상단 원점을 전제로 한 식이므로 CSS 기본 중앙 원점에 맡기면 권역·마커 중심이 달라질 수 있었다.
- 동일한 원점과 transform helper를 권역 framing 및 marker focus에 공통 적용했다.
