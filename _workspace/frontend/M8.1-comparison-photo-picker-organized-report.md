# M8.1 사진 놓기 사진 선택 정리 — 프런트엔드 결과

## 변경 범위

- `ComparisonPhotoPickerDialog` 공통 컴포넌트를 추가했다.
- 비교 생성(`ComparePage`)과 비교 결과의 사진 교체가 같은 선택 컴포넌트를 사용한다.
- 개인 앨범에서 수상작 비교를 시작하는 `AlbumComparisonPicker`도 같은 선택 컴포넌트를 사용한다.

## 사용자 흐름

1. 처음에는 `새 사진 추가`를 기본 행동으로 보여 준다. 파일을 고르면 EXIF 촬영일을 채우고, 없으면 촬영일을 직접 입력한 뒤 추가한다.
2. `앨범에서 고르기`를 누르면 기존 사진만 별도 화면에서 본다.
3. 기존 사진은 `최근`, `날짜`, `장소`로 전환할 수 있다. 날짜와 장소 보기에서는 해당 기준으로 묶어 표시한다.
4. 사진을 누르면 즉시 닫지 않고 상단의 `선택한 사진` 요약에서 확인한 뒤 `선택`으로 확정한다.

## 설계 결정

- 업로드와 기존 앨범 선택을 한 그리드에 섞지 않았다. 사진 수가 늘어도 기존 사진 탐색이 복잡해지지 않는다.
- 선택 UI와 EXIF/수동 촬영일 처리는 공통 컴포넌트 한 곳에 두고, 생성·교체·앨범 진입은 각각 사진을 선택한 뒤의 도메인 동작(비교 생성 또는 교체)만 책임진다.
- 기존 앨범 사진의 선택 가능 조건과 비교 생성/교체 API 계약은 변경하지 않았다.
