# M10.1 프런트 지역 코드 계약 검토

## 범위

- 앨범 지도 지역 카탈로그와 수상작 상세·비교 사진 선택의 `mapRegionCode`/`mapCityCode` 소비 경로를 대조했다.
- UI 및 API 계약은 변경하지 않았다.

## 결과

- 승인 정본인 `SINAN`을 신안군의 표준 코드로 사용한다.
- `koreaRegions.ts`와 `albumMapCityPositions.ts`가 같은 `SINAN` 키를 사용해 앨범 지도 선택·마커 위치 조회가 유지된다.
- 수상작 상세 DTO의 `mapCityCode`는 `AlbumComparisonPicker`와 `PhotoComparisonResultDialog`에서 가공 없이 비교 사진 선택 조건으로 전달된다.
- `comparisonPhotoLocation.ts`는 대상 코드와 사진 번들 코드를 동등 비교하므로 `SINAN`을 그대로 소비한다.
- 프런트에 `SHINAN` 참조는 남아 있지 않다.

## 검증

- 테스트 러너는 프런트에 구성되어 있지 않아 추가 테스트는 만들지 않았다.
- `npm run build` 및 `git diff --check` 실행 결과는 통합 QA에서 대조한다.
