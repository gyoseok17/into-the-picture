# M8.1 앨범 지도 시·군 좌표표 프런트엔드 보고

## 변경 범위

- `albumMapCityPositions.ts`에 161개 선택 가능 시·군 코드의 SVG 기준 정규화 좌표를 추가했다.
- `PhotoRecordMapView`는 `mapCityCode`가 있는 기록을 이 좌표표로 표시하고, 장소 코드가 없는 구형 기록에만 기존 위경도 fallback을 사용한다.

## 설계 결정

- 앨범 지도 SVG는 실제 위경도 투영 지도가 아니므로, 위경도 비율 환산보다 그림 경계에 맞춘 코드별 좌표표가 정확하다.
- 좌표표를 뷰 컴포넌트에서 분리해 지도 그림을 교체하거나 보정할 때 좌표 파일만 수정할 수 있다.
- 동일 시·군의 방문 기록을 하나로 묶는 기존 그룹 ID와 겹침 처리에는 손대지 않았다.

## 검증

- `koreaRegions`의 161개 시·군 코드와 좌표표 키 161개가 일치하는지 확인했다.
- 렌더링된 지도 PNG의 권역 색상 위에 모든 좌표가 놓이는지 확인했다: 161/161 통과.
- `_workspace/qa/M8.1-verify-album-map-city-positions.ps1`로 코드 수와 PNG 권역 색상 위치를 반복 검증할 수 있다.
- 빌드와 diff 검사는 통합 QA 단계에서 다시 확인한다.

## 보정

- QA에서 제주 및 남·서해안 일부 좌표가 SVG 도형 밖이라는 문제를 발견했다. 해당 위치를 실제 PNG 도형 안으로 보정하고, 전체 161개를 PNG 색상 기준으로 재검증했다.

## 남은 위험

- 실제 SVG 위 최종 미세 위치는 브라우저에서 주요 도시(서울·전주·부산·제주 등)를 확인하며 소수점 단위로 보정할 수 있다.
