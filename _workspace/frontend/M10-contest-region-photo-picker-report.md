# M10 수상작 지역 기반 앨범 사진 선택 — 프런트 결과

## 변경 범위

- `ComparisonPhotoPickerDialog`은 선택적으로 수상작의 검증된 `regionCode`·`cityCode`를 받는다.
- `AlbumComparisonPicker`와 비교 결과 수정의 사진 교체 선택기는 수상작 상세의 `mapRegionCode`·`mapCityCode`를 위 선택기에 전달한다.
- `comparisonPhotoLocation.ts`는 React·HTTP에 의존하지 않는 후보 묶음 필터 규칙만 가진다.

## 설계 결정

- 양쪽에 시군 코드가 있으면 시군 코드가 일치하는 묶음만 보인다.
- 수상작 또는 묶음 한쪽에 시군 코드가 없으면 같은 권역 코드까지 허용한다.
- 수상작의 권역 코드가 없으면 호환성을 위해 기존처럼 전체 앨범을 표시한다.
- 대상 권역에서 후보가 없으면 `이 지역에 기록한 사진이 없어요.`와 새 파일 선택 경로를 표시한다.
- 사진 교체는 수상작 상세 위치를 받는 동안 선택기를 열지 않아, 필터 전 전체 앨범이 잠깐 보이지 않는다.
- 새 사진 직접 추가, 비교 중 사진 비선택, 기존 비교 생성/크롭 흐름은 변경하지 않았다. 직접 추가한 사진의 위치 입력 흐름은 이번 UI 필터 범위 밖이다.

## 검증

- `frontend npm run build` 통과.
- TypeScript가 선택적 지역 입력 및 모든 선택기 호출부를 검증했다.

## 영향 계약

- 기존 수상작 상세의 `mapRegionCode`, `mapCityCode`와 기존 앨범 묶음의 같은 필드를 프런트에서 비교할 뿐 API·DTO·DB 변경은 없다.
