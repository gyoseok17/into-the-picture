# 지도 사진 목록의 수상작 연결 표시

## 변경 범위

- `PhotoRecordMapView.tsx`의 지도 포커스 패널 하단 사진 목록
- API, DB, 비교 생성·공개 규칙은 변경하지 않음

## 구현

- 사진별 비교 연결 여부를 기존 `comparisons` 데이터에서 계산했다.
- 연결된 사진 썸네일 우측 상단에 트로피 아이콘을 표시했다.
- 아이콘은 썸네일 위에만 겹치며, 사진 선택과 확대 동작은 그대로 유지한다.
- 같은 표시를 확대 창의 썸네일에도 적용해 앨범/스토리의 의미와 맞췄다.
- 지도 패널 아래의 `연결된 수상작` 목록(`PhotoComparisonLinks`)은 제거했다.
- 비교 결과 열기는 사진 확대 창의 원본 오버레이를 통해 계속 가능하다.

## 접근성 및 예외

- 트로피가 있는 썸네일의 접근성 이름에 `수상작 비교 연결됨`을 포함했다.
- 한 장뿐인 기록은 하단 썸네일 목록이 원래 없으므로 기존 `비교 연결` 상태 표시와 확대 창 오버레이를 유지한다.
