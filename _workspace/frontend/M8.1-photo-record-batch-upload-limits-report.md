# M8.1 사진 기록 묶음 업로드 한도 - 프런트엔드 보고

## 변경 범위

- `BatchPhotoUploadPanel`의 파일 선택을 묶음 최대 3장, 파일별 최대 10MB로 제한했다.
- 선택 직후 10MB 초과 파일은 제외하고, 유효한 파일이 4장 이상이면 처음 3장만 준비한다.
- 선택 결과에 따라 제외 사유를 한국어 안내로 표시한다.
- 선택된 항목이 비정상 상태로 남더라도 업로드 직전에 같은 한도를 한 번 더 검사한다.

## 설계 결정

- 파일 선택기는 기존 대기열을 교체하는 동작이다. 새로 고른 파일이 모두 제한을 넘으면 기존에 준비한 사진을 지우지 않고 유지한다.
- 클라이언트 제한은 빠른 피드백용이며, 실제 권한·파일 수·형식·크기 판정은 서버 계약을 계속 따른다.
- API 요청 형식과 응답 타입은 바꾸지 않았다. 계약은 `_workspace/contracts/M8.1-photo-record-batch-upload-limits.md`를 사용한다.

## 남은 수동 확인

- 4장을 선택했을 때 처음 3장만 미리보기에 남고 안내가 보이는지
- 10MB 초과 파일만 선택했을 때 기존 선택 사진이 유지되고 안내가 보이는지
- 10MB 초과 파일과 정상 파일을 함께 선택했을 때 정상 파일만 업로드되는지
