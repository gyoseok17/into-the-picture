# M8.1 사진 놓기 새 사진 촬영일 입력 보고

## 변경 범위

- `AlbumComparisonPicker`의 새 사진 추가 경로
- `ComparePage`의 새 사진 추가 경로
- 비교 결과 상세의 새 사진 교체 경로

기존 앨범 사진을 선택하는 경로는 변경하지 않았다.

## 동작과 계약

1. 사용자가 새 파일을 고르면 즉시 업로드하지 않는다.
2. JPEG, PNG, WebP의 EXIF 촬영일을 읽을 수 있으면 `datetime-local` 입력값에 미리 채운다.
3. EXIF 촬영일이 없거나 지원하지 않는 형식(HEIC/HEIF 포함)이면 촬영일을 직접 입력해야 `사진 추가` 버튼이 활성화된다.
4. 확인 시 파일과 `takenAt`을 같은 multipart 요청의 `/me/photos`로 전송한다.
5. 기존 앨범 사진 선택은 촬영일 입력 단계 없이 기존처럼 비교 구도 편집기로 넘어간다.

## 오류·반응형 확인

- 입력값이 없으면 업로드를 시작하지 않아 서버의 촬영일 누락 오류를 예방한다.
- 사진 미리보기와 촬영일 입력 영역은 선택 창의 스크롤 영역 안에 있어 모바일 작은 화면에서도 확인할 수 있다.
- 선택 취소와 창 닫기에서 미리보기 Object URL을 해제한다.

## 검증

- `frontend`: `npm run typecheck` 통과
- `git diff --check` 통과 (줄 끝 경고 외 오류 없음)

## 남은 수동 확인

- EXIF가 있는 JPEG/PNG/WebP를 선택했을 때 날짜가 채워지는지
- EXIF가 없는 이미지에서 날짜 입력 전에는 추가가 비활성인지
- 사진 놓기 생성과 결과 상세의 사진 변경 양쪽에서 `takenAt` multipart 값이 전송되는지
