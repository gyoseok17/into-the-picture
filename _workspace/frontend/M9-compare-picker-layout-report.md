# M9 수상작 비교 사진 선택 레이아웃 보고

- 작업일: 2026-09-19
- 담당: 프런트엔드

## 변경 범위

- `frontend/src/features/comparison/components/ComparisonPhotoPickerDialog.tsx`

## 설계 결정

- 새 사진 파일을 고른 뒤에는, 파일 선택용 대형 카드와 선택 사진 편집기를 함께 표시하지 않는다.
- 선택된 사진은 112px(작은 화면)~128px(넓은 화면) 미리보기로 키우고, 촬영일 입력과 한 행으로 정렬한다.
- 파일을 바꿀 필요가 있을 때는 선택 사진 아래의 작은 `다른 사진` 버튼으로 같은 파일 선택기를 다시 연다.

## 이유

- 기존에는 파일을 고른 뒤에도 160px 높이의 `새 사진 추가` 카드가 남고, 실제 선택한 사진 미리보기는 80px이라 시선과 공간 비중이 반대였다.
- 선택 이후 단계에서는 추가 행동보다 선택 사진 확인·촬영일 확인·저장이 주 행동이므로, 편집 카드에 공간을 집중한다.

## 보존한 흐름·계약

- 첫 단계에서는 직접 파일 선택이 기본이고, `앨범에서 고르기`는 별도 경로로 유지된다.
- 비교 중인 사진은 기존처럼 선택 불가 상태를 유지한다.
- 파일 업로드 요청과 촬영일 필수 검증, 비교 생성·크롭 흐름은 변경하지 않았다.

## 검증

- `frontend`: `npm run build` 통과.
- `git diff --check` 통과.
- 기존 번들 크기 경고(500kB 초과)는 유지되며 이번 변경과 무관하다.

## 남은 위험

- 실제 기기에서 파일 선택 후 `다른 사진`으로 교체, EXIF 촬영일 자동 채움·직접 입력·추가 완료를 한 번 확인하면 된다.
