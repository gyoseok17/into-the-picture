# M10 스토리 묶음 상세 전환 버튼 정리

## 변경 범위

- `frontend/src/features/photo-record/components/PhotoRecordAlbum.tsx`
  - 스토리 모드의 `PhotoBundleLightbox`에서 이전·다음 버튼, 순번 표시, 전환용 `move` 핸들러를 제거했다.
  - 사진 썸네일은 단일 행 `overflow-x-auto` 컨테이너에 그대로 유지했다.
  - 썸네일은 `shrink-0`이므로 사진 수가 컨테이너 폭을 넘으면 줄바꿈하지 않고 가로 스크롤된다.
  - 썸네일 선택으로 대표 사진을 바꾸는 상태(`index`), 큰 사진 표시, 비교 트로피 표시는 유지했다.

## 설계 결정

- 사진 이동 책임을 중복 버튼이 아니라 썸네일 선택과 가로 스크롤에만 둔다. 사진이 많아도 상세 패널의 세로 공간을 추가로 차지하지 않는다.

## 검증

- `frontend`: `npm run build` 통과
- 전체 작업 트리: `git diff --check` 통과

## 남은 위험·수동 확인

- 실제 브라우저에서 많은 사진이 든 묶음을 열어 모바일·데스크톱 모두에서 썸네일 가로 스크롤, 임의 썸네일 선택, 큰 사진 클릭 확대를 확인해야 한다.
- Vite의 500 kB 청크 경고는 기존 번들 최적화 후속 과제이며, 이번 변경과 무관하다.
