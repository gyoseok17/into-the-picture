# M10 스토리 묶음 확대 좌우 클릭 탐색 보고

## 변경 범위

- `frontend/src/features/photo-record/components/PhotoRecordAlbum.tsx`의 `PhotoBundleLightbox`

## 구현

- 묶음에 사진이 두 장 이상일 때 큰 사진 영역의 왼쪽 클릭은 이전 사진, 오른쪽 클릭은 다음 사진으로 순환 이동한다.
- 한 장뿐인 묶음은 포인터 시작 정보를 기록하지 않아 탐색 동작이 없다.
- 썸네일 선택과 가로 스크롤 영역은 변경하지 않았다.
- 포인터 시작·종료 거리의 직선 거리가 12px을 초과하면 탐색하지 않아 터치 드래그나 스크롤을 단순 클릭으로 처리하지 않는다.
- 포인터 취소와 이미지 기본 드래그도 별도로 처리했다. 키보드 포커스 상태에서는 좌·우 화살표 키로 같은 탐색을 제공한다.

## 검증

- `frontend npm run build` 통과
- `git diff --check` 통과

## 남은 확인

- 실제 모바일 브라우저에서 세로 스크롤 후 사진 영역을 놓았을 때 전환되지 않는지 수동 확인이 필요하다.
