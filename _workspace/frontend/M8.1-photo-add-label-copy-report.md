# M8.1 사진 추가 공통 입력 문구 정리

- 변경 범위: `BatchPhotoUploadPanel`의 공통 기록 입력 영역만 수정했다.
- 결정: 선택 여부는 제목·필드 라벨에 붙이고, 입력 칸 안에서는 제거했다. 라벨의 보조 문구는 별도 grid 행이 되지 않도록 inline `span`으로 감쌌다.
- 변경: `기록 더하기 (선택)`을 `기록 더하기`로, 종료일과 메모를 각각 `종료일 (선택)`, `메모 (선택)` 라벨로 바꿨다.
- 영향 계약: 저장 값, 필수 여부, aria-label, 업로드 상태 및 API 호출은 변경하지 않았다.
- 검증: `npm run build`, `git diff --check` 실행 결과를 확인한다.
