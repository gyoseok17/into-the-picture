# M10 비교 관리 선택 삭제 바

- 변경 범위: `PhotoRecordAlbum`의 다중 선택 삭제 바 레이아웃.
- 결정: 문서 흐름의 `sticky` 바를 화면 하단 `fixed` 바로 변경했다. 선택한 사진이 긴 스토리 목록 밖으로 스크롤된 뒤에도 선택 개수와 삭제 동작을 유지한다.
- 반응형: 모바일은 하단 내비게이션과 안전 영역 위(`5.25rem + safe-area`), 데스크톱은 화면 하단 1.5rem 위에 표시한다. 최대 폭은 `max-w-md`로 제한했다.
- 계약 영향: 없음. 기존 선택 상태와 삭제 mutation을 그대로 사용한다.
- 검증: `frontend/npm run build` 통과, `git diff --check` 통과. 기존 Vite 500kB 청크 경고만 존재한다.
