# M8.1 사진 확대 수상작 정보 프런트엔드 결과

## 변경 범위

- `PhotoComparisonOverlay`를 사진 확대 전용 `PhotoComparisonLightboxInfo`로 교체했다.
- 지도 `MapPhotoLightbox`, 스토리 `PhotoBundleLightbox` 모두 이미지 아래에 트로피·수상작 제목·장소·`비교 보기`를 표시한다.
- 연결이 여러 건이면 첫 수상작을 대표로 보이고, 버튼의 건수와 기존 결과 다이얼로그의 선택 기능으로 나머지를 확인한다.

## 설계 결정

- 확대 이미지 위의 떠 있는 수상작 썸네일은 완전히 제거해 사진을 가리지 않게 했다.
- 결과 보기에는 기존 `PhotoComparisonResultDialog`를 그대로 사용해 경로 이동과 API·DB 변경 없이 중첩 모달/초점 복귀 동작을 유지했다.
- 짧은 모바일 뷰포트에서 수상작 정보와 사진 탐색 조작이 가려지지 않도록 두 라이트박스 내용에 최대 높이와 세로 스크롤을 적용했다.

## 검증

- `npm run typecheck` 통과
- `npm run build` 통과 (기존 500KB 청크 경고만 존재)
- `git diff --check` 통과

## 남은 위험

- 비교 연결 수가 매우 많아질 때 결과 다이얼로그 목록의 페이지 처리 여부는 기존 공개 비교 목록 성능 개선 과제와 함께 검토한다.
