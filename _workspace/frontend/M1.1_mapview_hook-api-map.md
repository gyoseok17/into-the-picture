## UI / 상태 처리

- 뷰 토글: `ContestListPage` 상단 `[ 리스트 | 지도 ]` 세그먼트. `view` state로 전환.
- 지도 뷰 3종 상태:
  - 로딩 → `Skeleton`(지도 종횡비).
  - 에러 → `ErrorState` + 재시도(`refetch`).
  - 빈 배열 → 지도는 정상 렌더, "표시할 위치 정보 없음" 안내 배지(리스트 뷰에선 작품 여전히 노출).
- 다중 마커: `ContestMapView.tsx`가 공용 `lib/kakaoMap.ts` 로더의 `MarkerClusterer`를 사용한다. 축소 시 가까운 핀은 숫자 클러스터로 묶이고, 확대하면 개별 핀으로 분리된다. `LatLngBounds`로 핀 전체를 맞추되 단일 핀은 center만 지정한다.
- **지도 생성(1회)과 마커/클러스터 갱신(pins 변경 시)을 별도 effect로 분리** — 지도는 mount 시 1회 생성해 `mapRef`에 보관하고, 필터 결과가 바뀌면 이전 마커·클러스터·선택을 비운 뒤 다시 구성한다. 언마운트 시 지도·클러스터 이벤트 리스너를 제거한다.
- 개별 마커 클릭은 1개, 숫자 클러스터 클릭은 해당 작품 전체를 선택한다. 데스크톱에서는 지도 우측 패널, 모바일에서는 지도 아래 패널에 큰 썸네일·등급·지역·제목 카드를 표시하며 카드 클릭 시 `navigate('/contests/{id}')`로 이동한다. 줌·드래그·필터 변경 시 선택은 비운다.
- **개수 표시는 지도 영역 '밖'**(지도 위 한 줄) "지도에 표시된 수상작 N개"(N = 현재 pins.length, 필터 반영). 지도 안 오버레이 배지는 제거. 빈 배열이면 N=0 + 지도 안 "위치 정보 없음" 안내 유지.
- 카카오 키 미설정/로드 실패 → "지도 준비중" placeholder(기존 `ContestMap.tsx` graceful 패턴 재사용).

## 버그 수정 (2026-07-31, 사용자 확인 피드백)

**증상:** 마커 클릭해도 미리보기 카드가 안 뜸.
**근본원인:** 단일 effect(deps `[pins]`)에서 지도·마커를 함께 생성했다. StrictMode 이중 마운트 + async(`loadKakaoMaps().then`) 조합에서 같은 컨테이너 DOM에 `new kakao.maps.Map(...)`이 중복 호출되어 지도 레이어가 겹쳐 쌓이고, 예전 마커에 붙은 click 리스너가 죽은(위에 덮인) 레이어에 남아 클릭이 산 인스턴스에 도달하지 못했다. 이전 cleanup은 `cancelled` 플래그만 세우고 생성된 지도/마커를 정리하지 않아 유령 인스턴스가 남았다.
**수정:** 지도 생성 effect(deps `[]`, 1회)와 마커 갱신 effect(deps `[pins, mapReady]`)로 분리. 마커 갱신 시 이전 마커를 `setMap(null)`로 전부 제거 후 재생성 → 유령 마커·죽은 리스너 제거. 지도 인스턴스가 하나로 유지되어 클릭이 항상 산 마커에 도달.

## 2차 UI 수정 (2026-08-01, 사용자 확인 피드백)

**1) 미리보기 카드가 지도에 가려짐.** setSelected/렌더는 정상이었으나 카카오맵 내부 타일/컨트롤이 자체 stacking context에서 높은 z-index를 써 카드가 덮였다. 카드 래퍼(`absolute inset-x-3 bottom-3`)에 `z-50` 추가 → 지도 위에 확실히 표시.
**2) 개수 표시를 지도 '밖'으로.** 지도 안 좌상단 오버레이 배지를 제거하고, 지도 컨테이너 위쪽에 별도 한 줄(`MapCount`) "지도에 표시된 수상작 N개"로 이동. N = pins.length(필터 반영).

## 3차 UX·초기화 수정 (2026-08-02)

- 겹친 핀을 하나씩 선택하기 어려워 `MarkerClusterer`를 추가했다. 클러스터 클릭은 해당 작품들의 목록을 선택 패널에 표시하고, 확대 시 카카오 SDK가 개별 핀으로 분리한다.
- 기존 지도 안 하단 단일 미리보기 카드는 제거했다. 데스크톱은 지도 우측, 모바일은 지도 아래의 큰 카드 목록으로 바꿔 지도와 정보가 겹치지 않게 했다.
- `autoload=false` SDK는 `maps.load()` 완료 전 `MarkerClusterer`가 준비되지 않을 수 있어, 로더가 초기화 완료 콜백 안에서 검증하도록 수정했다. 지도 전환 시 "지도 준비중"만 보이던 회귀를 방지한다.
