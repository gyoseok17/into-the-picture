# M8.1 공통 사진 추가 패널 프런트엔드 보고

## 변경 범위

- `BatchPhotoUploadPanel`에 장소 요약 필드와 장소 선택 오버레이를 추가했다.
- 상위 앨범이 `PhotoAddSheet` 하나를 관리하고, 스토리·지도·보관함은 해당 시트를 연다.
- 지도 진입 시 선택한 시·군은 `initialLocation`으로 전달되어 장소 필드에 즉시 표시된다.
- 장소 코드가 없으면 업로드 대상 수를 0으로 처리하고 업로드 함수도 방어해 저장되지 않는다.
- 지도 전용의 업로드 시트와 장소 필드 숨김 분기를 제거했다.
- 보관함에도 같은 `사진 추가` 진입점을 제공했다.

## 설계 결정

- 기존 `PhotoRegionField`와 `uploadPhotoRecordBundle` API를 재사용했다. 장소 선택 UI만 오버레이로 감싸 API·서버 계약 변경을 피했다.
- 오버레이는 portal과 스크롤 잠금을 사용한다. 선택 시 원래 사진 추가 패널 상태를 유지한 채 닫힌다.

## 검증

- `frontend: npm run build` 통과 (`tsc -b`, Vite production build).
- `git diff --check` 통과.

## 남은 확인

- 브라우저에서 스토리·보관함·지도 진입별 실제 터치 흐름과 선택 후 패널 복귀 위치를 QA가 확인해야 한다.
