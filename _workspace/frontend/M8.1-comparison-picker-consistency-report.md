# M8.1 사진 선택 일관성·앨범 조회 재사용 프런트 보고

작성일: 2026-09-14
담당: 프런트엔드

## 변경 범위

- `ComparisonPhotoPickerDialog`에 `unavailablePhotoIds`와 선택적 `bundles` 입력을 추가했다.
- 새 비교와 기존 비교의 사진 교체는 전체 활성 사진을 전달하고, 저장된 비교에 연결된 사진은 목록에서 숨기지 않고 `비교 중`으로 표시해 선택을 막는다.
- 앨범에서 수상작 비교를 시작할 때는 이미 열린 앨범의 활성 묶음을 `bundles`로 전달한다. 선택창은 외부 묶음이 있으면 별도 `/me/photos/bundles` 조회를 시작하지 않는다.
- 비교 전용 단일 사진 업로드 성공 뒤 `user-photos`, 앨범 기록·묶음·지도 캐시를 함께 무효화한다.

## 설계 결정

- 사진 교체 화면의 현재 비교 사진도 선택 불가로 통일했다. 같은 id로의 교체는 결과가 바뀌지 않고, 다른 저장 비교에 이미 연결된 사진 재사용과 동일한 정책이므로 목록에 보이되 `비교 중`으로 표시한다.
- 무효화는 강제 refetch가 아니다. React Query는 현재 화면에서 구독 중인 쿼리만 다시 조회하므로, 앨범을 보고 있지 않다면 추가 네트워크 요청을 만들지 않는다.
- 선택창은 데이터 소유자가 없을 때만 지연 조회한다. 따라서 일반 진입은 기존 동작을 유지하면서 앨범 진입의 중복 호출만 없앤다.

## 남은 수동 확인

- 한 묶음 안의 사용 중 사진과 사용 가능 사진이 함께 표시되고, 사용 중 사진의 클릭·키보드 선택이 모두 막히는지 확인한다.
- 앨범에서 시작할 때 묶음 API가 추가로 호출되지 않는지 Network 탭에서 확인한다.
