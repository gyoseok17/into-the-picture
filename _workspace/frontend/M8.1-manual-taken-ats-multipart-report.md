# M8.1 수동 촬영일 multipart 프런트 수정 보고

작성일: 2026-09-08

## 변경 범위

- `BatchPhotoUploadPanel`이 모든 사진의 수동 촬영일이 비어 있으면 `manualTakenAts`를 `undefined`로 전달한다.
- 하나라도 직접 지정한 경우에는 파일 순서에 맞는 전체 배열을 전달하고, 비어 있는 위치는 API 직렬화 시 `__AUTO__` 예약값으로 바꾼다.

## 설계 결정

- API 직렬화 모듈은 비어 있는 전체 배열을 생략하고, 혼합 배열의 `null`을 `__AUTO__` 예약값으로 직렬화한다.
- 따라서 화면의 입력·미리보기·날짜 검증을 바꾸지 않고 업로드 payload 생성만 보완했다.

## 검증 계획

- 수동 촬영일 미지정: `manualTakenAts` 필드 없음.
- 혼합 지정: `files`와 같은 수의 슬롯, 지정하지 않은 위치는 `__AUTO__`.
- 타입 검사, 프로덕션 빌드, diff 공백 검사를 실행한다.

## 남은 확인

- 실제 브라우저에서 EXIF 없음 + 묶음 시작일 지정 업로드, 수동 날짜 혼합 업로드를 각각 확인한다.
