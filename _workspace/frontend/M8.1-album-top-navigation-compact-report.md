# M8.1 앨범 상단 보기 전환부 축약 프런트 보고

## 변경 범위

- `frontend/src/features/photo-record/components/PhotoRecordAlbum.tsx`

## 구현

- 스토리·맵·보관함 전환 컨트롤의 줄바꿈을 제거했다.
- 540px 이하에서 텍스트 대신 `BookOpen`, 지도, 보관함 아이콘만 표시하도록 했다.
- 접근성 이름과 마우스 도움말은 텍스트가 숨겨져도 유지했다.

## 설계 이유

보기 전환은 짧고 자주 쓰는 상단 조작부이므로, 좁은 폭에서 두 줄로 밀기보다 활성 상태를 유지한 아이콘 전용 한 줄로 축약하는 편이 화면 흐름을 보존한다.

## 영향과 위험

- 사진 기록의 API·저장 데이터·라우팅은 변경하지 않았다.
- 540px 이하에서는 아이콘 의미를 처음 쓰는 사용자가 즉시 알기 어려울 수 있어, `title`과 접근성 이름을 함께 제공한다.

## 검증

- `npm run typecheck` 통과.
- `npm run build` 통과. 기존 500kB 초과 청크 권고만 비차단 상태로 남았다.
- `git diff --check` 통과.
- 독립 QA 결과는 수신 뒤 별도 QA 문서와 마일스톤 로그에 보완한다.
