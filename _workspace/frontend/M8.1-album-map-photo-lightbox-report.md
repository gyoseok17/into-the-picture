# M8.1 지도 사진 확대 보기 프런트엔드 보고

## 변경 범위

- `frontend/src/features/photo-record/components/PhotoRecordMapView.tsx`

## 구현

- 선택한 지도 방문 기록 패널의 큰 사진을 키보드 접근 가능한 `사진 크게 보기` 버튼으로 만들었다.
- 여러 사진이 있는 기록은 패널의 썸네일을 누르면 해당 사진을 선택한 채 바로 라이트박스를 연다.
- 라이트박스는 현재 기록의 사진만 대상으로 이전·다음 순환과 썸네일 전환을 제공한다. 내부에서 사진을 바꾸면 지도 패널의 현재 사진도 같은 사진으로 맞춘다.
- 스토리의 묶음 보기와 동일하게 큰 사진·사진 수·비교 연결 오버레이를 보이며, 기존 지도 패널의 대표 기록 설정·방문 기록·비교 링크는 변경하지 않았다.
- 라이트박스는 `createPortal(document.body)`와 `z-[90]`을 사용한다. 지도 포커스 패널의 stacking context 밖에서 표시해 모바일 하단 내비게이션과 지도 오버레이에 가려지지 않는다.
- 배경 클릭·닫기·Escape는 라이트박스만 닫는다. 닫은 뒤에는 열었던 지도 패널의 큰 사진 버튼으로 초점을 복귀하고, 지도 마커·방문 기록 패널은 유지한다.

## 계약·범위

- API, DB, 사진 원본, 지도 좌표 및 비교 계약은 바꾸지 않았다.
- 사전 계약: `_workspace/contracts/M8.1-album-map-photo-lightbox.md`

## 검증

- `npm run typecheck` 통과.
- `npm run build`는 별도 장기 실행 중인 Node/Vite 작업과 CPU 경쟁으로 124초 제한 안에 완료되지 않아 중단했다. TypeScript 컴파일은 통과했으며, 통합 QA가 변경 후 빌드 및 동작을 재확인한다.
- `git diff --check`는 기존 작업 트리 전체의 CRLF 경고만 출력했고 공백 오류는 없었다.
