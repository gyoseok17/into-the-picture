# M8.1 앨범 지도 PC 지역 선택창 overflow 수정 — 프런트엔드 결과

- 날짜: 2026-09-10
- 담당: 프런트엔드
- 변경 파일: `frontend/src/features/photo-record/components/PhotoRecordMapView.tsx`
- 계약: `_workspace/contracts/M8.1-map-region-picker-desktop-overflow.md`

## 변경

- 지도 컨테이너를 size container로 지정했다.
- PC에서 region dialog를 `top-0` 아래 열림에서 `bottom-full + mb-2` 위쪽 열림으로 바꿨다.
- PC dialog에 `max-height: calc(100cqh - 5rem)`, `overflow-y-auto`, `overscroll-contain`을 적용했다. 많은 시·군 목록은 지도 경계 안에서 dialog 내부 스크롤로 선택한다.

## 유지한 동작

- 모바일의 기본 `bottom-0` 열림 방향과 너비는 그대로다.
- 지역 선택 trigger, 시·군 선택 뒤 dialog 닫힘, 선택된 시·군에 따른 사진 추가 enable 조건은 바꾸지 않았다.
- 지역 필터·marker 포커스·확대·API는 변경하지 않았다.

## 검증 계획

- PC: 가장 많은 시·군 권역에서 dialog가 trigger 위쪽에 있고, 최상단·최하단 도시까지 내부 스크롤로 선택 가능한지 확인한다.
- 모바일: 동일 trigger가 기존처럼 아래 고정 기준으로 열리고, 사진 추가 버튼 및 도시 선택이 유지되는지 확인한다.
- `npx tsc -p tsconfig.app.json --noEmit`, `npx vite build`, no-index diff check를 실행한다.
