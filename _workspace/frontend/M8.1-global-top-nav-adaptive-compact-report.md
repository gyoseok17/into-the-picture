# M8.1 전역 상단 내비게이션 적응형 축약 구현 보고

## 변경 범위

- `frontend/src/components/layout/TopNav.tsx`

## 설계와 이유

- 기존 768~1023px 고정 아이콘 모드를 제거했다. 이 구간에는 충분히 넓은 창도 있어 메뉴명이 불필요하게 사라졌다.
- 화면에 숨긴 확장 메뉴의 실제 폭과 브랜드·계정 영역·간격을 합산해 필요한 폭을 계산하고, 컨테이너 양쪽 패딩을 뺀 실제 flex 가용 폭과 비교한다.
- `ResizeObserver`가 컨테이너·브랜드·계정·측정 메뉴의 크기 변화를 감시하고, `requestAnimationFrame`으로 한 프레임에 한 번만 재측정한다.
- 상태값이 달라질 때만 갱신해 관찰과 렌더의 반복 루프를 방지한다.

## 영향과 위험

- 라우트, 로그인·로그아웃, 접근성 이름, 모바일 하단 탭은 바꾸지 않았다.
- 실제 브라우저에서 로그인 전/후와 긴 닉네임으로 메뉴 전환 지점이 자연스러운지 QA가 확인해야 한다.
