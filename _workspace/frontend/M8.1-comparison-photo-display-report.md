# M8.1 수상작 비교 내 사진 표기 프런트엔드 결과

## 변경 범위

- `comparisonPhotoDisplay` 공통 헬퍼를 추가해 장소 우선 제목·촬영일 보조 정보 규칙을 한 곳에서 제공한다.
- 비교 생성 화면의 선택 사진, 앨범 사진 선택 요약·타일, 비교 결과 목록·상세 헤더, 수상작/내 사진 비교판에 적용했다.
- 새 파일 미리보기는 파일명 대신 입력 또는 EXIF에서 얻은 촬영일을 표시한다.

## 보존 범위

- 이미지 alt와 크롭 편집기의 원본 파일명 전달, API·DB·파일명 데이터, 일반 앨범 UI는 변경하지 않았다.
- 메모는 비교 제목과 보조 정보에 사용하지 않았다.

## 검증

- `npm run typecheck` 통과
- `npm run build` 통과 (기존 500KB 번들 경고만 존재)
- `git diff --check` 통과
