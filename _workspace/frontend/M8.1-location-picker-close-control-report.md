# M8.1 장소 선택 닫기 버튼 정리 보고

## 변경 범위

- `BatchPhotoUploadPanel.tsx`의 `LocationPickerDialog` 우측 닫기 `×`만 제거했다.
- 지도 기록 상세, 방문 내역, 사진 비교 등 다른 대화 상자의 닫기 버튼은 변경하지 않았다.

## 동작 확인

- 장소 선택 오버레이의 배경을 누르면 오버레이만 닫히고 사진 추가 폼 입력값은 유지된다.
- `Escape`도 장소 선택 오버레이만 닫도록 우선 처리해, 뒤의 사진 추가 시트가 함께 닫히지 않는다.
- 업로드 중에는 기존처럼 취소 동작을 막는다.

## 검증

- `npm run build` 통과.
- `git diff --check` 통과.
- Vite의 500 kB 청크 크기 경고는 기존 비차단 경고다.
