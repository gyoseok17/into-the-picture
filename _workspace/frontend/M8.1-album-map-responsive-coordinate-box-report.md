## 원인

- 기존 stage는 `h-full max-w-full aspect-[2/3]`였다. 세로가 넓은 뷰포트에서 CSS `max-width`만 적용되면 stage 자체는 전체 높이를 유지할 수 있고, SVG의 `preserveAspectRatio="xMidYMid meet"`만 실제 2:3 크기로 letterbox 처리된다.
- 이때 `%` absolute marker는 전체 stage를 기준으로 계산되어, SVG 도형의 위·아래 여백만큼 남북 좌표가 어긋날 위험이 있었다.

## 구현

- 뷰포트 `clientWidth = W`, `clientHeight = H`를 `ResizeObserver`로 관찰한다.
- 실제 stage를 `width = min(W, H × 2 / 3)`, `height = width × 3 / 2`로 계산하고 grid 중앙에 배치한다.
- SVG와 marker absolute wrapper는 이 stage 내부의 `inset-0`을 함께 사용한다. SVG의 1024:1536 viewBox와 stage가 정확히 같은 2:3이므로 letterbox가 없다.
- 선택 시의 기존 `translate`·`scale` transform도 SVG와 marker의 공통 wrapper에 그대로 적용된다.
- 좌표표, SVG path, API, 묶음·선택 기준은 변경하지 않았다.

## 계산 검증

| 화면 폭 | 짧은 높이 stage | 긴 높이 stage | 종횡비 |
| --- | --- | --- | --- |
| 375px | 375 × 562.5 | 375 × 562.5 | 2:3 |
| 390px | 390 × 585 | 390 × 585 | 2:3 |
| 430px | 402 × 603 | 430 × 645 | 2:3 |

- 짧은 immersive 높이(667px viewport, 지도 603px)와 긴 immersive 높이(844px viewport, 지도 780px)를 계산했다.
- 일반 카드 모드의 최소/긴 높이도 각각 512px·636px에서 375/390/430px 폭을 계산했고, 모두 2:3(`0.666667`)을 유지했다.
- 따라서 marker `left/top %`의 기준 상자와 SVG rendered viewport의 원점·너비·높이가 동일하다.
