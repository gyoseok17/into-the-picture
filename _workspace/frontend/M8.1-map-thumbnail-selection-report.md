# M8.1 지도 사진 목록 선택과 확대 분리

## 변경 범위

- `frontend/src/features/photo-record/components/PhotoRecordMapView.tsx`의 지도 정보 패널 다중 사진 썸네일을 수정했다.
- 썸네일을 누르면 현재 큰 사진만 바꾸고, `MapPhotoLightbox`는 열지 않는다.
- 큰 사진 버튼은 기존처럼 사진 확대 창을 여는 유일한 진입점으로 유지했다.

## 설계 결정

- 썸네일은 사진 선택, 큰 사진은 상세 확대라는 서로 다른 책임으로 분리했다.
- 수상작 비교 연결 여부와 트로피 표시는 유지하며, 스크린 리더 이름도 `크게 보기`에서 `선택`으로 실제 동작에 맞췄다.
- 비교 매핑, 방문 기록, 대표 설정, API·DB 계약은 변경하지 않았다.

## 검증

- `npm run typecheck`
- `npm run build`
- `git diff --check`

## 수동 확인 항목

- 여러 사진 묶음에서 썸네일 선택 시 큰 사진·선택 테두리만 바뀌고 확대 창이 열리지 않는지 확인한다.
- 큰 사진을 누르면 확대 창이 열리고, 트로피와 수상작 비교 결과 접근이 유지되는지 확인한다.
