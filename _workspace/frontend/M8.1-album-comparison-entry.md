# M8.1 앨범 기반 사진 놓기 전환 — 프런트 결과

## 변경 범위

- 하단 내비게이션의 사진 놓기를 `/me/album`의 `내 앨범`으로 전환했다.
- 수상작 상세와 마이의 새 비교 CTA를 `/me/album?contestId=<id>`로 전환했다.
- 앨범에 수상작 고정 사진 선택 모드를 추가했다. 선택 대상은 묶음의 대표 사진이 아니라 사용자가 누른 개별 `bundle.photos[].id`다.
- 새 사진은 앨범 사진 API로 추가한 뒤 바로 비교 생성 대상으로 사용한다.
- 비교 연결 여부는 비교 목록의 `userPhoto.id`와 앨범 사진 ID를 대조해 파생한다. 연결된 사진에만 작은 상태 표시를 보인다.
- 지도 사진 상세와 스토리 라이트박스에는 연결 수상작과 저장 결과 진입 링크를 표시한다. 연결이 없는 사진·묶음에는 추가 UI를 렌더링하지 않는다.
- 기존 저장 결과 링크는 `/compare?contestId=<id>`를 유지한다. 이는 새 작성이 아니라 기존 결과 열기 전용이다.

## 계약 및 호환성

- `_workspace/contracts/M8.1-album-comparison-entry.md`에 경로·선택 모드·표시 계약을 작성했다.
- 서버 실제 enum에 맞춰 `PhotoTakenAtSource`의 `BUNDLE_FALLBACK`을 `BUNDLE_START_FALLBACK`으로 수정했다.

## 검증

- CTA 경로 대조: 새 비교 CTA 2곳은 `/me/album?contestId=`이며, 기존 결과 링크만 `/compare?contestId=`다.
- `git diff --check` 통과.
- `npm.cmd run build`는 TypeScript 단계 통과 뒤, 현재 샌드박스에서 Vite가 `vite.config.ts`와 상위 디렉터리 읽기를 거부해 실패했다. 권한 상승 재시도는 사용자 중단으로 완료되지 않았다.

## 남은 위험

- 스토리 라이트박스는 현재 선택된 개별 `photo.id`만으로 링크를 계산한다. 사진을 이전·다음 또는 썸네일로 바꾸면 연결 수상작과 결과 링크도 함께 바뀌며, 연결되지 않은 사진에는 UI가 없다.

## 2026-09-04 기존 사진 놓기 결과 전시 구성 개편
