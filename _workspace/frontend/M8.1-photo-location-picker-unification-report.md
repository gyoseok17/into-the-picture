# M8.1 사진 추가 장소 선택 UI 통합 — 프런트 보고

## 변경 범위

- `PhotoAddSheet` 헤더의 닫기 아이콘을 제거하고, 배경 클릭과 `Escape` 키의 닫기 동작은 업로드 중이 아닐 때만 유지했다.
- 사진 추가의 `PhotoRegionField`는 지도 SVG 대신 권역 버튼을 먼저 보여주고, 권역 선택 뒤 시·군 검색·칩 목록을 보여준다.
- 맵의 지역 변경 패널과 사진 추가 시트가 `RegionCityPicker` 하나를 재사용한다.

## 설계 결정

- 지도는 맵 보기에서만 유지하고, 시트 안의 장소 선택은 목록 기반으로 축소했다. 모바일 시트에서 작은 지도를 다시 조작하지 않아도 된다.
- 지도와 시트의 시·군 검색 조건, 선택 표시, 빈 검색 결과 처리를 공통 컴포넌트로 모아 둘 중 한 곳만 달라지는 문제를 막았다.
- 맵에서 전달한 초기 `mapRegionCode`·`mapCityCode`와 기존 장소 필수 검증은 변경하지 않았다.

## 검증

- `frontend/npm run build` 통과.
- `git diff --check` 통과.
- Vite의 기존 500kB 청크 경고만 남아 있으며 이번 변경으로 생긴 오류는 없다.

## 남은 확인

- 브라우저에서 스토리·보관함·맵 진입점별 장소 변경과 업로드 성공·실패 후 복귀를 통합 QA로 확인한다.
