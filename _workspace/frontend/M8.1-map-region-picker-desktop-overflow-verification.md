# M8.1 PC 지역 선택창 overflow 수정 — 검증 추가 기록

- 날짜: 2026-09-10

## QA 반영

- QA가 발견한 stacking context 위험을 해결했다. 열린 상태의 `RegionPicker` parent는 `z-30`, 기본 상태는 기존 `z-10`이다.
- 따라서 열린 지역 dialog는 `MapFocus`의 `z-20` 사진 카드보다 위에 렌더링된다. dialog를 닫으면 기존 marker/패널 계층으로 복귀한다.

## 검증 상태

- 정적 geometry 검토: PC upward opening과 `100cqh` map-bound max-height는 정상이라는 QA 사전 검토를 받았다.
- typecheck/build는 동시 Node 검증 작업으로 한 번의 통합 실행이 시간 제한을 넘겨, 분리 재실행 및 QA 결과를 대기한다.
