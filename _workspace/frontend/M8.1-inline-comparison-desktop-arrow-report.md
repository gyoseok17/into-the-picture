# M8.1 인라인 비교 결과 PC 화살표 제거 — 프런트엔드 보고

## 변경 범위

- `ComparisonPlacementPair`에 `showDesktopDirection` 선택 속성을 추가했다. 기본값은 `true`여서 기존 사진 놓기 관리 화면의 방향 화살표는 그대로다.
- `PhotoComparisonResultDialog`만 이 속성을 `false`로 전달해 앨범·수상작 상세 위의 인라인 비교 결과 PC 화면에서 가운데 `→`를 보이지 않게 했다.

## 설계 결정

- 공통 비교판의 기본 동작을 바꾸지 않고 인라인 다이얼로그 사용처에서만 표시를 끄도록 분리했다.
- 화살표를 없앤 PC 레이아웃은 동일 너비의 두 열로 재구성해 빈 열이나 이미지 폭 변화가 남지 않게 했다.
- 모바일 열 배치, 이미지·라벨, 다이얼로그의 키보드·닫기·초점 복귀는 변경하지 않았다.

## 검증

- `npm run typecheck` 통과
- `npm run build` 통과 (기존 Vite 500 kB 청크 권고만 출력)
- `git diff --check` 통과 (기존 워크트리의 CRLF 경고만 출력)

## 범위 밖

- 백엔드·DB·API, `ComparePage` 및 비교 관리 레이아웃은 수정하지 않았다.
