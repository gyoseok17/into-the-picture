# M8.1 비교 사진 촬영일 날짜 입력 전환 — 프런트엔드 결과

## 변경

- 공통 `ComparisonPhotoPickerDialog`의 새 사진 촬영일 입력 형식을 `datetime-local`에서 `date`로 바꿨다.
- EXIF에서 얻은 촬영일도 날짜 부분만 입력 칸에 표시한다.
- 업로드 직전 선택한 날짜에 `T00:00:00`을 붙여 서버의 기존 `LocalDateTime` 형식 계약을 유지한다.

## 영향 범위

- 새 비교, 기존 비교 사진 교체, 앨범에서 수상작 비교를 시작하는 세 경로에 공통 적용된다.
- 사진 원본과 EXIF 원본 시각을 변경하거나 저장하지 않으며, 비교용 새 사진 업로드 요청의 촬영일 값만 날짜 시작 시각으로 보낸다.
