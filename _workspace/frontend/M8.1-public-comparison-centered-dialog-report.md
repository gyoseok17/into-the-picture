# M8.1 수상작 공개 비교 사진 중앙 비교 화면 보고서

## 변경 범위

- 수상작 상세의 공개 비교 사진 화면을 모바일 하단 시트에서 화면 중앙 다이얼로그로 바꿨다.
- 다이얼로그에는 수상작 원본과 선택한 공개 사진을 같은 크기로 나란히 표시한다.
- 공개 사진이 여러 장이면 하단 썸네일에서 선택해 오른쪽 사진만 바꾼다.

## 설계 결정

- 원본 수상작 사진은 이미 상세 화면이 가진 `imageUrl`을 전달해 사용한다. 공개 비교 API는 그대로 `id`, `photoUrl`, `createdAt`만 소비한다.
- 썸네일 선택 상태는 갤러리 컴포넌트 내부 상태로 한정했다. API나 전역 상태에 선택값을 저장하지 않아, 모달을 닫았다 다시 열면 첫 사진을 기준으로 자연스럽게 시작한다.
- 이미지 비교판은 좁은 화면에서도 두 사진을 좌우로 유지한다. 원본과 선택 사진을 한 시선에서 비교하는 목적을 우선하며, 세로 공간은 모달 내부 스크롤로 처리한다.
- 로딩·오류·0건 화면은 기존 상태 컴포넌트와 공개 API 결과를 그대로 사용한다.

## 접근성과 반응형

- 다이얼로그는 `role=dialog`, `aria-modal`, 제목 연결, Escape·바깥 클릭 닫기, Tab 포커스 가두기와 닫은 뒤 원래 포커스 복귀를 유지한다.
- 썸네일은 실제 버튼이며 선택 상태를 `aria-pressed`와 선택 표식으로 전달한다.
- 모바일과 데스크톱 모두 중앙 배치하고, 화면 높이를 넘으면 다이얼로그 내부만 스크롤된다.

## 영향 범위와 위험

- API, DB, 공개 범위, 파일 권한 및 개인 앨범 메타데이터 노출 규칙은 변경하지 않는다.
- 수상작 이미지가 없을 수 있는 비정상 상세 응답에서는 원본 비교판을 생략하고 공개 사진 선택 목록만 표시한다. 정상 상세 흐름에서는 항상 원본이 있다.
