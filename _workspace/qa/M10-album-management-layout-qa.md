# M10 앨범 관리 표시 · 위치 코드 QA

검토 일시: 2026-09-21

## 대상

- 스토리 관리 모드의 선택 삭제 바가 스크롤과 무관하게 보이는지
- 스토리에서 맵으로 전환할 때 관리/선택 상태가 남지 않는지
- 전라·신안군 위치 코드의 프런트/백엔드 계약 일치 여부

## 정적 검토 결과

### 선택 삭제 바

- `PhotoRecordAlbum`은 선택 바를 스토리 타임라인 섹션 밖에서 렌더링한다.
- 표시 조건은 `layout === "story" && isManaging && selectedItems.size`다.
- `SelectionBar`는 `fixed`와 모바일 하단 내비게이션 위 오프셋, 데스크톱 `bottom-6`, `z-40`을 사용한다.
- 따라서 스토리에서 항목을 하나 이상 선택한 뒤 페이지를 스크롤해도 선택 수와 삭제 버튼은 뷰포트 하단에 유지된다.

### 스토리/맵 전환

- 레이아웃 전환은 `changeLayout`으로 단일화됐다.
- 이 함수는 새 레이아웃 설정과 함께 `isManaging`을 `false`, `selectedItems`를 빈 집합으로 초기화한다.
- 선택 바 자체도 스토리 전용 조건이라 맵에서 렌더링되지 않는다.
- 따라서 스토리 관리 중 맵으로 전환하면 체크 상태와 선택 삭제 바가 함께 해제된다. 맵에서 스토리로 돌아와도 관리 모드는 꺼진 상태다.

### 신안군 위치 계약

- 프런트 `koreaRegions.ts`: 전라 권역의 신안군 코드는 `SINAN`.
- 백엔드 `MapLocationCatalog`: 전라 권역의 신안군 코드는 `SINAN`.
- `MapLocationCatalog.resolve("JEOLLA", "SINAN")`은 같은 Region의 City를 찾으므로 `The map city does not belong to the map region.` 오류 대상이 아니다.

## 회귀 확인 항목

1. 스토리 → 관리 → 사진 체크 → 아래로 스크롤: 선택 바가 하단 내비게이션 위에 남는지
2. 위 상태에서 맵 선택: 체크 표시, 선택 삭제 바, 관리 상태가 모두 사라지는지
3. 맵 → 스토리 복귀: 관리 버튼이 `관리`로 표시되고 이전 선택이 복원되지 않는지
4. 전라 → 신안군 저장: 요청 값이 `JEOLLA` / `SINAN`이고 400 오류 없이 저장되는지
