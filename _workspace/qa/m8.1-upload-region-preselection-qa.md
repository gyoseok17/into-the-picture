# M8.1 사진 추가 시트 선(先) 지역 선택 QA

작성일: 2026-08-28
역할: 통합 QA (코드 수정 없음)

## 현 상태와 변경 확인점

- 현재 `BatchPhotoUploadPanel`은 파일을 하나 이상 선택한 뒤에만 `PhotoRegionField`를 렌더링한다. 따라서 사진을 고르기 전에 지역·시군을 정할 수 없다.
- 변경 후에는 사진이 0장인 초기 시트에서도 지역 선택 필드가 보여야 하며, 지도에서 이미 선택한 권역·시군은 초기값으로 유지되어야 한다.
- 저장 계약은 바꾸지 않는다. 업로드마다 `mapRegionCode`와 `mapCityCode`가 공통 초안 값으로 `POST /api/v1/me/photo-records`에 전송된다.

## 차단 기준

1. 사진 선택 전 지역을 고를 수 없거나, 선택 직후 파일 선택·추가를 하면 선택 값이 사라진다.
2. 지도에서 선택한 시군과 시트에 표시된 초기 선택이 다르거나, 업로드 요청의 지역 코드가 화면 선택과 다르다.
3. 권역만 바꾼 뒤 이전 권역의 시군 코드가 남아 잘못 저장된다.
4. 파일을 고르지 않고 시트를 닫았다가 열었을 때 지도 필터·확대·선택 핀이 초기화된다.
5. 업로드 중 지역을 바꿀 수 있거나 시트를 닫아 진행 중 요청의 결과를 사용자가 추적할 수 없게 된다.

## 수동 QA 체크리스트

### 1. 초기 선택과 변경

- [ ] 전체 지도 상태에서 사진 추가를 열면, 파일 선택 전에도 `위치에 표시할 지역` 선택 영역이 보인다.
- [ ] 지도에서 권역만 선택하고 열면 그 권역이 시트에 초기 표시되고, 시군은 미선택 상태다.
- [ ] 지도에서 권역과 시군까지 선택하고 열면 두 값이 시트에 초기 표시된다.
- [ ] 시트에서 다른 권역을 선택하면 이전 시군 선택이 즉시 해제된다.
- [ ] 같은 권역에서 시군만 바꾼 뒤 파일을 추가해도 새 시군 선택이 유지된다.
- [ ] 선택 지우기를 누르면 권역·시군이 함께 해제되며, 지역 미지정 업로드가 허용되는 기존 정책과 일치한다.
- [ ] 서버 위치 목록 요청이 실패해도 로컬 161개 목록으로 권역·시군 선택과 업로드를 계속할 수 있다.

### 2. 파일 선택과 요청 계약

- [ ] 지역을 먼저 선택 → JPEG/PNG/WebP/HEIC/HEIF 파일 1장을 선택 → 추가 순서에서 선택 위치가 그대로 남는다.
- [ ] 지역을 먼저 선택 → 여러 파일을 선택하면 모든 `POST /api/v1/me/photo-records` 요청의 `mapRegionCode`, `mapCityCode`가 동일하다.
- [ ] 지역을 바꾼 뒤 기존 대기 파일을 업로드하면 **바꾼 후의** 공통 위치가 모든 대기 파일에 적용됨을 확인한다.
- [ ] 지역 미선택 업로드는 두 위치 필드를 비우거나 null로 보내며, 기존처럼 보관함에는 저장되고 지도에는 위치 미지정 안내로 남는다.
- [ ] 업로드 중에는 지역 선택·파일 선택·닫기가 비활성화되고, 빠르게 여러 번 눌러도 중복 POST가 생기지 않는다.
- [ ] 일부 실패 후 재시도하면 실패한 파일만 다시 전송하되, 이미 고른 위치 값은 유지된다.

### 3. 지도 상태와 반응형 회귀

- [ ] 시트를 열고 지역을 변경한 뒤 닫아도, 지도 자체의 권역·시군 필터, 확대, 선택 핀은 시트 열기 전 상태를 유지한다. 시트 안의 변경은 업로드 초안일 뿐 지도 필터를 바꾸지 않아야 한다.
- [ ] 업로드 완료 후에도 지도는 맨 위나 전체 보기로 이동하지 않고 기존 시점에 남는다. 현재 필터와 일치하는 새 핀만 갱신돼 보인다.
- [ ] 모바일 360×800, 390×844에서 초기 지역 선택 → 시군 검색 → 파일 선택 → 업로드 버튼이 시트 내부 스크롤로 모두 접근 가능하다.
- [ ] 모바일 키보드를 열고 시군을 검색한 뒤 닫아도 선택값·파일 대기열이 유지되고 하단 내비게이션과 겹치지 않는다.
- [ ] 데스크톱 우측 시트에서도 지역 선택 목록은 시트 내부에서만 스크롤되며 지도 클릭이나 핀 포커스가 뒤에서 일어나지 않는다.

## 권고 구현·검증 메모

- 지역 필드는 파일 대기열 조건 밖에 두고, `items.length === 0`일 때도 렌더링해야 한다. 파일 선택 전에는 장소·메모·파일 목록·업로드 버튼만 숨겨도 된다.
- 초기 위치는 시트가 열릴 때 지도 필터를 복사한 값이어야 한다. 이후 시트 안에서 바꾼 값이 지도 필터 상태를 직접 변경하면 안 된다.
- `mapRegionCode`가 바뀌면 `mapCityCode`를 반드시 null로 초기화한다. 이 규칙은 지도 선택과 업로드 시트 선택 양쪽에서 동일해야 한다.
- 자동화 가능 최소 범위: 업로드 FormData에 권역·시군이 포함되는 경우, 권역 교체 시 시군 제거, 파일 0장일 때 지역 선택 필드 노출을 컴포넌트/브라우저 테스트로 추가한다.

## 사전 판정

구현 전 차단 이슈는 없다. 단, 현재 파일 0장 분기 안에 지역 선택 UI가 없는 것이 이번 변경의 직접 대상이며, 위 계약·회귀 항목을 실제 브라우저와 Network 요청으로 확인한 뒤 통합 판정해야 한다.
