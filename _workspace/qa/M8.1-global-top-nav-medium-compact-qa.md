# M8.1 전역 상단 내비게이션 중간 폭 축약 QA

- 검토일: 2026-09-11
- 범위: `TopNav`, `BottomTabBar`, 앨범 헤더 범위 복귀
- 판정: 통과

## 반응형 계약 대조

| 화면 폭 | 확인 결과 |
| --- | --- |
| 767px 이하 | `TopNav`는 숨겨지고 `BottomTabBar`가 표시된다. |
| 768px ~ 1023px | `TopNav`가 표시되며, 전역 메뉴 4개는 36px 아이콘 전용 버튼으로 표시된다. 줄바꿈은 발생하지 않는다. |
| 1024px 이상 | 전역 메뉴 아이콘과 텍스트 레이블이 함께 표시된다. |

- Tailwind 설정에 화면 폭 재정의가 없어 기본 `md = 768px`, `lg = 1024px`가 실제 기준이다.
- 생성 CSS에서 `md:max-lg`는 `min-width: 768px` 안의 `not all and (min-width: 1024px)` 조건으로 생성됨을 확인했다.

## 로그인 · 접근성 · 회귀 확인

- 비로그인: 우측 로그인 버튼과 아이콘 전용 전역 메뉴가 768px 폭에서 함께 한 줄에 배치된다.
- 로그인: 닉네임은 기존 `max-w-48`/말줄임을 유지하고, 로그아웃과 사용자 메뉴 동작은 변경되지 않는다.
- 아이콘 전용 메뉴: `aria-label`, `title`, 화면 낭독기용 레이블을 제공하며 아이콘 자체는 `aria-hidden`이다.
- 활성 메뉴 스타일, 각 `NavLink`의 경로 및 `/me`를 닉네임 메뉴에서 제공하는 기존 규칙을 유지한다.
- 요청 범위와 무관했던 앨범 헤더의 540px 아이콘 전용 규칙은 제거되어, 앨범의 스토리·맵·보관함은 기존 텍스트 전환부로 복귀했다.
