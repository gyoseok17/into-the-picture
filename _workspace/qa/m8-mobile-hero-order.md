# M8 모바일 히어로 순서 검토

- 검토일: 2026-08-14
- 범위: `frontend/src/pages/HomePage.tsx` 히어로의 화면 폭별 요소 순서와 높이

## 코드 판정

- 통과: 본문 블록이 `order-1`, 대표 사진 블록이 `order-2`다. 기본(모바일) flex/grid 순서는 본문 → 사진이므로, 모바일 첫 화면에는 제목과 소개 문구가 먼저 노출된다.
- 통과: `md:grid-cols-[1.05fr_0.95fr]`부터 두 블록이 두 열로 배치된다. 본문이 왼쪽, 사진이 오른쪽이며 DOM 순서도 동일하므로 별도의 `md:order-*`가 필요하지 않다.
- 통과: 사진은 모바일에서 `min-h-[42vh]`, 데스크톱에서는 `md:min-h-full`을 사용한다. 모바일에서 사진이 과도하게 커져 제목을 밀어내는 구조는 아니다.

## 확인 포인트

- 360px: 상단부터 작은 브랜드 문구, 제목, 설명, 아래로 이동 링크가 사진보다 먼저 보이는지 확인한다. 사진은 본문 다음에 시작하고 최소 높이 42vh를 유지해야 한다.
- 768px: `md` 구간에서 한 화면에 왼쪽 본문과 오른쪽 사진이 동시에 나타나는지 확인한다. 사진 오버레이의 장소·제목이 하단에서 잘리지 않아야 한다.
- 공통: 대표 수상작 데이터가 없을 때도 민트 대체 영역이 같은 순서와 높이로 표시되는지 확인한다.

## 위험 및 권고

- 현재 순서는 사용자 요구(모바일에서 사진이 맨 위에 나오지 않음)와 일치한다.
- 실제 브라우저에 이전 HMR 상태가 남아 있으면 새로고침 후 확인한다. 코드상에는 사진 우선 순서를 만드는 클래스가 없다.
