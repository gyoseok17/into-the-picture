# M8.1 다중 사진 추가: 날짜 전용 직접 촬영일 QA

- 검토일: 2026-08-28
- 범위: `BatchPhotoUploadPanel`의 공통 촬영일 입력을 날짜만 받도록 바꾸고, 직접 지정한 날짜를 각 업로드 요청의 로컬 자정 `takenAt`으로 전송하는 변경.
- API 계약: `POST /me/photos`의 선택 `multipart/form-data` 필드 `takenAt`은 Spring `ISO.DATE_TIME`으로 파싱되는 `LocalDateTime`이다. 날짜 전용 입력값 `YYYY-MM-DD`는 프런트에서 `YYYY-MM-DDT00:00:00`으로 변환한다. 시간대 오프셋/UTC 표기는 보내지 않는다.

## 정적 교차 검토

| 항목 | 확인 결과 | 판정 |
| --- | --- | --- |
| 입력 UI | 공통 직접 입력이 `type="date"`이며 시·분 선택 UI가 없다. | 통과 |
| 직접값 전송 | `toManualTakenAt`이 비어 있지 않은 날짜에만 `T00:00:00`을 붙이고, 업로드 항목마다 그 값을 우선 적용한다. | 통과 |
| 서버 타입 | 컨트롤러는 `@DateTimeFormat(ISO.DATE_TIME) LocalDateTime`을 받고 서비스는 요청값이 있을 때 EXIF보다 우선한다. | 통과 |
| 빈값·EXIF | 날짜가 비어 있으면 파일별 EXIF 값으로 폴백하고, EXIF도 없으면 `appendOptionalField`가 `takenAt` 자체를 생략한다. | 통과 |
| 재시도 | 재시도도 `uploadPending`의 같은 공통 상태와 파일별 EXIF를 사용한다. 성공 항목은 대상에서 제외한다. | 통과 |

## 수동·네트워크 확인 항목

- [ ] 날짜 선택기는 연·월·일만 선택할 수 있고 시간 입력/표시는 없다.
- [ ] `2026-08-28`을 직접 지정해 EXIF가 서로 다른 두 장을 업로드한다. 각 multipart 요청에 정확히 `takenAt=2026-08-28T00:00:00`이 있으며, 응답 JSON과 앨범·지도 표시의 날짜가 모두 8월 28일이다.
- [ ] 직접 지정일을 비운 뒤 업로드한다. 파일별 EXIF가 있는 사진은 각 원본의 `takenAt`으로 전송되고, EXIF 없는 사진은 빈 문자열이 아니라 `takenAt` 필드가 없는지 확인한다.
- [ ] EXIF가 없는 JPEG 및 HEIC/HEIF를 함께 선택한다. 빈 직접값은 서버 EXIF 재추출 또는 `null`을 허용하고, 날짜를 직접 지정하면 모두 해당일 자정으로 저장되는지 확인한다.
- [ ] 직접 지정일을 입력했다가 비운 뒤, 실패 항목을 재시도한다. 이전 날짜가 남아 전송되지 않고 파일별 EXIF/필드 생략 규칙으로 돌아가는지 확인한다.
- [ ] 업로드 중 하나를 실패시킨 뒤 재시도한다. 성공한 사진은 재전송하지 않고, 실패 항목은 같은 날짜 전용 직접값(또는 각자의 EXIF)으로 전송되는지 확인한다.
- [ ] 한국 표준시뿐 아니라 UTC-오프셋 브라우저 환경에서도 직접 지정일이 전날/다음 날로 표시·저장되지 않는지 확인한다. 전송값은 반드시 오프셋 없는 로컬 `LocalDateTime`이어야 한다.
- [ ] 기존 단일 사진 추가·사진 수정의 일시 입력 동작과 `PATCH /me/photos/{id}`의 `takenAt: null`로 날짜 지우기 계약은 변경되지 않았는지 확인한다.

## 회귀 위험과 차단 기준

- 차단: 날짜 전용 값이 `YYYY-MM-DD` 그대로 전송되어 서버가 400을 반환함.
- 차단: 직접 지정일이 EXIF로 덮이거나, 빈 직접값이 이전 날짜를 재전송함.
- 차단: `T00:00:00`이 UTC 변환으로 전날/다음 날이 됨.
- 권고: 항목 날짜 라벨은 현재 `new Date('YYYY-MM-DD')`를 사용한다. 이 형식은 브라우저에서 UTC로 해석될 수 있으므로 UTC 음수 시간대에서 전날로 보일 가능성이 있다. 날짜 전용 표시에는 문자열을 직접 표시하거나 로컬 날짜 구성 방식을 쓰는지 실제 대상 브라우저에서 확인할 것.

## 최종 판정

정적 계약 검토는 통과다. 날짜 전용 입력·로컬 자정 변환·서버 `LocalDateTime` 수용·EXIF/빈값 폴백은 코드 경로에서 일치한다. 실제 multipart 요청과 시간대별 화면 표시는 로그인 가능한 브라우저 환경에서 위 체크리스트로 최종 확인이 필요하다.
