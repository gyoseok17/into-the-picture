# M8 홈 기능 인덱스 QA 수용 기준

- 작성일: 2026-08-14
- 역할: 통합 QA
- 범위: 홈 히어로 다음에 추가하는 `한눈에 둘러보기` 기능 인덱스. 코드 변경 없음.

## 목적과 배치

첫 방문자가 현재 서비스의 네 가지 핵심 기능을 훑고 바로 이동할 수 있게 한다. 다만 홈의 사진 중심 에디토리얼 흐름을 기능 카드 모음으로 되돌리지 않는다.

- 배치: 히어로의 다음, `추천 여행지`보다 앞.
- 형식: `01` 번호, 기능명, 한 줄 설명, 이동 화살표를 가진 네 개의 실제 링크. 별도의 큰 CTA 버튼이나 아이콘 타일은 만들지 않는다.
- 순서: 수상작 보기 → 사진 찾기 → 혼잡도 보기 → 내 사진 남기기.
- 각 항목의 클릭 영역은 항목 전체이고, 최소 44×44px를 보장한다.

## 경로·인증 계약

| 항목 | 목적지 | 비로그인 수용 기준 |
| --- | --- | --- |
| 수상작 보기 | `/contests` | 바로 이동한다. |
| 사진 찾기 | `/explore` | 바로 이동한다. |
| 혼잡도 보기 | `/crowd` | 바로 이동한다. |
| 내 사진 남기기 | `/compare` | 항목을 숨기지 않는다. `로그인 후 내 사진을 기록할 수 있어요`처럼 사전 안내하고, 클릭하면 기존 `RequireAuth` 로그인 흐름으로 보낸 뒤 원래 목적지(`/compare`)로 돌아온다. |

`/me`는 로그인 사용자 전용 관리 화면이므로, 이 인덱스의 네 번째 진입점은 사진 기록을 시작하는 `/compare`를 사용한다. 로그인 사용자는 동일한 문구·목적지로 이동해도 된다.

## 모바일 수용 기준

- 360px에서는 4개 항목을 세로로 순서대로 보여 준다. 가로 스크롤은 사용하지 않는다. 기능 자체를 훑는 목적에 가로 이동은 발견성을 낮춘다.
- 768px 이상에서는 한 줄 4열 또는 2×2 배치를 허용한다. 긴 기능명·설명이 두 줄이 되어도 인접 항목의 높이와 화살표 위치가 깨지지 않아야 한다.
- 인덱스 바로 아래의 `추천 여행지` 가로 필름과 이동 축이 섞이지 않도록, 인덱스에는 가로 스크롤·스냅·드래그를 넣지 않는다.
- 모바일 하단 탭 바에 마지막 항목이 가려지지 않도록 현재 `AppShell`의 하단 여백 안에서 실제 기기 높이로 확인한다.

## 접근성·키보드 기준

- 문서 구조는 `h2` 제목 뒤에 의미 있는 목록(`ol` 또는 목록 역할)과 링크로 구성한다. 번호는 장식이 아니라 목록 순서를 보완한다.
- Tab 순서는 히어로의 `장면을 따라 내려가기` 다음에 인덱스 01→04, 그 다음 추천 여행지 링크·필름 순서여야 한다. CSS `order`로 시각 순서와 포커스 순서를 다르게 만들지 않는다.
- 각 링크는 기능명과 설명을 함께 읽을 수 있는 접근 가능한 이름을 가져야 한다. 화살표 아이콘만으로 목적지를 전달하지 않는다.
- 포커스 링은 민트 배경에서도 명확히 보여야 하며, hover 효과만으로 현재 항목을 알리지 않는다.
- `내 사진 남기기`의 로그인 필요 상태는 색이나 자물쇠 아이콘만으로 구분하지 말고 텍스트로도 제공한다.

## 현재 홈 흐름과의 간섭 점검

- 이 인덱스는 기능의 개요만 제공한다. 추천 수상작·혼잡도·검색 섹션의 실제 CTA를 대체하거나 중복 설명하지 않는다.
- 배경은 전체 홈의 단일 아이보리/민트 톤을 유지하되, 또 하나의 큰 색상 카드·강한 그림자·그라데이션 패널로 만들지 않는다. 얇은 구분선과 여백을 우선한다.
- 항목마다 서로 다른 색·큰 아이콘·버튼을 반복하면 사용자가 어디부터 눌러야 하는지 오히려 분산되고, 기존 에디토리얼 의도가 약해진다.
- 네 번째 항목은 로그인 여부에 따라 레이아웃이 출렁이거나 사라지지 않아야 한다. 인증 초기화 중에도 중립적인 안내 상태를 유지한다.

## 최종 QA 시나리오

1. 360px, 768px, 1280px에서 인덱스 네 항목과 다음 섹션의 시작점이 한 화면 흐름에서 자연스럽게 보이는지 확인한다.
2. 비로그인 상태에서 네 번째 항목을 눌러 로그인 후 `/compare`로 복귀하는지 확인한다.
3. 로그인 상태에서 네 항목이 모두 예상 경로로 이동하는지 확인한다.
4. 키보드만으로 홈 진입부터 01~04, 추천 여행지 필름까지 순서대로 이동하고 포커스가 보이는지 확인한다.
5. 화면 판독기로 각 링크의 기능명, 설명, 로그인 필요 안내가 중복·누락 없이 읽히는지 확인한다.

## 판정

위 기준을 충족하면 구현 진행 가능. 비로그인에서 내 사진 기능의 목적지 또는 로그인 복귀가 불명확하거나, 모바일에서 인덱스를 가로 이동으로 숨기는 경우는 차단 이슈다.
