# M8.1 앨범 지도 포커스·묶음·선택 해제 QA

작성일: 2026-08-28
상태: 구현 전 검토 완료 / 최종 수동 검증 대기

## 점검 대상과 현재 구조

- `PhotoRecordMapView`는 `regionFilter`로 권역·도시를, `selected` 배열로 마커 묶음의 사진 목록을 따로 관리한다.
- `groupPins`는 지도 좌표를 약 4% 격자로 반올림해 가까운 사진을 하나의 마커로 합친다. 마커 클릭 시 현재는 목록 패널만 연다.
- `AlbumMapSvg`는 원본 SVG 경로에 `data-region-code`를 붙여 권역 클릭을 전달하고, 선택 권역은 채움색으로 표시한다.
- 바깥 지도 컨테이너 클릭은 현재 `selected`만 닫는다. 권역 필터는 해제하지 않는다.

## 구현 계약 확인

| 사용자 동작 | 기대 결과 | 회귀 방지 조건 |
| --- | --- | --- |
| 단일 마커 클릭 | 해당 좌표를 중심으로 지도 아트워크가 확대·이동하고 사진 카드가 즉시 보인다 | 선택 패널이 지도 밖으로 밀리거나 마커가 클릭 불가 상태가 되지 않는다 |
| 같은/가까운 사진 묶음 클릭 | 묶음 수를 표시하고, 사진 목록에서 모든 사진을 구분해 선택할 수 있다 | 한 장만 보이거나 스크롤이 막히지 않는다 |
| 선택 권역 재클릭 | 권역·도시 필터와 사진 선택을 모두 비우고 전체 지도로 돌아간다 | 이미 선택한 권역을 다시 눌렀을 때 같은 필터를 재설정하지 않는다 |
| 지도 빈 공간 클릭 | 권역·도시 필터, 확대, 사진 선택을 모두 해제한다 | SVG의 권역·마커·사진 카드 클릭은 빈 공간 클릭으로 오인되지 않는다 |
| 도시 칩 선택 후 해제 | 도시 필터까지 함께 해제해 전체 마커를 다시 표시한다 | `mapCityCode`만 남아 빈 결과 상태가 되지 않는다 |

## 구현 전 발견한 위험

1. 현재 SVG 래퍼는 클릭 이벤트를 내부에서 처리한다. 지도 바탕의 빈 공간 해제와 권역 경로 클릭을 구분하려면 `onChoose`에 "같은 권역이면 해제" 규칙을 두고, 경로가 아닌 SVG 빈 곳 클릭은 상위 컨테이너까지 전파되게 해야 한다.
2. 마커·사진 카드 모두 상위 컨테이너 클릭 전파를 막아야 한다. 그렇지 않으면 마커 클릭 직후 선택/확대 상태가 즉시 해제될 수 있다.
3. 확대는 지도 그림과 마커 좌표에 같은 변환 기준을 적용해야 한다. 그림만 확대하면 마커가 실제 장소에서 어긋나고, 마커만 확대하면 권역 클릭 영역과 어긋난다.
4. 현재 `groupPins`의 4% 격자는 가까운 두 관광지를 한 묶음으로 만들 수 있다. 묶음 UI에는 장소명·날짜·썸네일을 모두 제공하고, 선택 후 다른 묶음을 눌렀을 때 이전 목록을 교체해야 한다.
5. 권역 필터 결과가 0장일 때에도 권역 재클릭/빈 공간 클릭으로 복귀할 수 있어야 한다. 빈 결과 안내가 화면의 클릭을 가로막으면 안 된다.
6. 모바일에서 확대된 지도 위 카드와 하단 권역·도시 패널이 겹칠 수 있다. 작은 화면(360px)에서는 하나를 닫거나 카드가 스크롤 가능한 높이를 유지해야 한다.
7. 사진 API 재조회·업로드·삭제 후 `selected`가 삭제된 사진 ID를 계속 참조할 수 있다. `pins` 변경 시 선택 묶음을 현재 핀 목록과 교차 검증하거나 닫아야 한다.

## 최종 수동 QA 체크리스트

### 기본 선택과 해제

- [ ] 미선택 전체 지도에서 권역을 누르면 해당 권역만 강조되고 마커가 필터링된다.
- [ ] 같은 권역을 한 번 더 누르면 강조·도시 패널·필터·확대·사진 카드가 모두 사라지고 전체 마커가 돌아온다.
- [ ] 다른 권역을 누르면 이전 권역과 사진 카드는 닫히고 새 권역만 선택된다.
- [ ] 도시를 고른 뒤 선택 권역을 다시 누르거나 지도 빈 공간을 누르면 도시 조건도 함께 해제된다.
- [ ] SVG의 바탕 빈 곳을 눌렀을 때 전체 지도로 복귀한다.

### 마커 포커스와 사진 표시

- [ ] 단일 사진 마커 클릭 시 그 마커가 지도 중심 부근으로 확대되고 사진 카드가 보인다.
- [ ] 사진 카드의 썸네일·장소명·촬영일이 선택 마커의 데이터와 일치한다.
- [ ] 확대 중 다른 마커를 눌러도 새 위치와 새 사진으로 정상 전환된다.
- [ ] 사진 카드 닫기는 사진 카드만 닫고, 권역 필터 및 확대 해제 정책이 설계와 일치한다.
- [ ] 빈 공간 클릭은 포커스·카드·권역·도시 필터를 한 번에 초기화한다.

### 겹침/묶음

- [ ] 동일 좌표 사진 2장 이상은 하나의 숫자 마커로 보인다.
- [ ] 숫자 마커 클릭 시 누락 없이 모든 사진을 확인할 수 있고 목록이 넘치면 스크롤된다.
- [ ] 가까운 서로 다른 장소가 묶인 경우에도 각 사진의 장소명이 구분되어 보인다.
- [ ] 묶음 사진 중 하나를 선택하는 후속 동작이 있다면 선택 대상이 명확히 표시된다.

### 반응형·회귀

- [ ] 360px 모바일에서 상단 조작줄, 지도, 마커, 사진 카드, 하단 권역 패널이 서로 가려지지 않는다.
- [ ] PC에서 확대 후에도 지도 비율과 마커 좌표가 어긋나지 않는다.
- [ ] 권역 코드가 없는 기존 사진도 좌표 기반 보정으로 해당 권역 필터에서 계속 보인다.
- [ ] 사진이 0장인 권역과 지도 핀이 0개인 앨범 모두에서 선택 해제와 뒤로가기가 가능하다.
- [ ] 업로드·삭제 후 지도 데이터 갱신 시 사라진 사진 카드나 잘못된 묶음 수가 남지 않는다.

## QA 판정 기준

- 차단: 선택 해제 불가, 마커 클릭 뒤 즉시 상태 해제, 확대 시 마커/지도 위치 불일치, 묶음의 사진 누락, 모바일에서 사진 카드 조작 불가.
- 권고: 확대 배율·애니메이션 시간은 멀미를 유발하지 않도록 실제 모바일 기기에서 조정한다.
- 최종 판정 보류: 구현 도착 뒤 빌드와 위 수동 시나리오를 교차 검증한다.
