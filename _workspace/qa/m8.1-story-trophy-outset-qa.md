# M8.1 스토리 폴라로이드 바깥 트로피 QA

작성일: 2026-09-04
상태: 최종 검증 완료

## UI 계약

- 트로피는 폴라로이드 좌상단 바깥으로 살짝 돌출되고, 사진 및 흰 프레임 여백을 가리지 않는다.
- 카드 상단 여백은 기존 폴라로이드 비율로 복원하며, marker 위치만 outer wrapper의 음수 top/left offset으로 조정한다.
- outer wrapper와 상위 story surface는 marker를 잘라내지 않고, marker는 stack 종이와 카드 위에 보인다.
- 연결 사진이 0장이면 marker를 렌더링하지 않는다. 숫자는 연결된 개별 사진 수다.

## 최종 체크리스트

- [x] 이미지·흰 프레임과 marker가 겹치지 않고 상단 여백이 불필요하게 커지지 않는다.
- [x] outer wrapper와 ancestor가 돌출 marker를 clip하지 않는다.
- [x] 2~3장 stack, 회전 transform, 카드 선택 checkbox와 z-index가 충돌하지 않는다.
- [ ] 320px 폭에서 화면 가장자리와 회전된 stack의 marker가 잘리지 않는지 시각 확인이 필요하다.
- [x] 일반 사진 marker 미노출, 연결 수 집계, thumbnail·mini-card·삭제 cache 회귀가 없다.
- [x] `tsc -b`, `git diff --check`를 통과했다.

## 최종 소스·타입 검증 (2026-09-04)

### 통과

- marker는 clip 없는 outer story wrapper의 `absolute -left-5 -top-5` 형제로 이동했고, white frame의 상단 여백은 기본 `p-2`로 복원됐다. 따라서 사진과 흰 프레임 내부를 가리지 않는다.
- outer wrapper는 `overflow`를 지정하지 않고, 뒤 stack은 z-0·white frame은 z-10·marker는 z-20이라 2~3장 stack과 회전에서도 marker가 뒤에 가려지지 않는다.
- marker는 연결된 개별 사진이 없으면 `null`이고, count는 `getConnectedPhotoCount`가 연결 여부를 photo 단위로 집계한다.
- story card 내부 checkbox는 우측 상단, marker는 outer 좌측 상단이라 충돌하지 않는다. thumbnail별 트로피, 현재 사진 mini result card, delete cache invalidation도 기존 개별 사진 계약을 유지한다.
- `tsc -b` 통과, `git diff --check` 공백 오류 없음(LF/CRLF 경고만 출력).

### 수동 확인 항목

- 실제 320px 폭에서 화면 가장자리 및 회전된 2~3장 stack의 돌출 marker가 잘리지 않는지 시각 확인.
