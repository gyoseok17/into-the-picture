# M8.1 지도 큰 사진 수상작 비교 트로피 QA

## 계약 대조

- 지도 패널의 현재 큰 사진은 `photo.id`로 비교 기록을 필터링한다. 연결된 현재 사진에만 `PhotoComparisonTrophyBadge`가 렌더링된다.
- 트로피는 사진 좌측 상단의 아이콘 전용 버튼이며, 비교가 없으면 렌더링되지 않는다. 아이콘 전용 동작은 `aria-label`과 `title`로 설명한다.
- 트로피 클릭은 `stopPropagation()` 뒤 `PhotoComparisonResultDialog`를 연다. 따라서 큰 사진 클릭의 확대 보기와 페이지 이동을 일으키지 않는다.
- 사진 아래의 `PhotoComparisonBadge`/`비교 연결` 영역은 `MapFocus`에서 제거됐다. 여러 사진의 아래 목록에는 기존 트로피만 남아 연결 사진을 구별한다.
- 여러 비교 기록은 결과 다이얼로그의 기존 썸네일 전환으로, 단일 사진 기록은 큰 사진의 트로피로 접근한다.

## 상호작용·적층 검토

- 큰 사진 버튼과 트로피 버튼은 중첩되지 않은 형제 요소다. 트로피가 이미지 위 `z-10`에 있고 클릭 전파도 중단하므로 확대 핸들러와 충돌하지 않는다.
- 비교 결과 다이얼로그는 포털의 `z-[100]`으로 지도 패널보다 위에 열린다. Escape·배경·닫기 후 트로피 버튼으로 초점이 돌아가며 지도 선택 상태는 유지된다.
- 다중 사진에서 아래 썸네일은 `setPhotoIndex`만 호출한다. 연결된 사진으로 바꾸면 큰 사진 트로피가 나타나고, 미연결 사진으로 바꾸면 사라진다.
- 모바일·PC 모두 절대 배치 기준 부모가 큰 사진의 `relative` 컨테이너이며, 28px 터치 버튼과 고대비 아이콘을 사용한다. 실제 물리 기기 탭 영역은 수동 확인 권고로 남긴다.

## 자동 검증

- `npm run typecheck` 통과
- `npm run build` 통과
- `git diff --check` 통과. 기존 작업 트리의 CRLF 경고만 있으며 차단 오류는 없다.
- 빌드의 500KB Vite 청크 경고는 기존 비차단 권고다.
