# M8 추천 여행지 출처 문구 · 가로 필름 스크롤 검토

- 검토일: 2026-08-14
- 범위: 홈 추천 여행지 섹션의 출처 문구와 가로 필름 스크롤바 비표시
- 코드 변경: 없음

## 확인 결과

### 출처 문구

- 홈의 추천 항목은 `useContests({})`의 첫 페이지를 사용한다.
- 해당 API는 `ContestWork`를 조회하며, 이 데이터는 외부 `PhokoAwrdService`에서 동기화한 공모전 수상작이다. 설계 문서도 한국관광공사의 관광사진·공모전 수상작을 사용한다고 명시한다.
- 따라서 추천 여행지 설명에는 아래처럼 **한국관광공사 관광사진 공모전 수상작**임을 밝히는 표현이 실제 데이터와 일치한다.

> 한국관광공사 관광사진 공모전 수상작에서, 다음 여행의 장면을 골라보세요.

- `추천 여행지`라는 제목은 장소 자체가 큐레이션된 것처럼 읽힐 수 있으므로, 위 문구처럼 사진의 출처와 수상작이라는 성격을 함께 표시하는 것이 오해를 줄인다.

### 스크롤바 비표시

- 현재 필름은 `overflow-x-auto`와 `snap-x snap-mandatory`로 실제 가로 스크롤·스냅을 제공한다. 스크롤바만 숨기면 마우스 휠/터치 드래그/트랙패드 동작은 유지된다.
- 각 항목이 링크이므로 키보드 Tab으로 다음 항목에 이동할 때 브라우저가 보이지 않는 항목을 화면 안으로 가져온다. 따라서 키보드 접근 자체는 유지된다.
- 다만 스크롤바를 완전히 감추면 데스크톱 사용자에게 가로로 더 볼 수 있다는 단서가 사라진다. 첫 카드의 일부만 보이게 하는 현재 폭, 제목의 `사진을 옆으로 넘기며` 안내, 스냅 동작을 유지해야 한다.
- 권장 구현은 필름 컨테이너에만 브라우저별 스크롤바 숨김을 적용하는 것이다. `scrollbar-width: none`, `-ms-overflow-style: none`, `::-webkit-scrollbar { display: none; }` 조합이면 기능을 바꾸지 않는다. 상위 홈 컨테이너에 적용하면 세로 스크롤까지 영향을 줄 수 있으므로 금지한다.
- 모바일 360px, 데스크톱 1280px에서 터치/트랙패드로 두 번째·마지막 카드까지 이동 가능한지, Tab 포커스가 보이는지 최종 확인이 필요하다.

## QA 판정

**진행 가능.** API·데이터 계약 변경 없이 문구와 필름 컨테이너의 시각 처리만 변경한다. 구현 후에는 스크롤바가 보이지 않아도 가로 이동과 키보드 포커스가 유지되는지만 확인하면 된다.
