# M8.1 인라인 수상작 비교 가운데 화살표 제거 QA

## 범위

- 대상: 앨범·수상작 상세 위에서 여는 `PhotoComparisonResultDialog`의 데스크톱 비교판.
- 제외: 독립 `사진 놓기` 결과 화면과 공개 관리의 기존 비교 레이아웃.

## 계약·구현 교차 확인

- `PhotoComparisonResultDialog`만 `ComparisonPlacementPair`에 `showDesktopDirection={false}`를 전달한다.
- 공통 비교판은 기본값을 `true`로 유지한다. 따라서 `ComparePage`의 독립 결과 화면은 기존 데스크톱 중앙 `ArrowRight`를 계속 사용한다.
- 인라인 창은 화살표 열 없이 `md:grid-cols-2`로 수상작·내 사진을 같은 두 열에 배치한다. 모바일에서는 기존 단일 열 그리드 동작을 유지한다.
- `PHOTO_ONLY`는 기존처럼 내 사진 하나만 표시하며, 이 변경으로 화살표·레이아웃 조건이 추가되지 않는다.
- 다이얼로그의 제목, 닫기 버튼, 비교 대상 전환 목록, Escape·배경 닫기·초점 복귀는 변경되지 않았다.

## 검증

- `npm run typecheck` 통과.
- `npm run build` 통과. Vite 500kB 청크 경고만 기존 비차단 권고로 남음.
- `git diff --check` 통과. 기존 작업 트리의 CRLF 경고만 출력됨.

## 판정

통과. 인라인 확대 비교창에서만 데스크톱 화살표를 제거했고, 공통 컴포넌트 기본값으로 다른 비교 레이아웃의 기존 동작을 보존했다. 실제 PC·모바일 브라우저에서 인라인 창을 열어 두 사진 사이 여백이 의도대로 보이는지만 최종 수동 확인 권고로 남긴다.
