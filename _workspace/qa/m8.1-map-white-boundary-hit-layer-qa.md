# M8.1 지도 흰 경계 기반 클릭 레이어 QA 기준

작성일: 2026-08-27
범위: 앨범 지도 PNG의 흰 경계와 권역 SVG 클릭 레이어의 일치 여부. 프로덕션 코드 수정 없음.

## 사용자 관점의 합격 정의

사용자는 색칠된 블록을 누른다고 느껴야 하고, 두 블록 사이의 **흰 경계는 어느 권역에도 속하지 않아야** 한다.

- 권역 강조 fill·hover·focus 효과가 흰 경계를 덮거나 옆 블록에 번져 보이면 불합격이다.
- 흰 경계 한가운데를 클릭/탭했을 때 선택이 바뀌면 불합격이다.
- 각 색 블록의 가장자리 안쪽을 눌렀을 때는 해당 블록이 선택되어야 한다. 흰 경계에 닿기 직전의 색 영역을 누르기 어렵다고 느껴지면 불합격이다.
- 강조 상태에서도 원래 흰 경계가 모든 인접 블록 사이에 연속해서 보여야 한다. 선택 색의 stroke는 SVG path 양쪽으로 퍼지므로, 흰 경계를 가리는 테두리를 기본값 또는 선택 상태에 사용하면 안 된다.

## 허용 오차

원본 지도는 `1024 × 1536` 좌표계이고 SVG도 반드시 같은 `viewBox="0 0 1024 1536"`와 같은 2:3 컨테이너를 써야 한다.

| 항목 | 허용 | 불허 |
| --- | --- | --- |
| 내부 흰 경계와 visible highlight | 경계의 색 블록 쪽으로 최대 원본 4px(일반 모서리·직선), 곡선/접점은 최대 6px **안쪽** | 흰 선 위 또는 이웃 색 블록 방향으로 1px이라도 넘어감 |
| 클릭 영역 | 색 블록 내부 전체. 흰 경계 중심은 비클릭 | 터치 편의를 이유로 hit 영역이 흰 경계·옆 블록까지 확장됨 |
| 실제 화면에서의 시각 오차 | PC 일반 표시에서 최대 1 CSS px inset, 작은 모바일에서는 최대 2 CSS px inset | 흰 선이 강조 fill/stroke로 끊겨 보임 |
| 블록 내부 공백 | 장식 라벨·제어가 아닌 모든 색 영역에서 클릭 가능 | 큰 무반응 구멍, 경계 겹침으로 두 권역이 동시에 후보가 되는 구간 |

오차는 대칭이 아니다. 시각·터치 보정이 필요하면 **언제나 색 블록 안쪽으로만** 물러나야 한다. 흰 경계는 완전한 안전 영역으로 남긴다.

## 구현 전 구조 확인

- `RegionArtwork`는 현재 원본 좌표계 path를 `viewBox="0 0 1024 1536"` 위에 놓는다. 유지해야 한다.
- 이미지와 SVG는 같은 `relative aspect-[2/3]` 래퍼에 있어야 한다. 이미지에 `object-contain` 여백이 생기는 더 넓은 부모에 SVG를 붙이면 실제 그림과 path가 비율상 어긋난다.
- `path`의 SVG stroke는 중심선을 기준으로 양쪽에 칠해진다. 현재의 `stroke-primary/60`처럼 보이는 stroke는 경계 위로 번질 수 있으므로, 흰 경계를 보장하려면 기본 stroke를 없애거나 path를 안쪽으로 inset한 별도 강조 형태를 사용해야 한다.
- 영역끼리 path가 겹치지 않게 하고, 흰 경계 부분에는 어떤 path도 두지 않는다. 선택 레이어의 z-index가 사진 핀·헤더보다 올라가는 경우에는 선택 모드 동안만 핀을 비활성화하고, 일반 지도 열람에서는 경계 레이어가 핀 클릭을 가로채지 않게 한다.

## 검수 절차

1. **정적 정합**: 원본 PNG 위에 SVG path 외곽선만 디버그로 겹쳐 8개 권역(제주 포함)의 모든 인접 경계를 확대 확인한다. 흰 선 중심을 path가 넘는 부분은 경계별로 수정한다.
2. **경계 3점 테스트**: 각 인접 권역 경계에서 `왼쪽/위 블록 안쪽`, `흰 선 중앙`, `오른쪽/아래 블록 안쪽`을 차례로 클릭한다. 결과는 `A 선택 → 변화 없음 → B 선택`이어야 한다. 모든 주요 경계·3권역 접점·제주 외곽에 반복한다.
3. **PC 화면**: 100%, 125%, 150% 브라우저 확대에서 hover·선택·focus 상태를 확인한다. 브라우저 확대에 따라 흰 경계가 사라지거나 클릭 권역이 달라지면 불합격이다.
4. **모바일 화면**: 320px·375px·430px 폭에서 실제 탭으로 같은 3점 테스트를 한다. 스크롤 시작 동작은 선택으로 처리하지 않고, 한 탭은 한 번만 선택된다.
5. **저장 회귀**: 각 권역에서 도시를 하나 선택해 업로드하고 새로고침·지도 재진입 후 같은 권역이 강조/필터/핀 위치에 반영되는지 확인한다. 흰 경계 오차를 고치면서 권역 코드 매핑을 바꾸지 않는다.

## 판정 기록 형식

각 경계는 `권역 A ↔ 권역 B / PC·모바일 / A 내부·흰선·B 내부 / 통과·실패 / 스크린샷`으로 남긴다. 단순히 "대략 맞아 보임"으로는 통과시키지 않는다.
