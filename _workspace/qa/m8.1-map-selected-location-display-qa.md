# M8.1 지도 사진 추가: 선택 지역 표시 QA

- 검토일: 2026-08-28
- 역할: 통합 QA (코드 수정 없음)
- 범위: 지도에서 연 사진 추가 시트에서 자유 `placeName` 입력을 제거하고, 지도에서 선택한 권역·시군을 표시하는 변경

## 계약 기준

| 진입 경로 | UI 위치 값 | 업로드 payload |
| --- | --- | --- |
| 지도 사진 추가 | 지도에서 이미 선택한 권역·시군을 읽기 전용으로 표시 | `mapRegionCode`, `mapCityCode`는 현재 지도 선택 코드와 정확히 일치. `placeName`은 보내지 않음. |
| 일반 앨범 사진 추가 | 기존 `PhotoRegionField`와 장소 입력을 유지 | 사용자가 입력·선택한 값만 선택적으로 전송. |

- 지도 진입은 시군이 선택된 경우에만 사진 추가를 활성화한다. 권역만 선택했거나 선택값이 없으면 시트를 열 수 없다.
- 지도 시트는 위치를 다시 고르거나 지우는 컨트롤을 노출하지 않는다. 선택 지역 표시는 사용자가 값을 바꾸는 입력이 아니다.
- 서버의 multipart 선택 필드 계약은 그대로이며, 빈 값은 `appendOptionalField`가 payload에서 생략한다.

## 변경 전 정적 점검

- `MapUploadSheet`는 `BatchPhotoUploadPanel`에 `initialLocation`을 전달하고 `showLocationField={false}`를 사용한다. 지도 선택값을 공통 업로드 값으로 고정하는 경로는 존재한다.
- 현재 `BatchPhotoUploadPanel`의 파일 선택 뒤 입력 행에는 `placeName` 입력이 조건 없이 렌더링된다. 따라서 지도 시트에서 자유 장소 입력이 사라지고 선택한 권역·시군 표시로 대체되었는지는 구현 반영 뒤 반드시 재점검해야 한다.
- `uploadPhotoRecord`는 null·빈 문자열 필드를 multipart에서 생략한다. 지도 흐름에서 `placeName`을 `null`로 유지하면 자유 장소 값이 전송되지 않는다.

## 수동·네트워크 체크리스트

### 1. 지도 선택값과 표시 일치

- [ ] 수도권 → 서울특별시를 고르고 지도 `사진 추가`를 열면, 시트에 `수도권 · 서울특별시`(실제 카탈로그 레이블)가 표시된다.
- [ ] 다른 권역·시군(예: 제주 → 서귀포시)도 코드가 아닌 사람이 읽는 권역·시군 레이블로 표시된다.
- [ ] 시트를 닫은 뒤 지도에서 다른 시군을 고르고 다시 열면, 이전 표시가 남지 않고 새 선택값만 표시된다.
- [ ] 지도 시트 안에 권역 지도, 시군 검색, 시군 칩, 위치 지우기, 자유 장소 텍스트 입력이 남아 있지 않다.
- [ ] 시트의 권역·시군 표시는 포커스 가능한 편집 컨트롤이 아니며 업로드 중에도 선택값을 변경할 수 없다.

### 2. 시군 필수 진입 게이트

- [ ] 권역 미선택 및 권역만 선택 상태에서는 `사진 추가`가 비활성화되고 시군 선택 필요 이유가 전달된다.
- [ ] 시군 선택 후에만 버튼이 활성화되고, 열리는 시트의 표시값은 버튼 활성화에 사용한 시군과 동일하다.
- [ ] 시트가 열린 뒤 배경 지도 클릭, Escape/닫기, 업로드 성공·실패 후에도 지도 필터의 권역·시군 선택은 초기화되지 않는다.

### 3. multipart payload 및 빈값 회귀

- [ ] 지도에서 선택한 권역·시군으로 사진 1장을 올릴 때 각 `POST /me/photos`에 `mapRegionCode=<선택 코드>`와 `mapCityCode=<선택 코드>`가 정확히 한 번씩 포함된다.
- [ ] 같은 요청에 `placeName` 파트가 없으며, 빈 문자열 `placeName=`도 전송하지 않는다.
- [ ] 다중 사진 업로드는 모든 파일 요청에 동일한 지도 권역·시군 코드를 보내며, 각 요청에 이전 업로드의 장소 값이 섞이지 않는다.
- [ ] 지도 위치 없이 일반 앨범에서 업로드하면 map 코드와 장소를 비워 둘 수 있고, 이 경우 세 optional field가 빈 문자열이 아니라 생략된다.
- [ ] 업로드 응답 및 새로고침 뒤 지도 핀/레코드의 `mapRegionCode`, `mapCityCode`가 요청값과 일치한다.

### 4. 일반 앨범 입력 유지

- [ ] 앨범의 일반 `사진 추가`에서는 `PhotoRegionField`가 계속 보이고, 권역 선택·시군 검색·변경·지우기가 기존처럼 동작한다.
- [ ] 일반 앨범에서는 `장소 (선택)` 입력이 계속 보이며 입력한 비어 있지 않은 값만 `placeName`으로 전송된다.
- [ ] 일반 앨범의 장소 입력을 지우면 다음 업로드 요청에서 `placeName`이 생략된다.
- [ ] 일반 앨범에서 지도 위치와 장소를 함께 제공하는 기존 조합은 유지된다. 지도 전용 시트의 입력 제거가 공통 패널 전체로 번지지 않는다.

## 차단 기준과 판정

- 차단: 지도 시트에서 장소를 자유 입력하거나 위치를 변경할 수 있음.
- 차단: 권역만 선택한 상태에서 지도 업로드 시트가 열림.
- 차단: 표시 레이블과 전송한 코드가 다른 권역·시군을 가리킴.
- 차단: 지도 업로드 요청에 이전/빈 `placeName`이 포함됨, 또는 일반 앨범의 장소 입력이 사라짐.

현재 판정: **구현 반영 전 보류.** 위 정적 점검에서 발견한 `placeName` 무조건 렌더링 경로가 변경된 뒤, 브라우저 Network의 multipart 요청과 일반 앨범 회귀를 함께 확인해야 통과로 전환할 수 있다.
