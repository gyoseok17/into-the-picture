# M8.1 지도 사진 추가: 파일 선택 전 지역 표시·헤더 문구 정리 QA

- 검토일: 2026-08-28
- 역할: 통합 QA (코드 수정 없음)
- 검토 방식: `BatchPhotoUploadPanel`, `PhotoRecordMapView`, `PhotoRegionField` 정적 대조

## 확인 대상 계약

| 진입 경로 | 파일 미선택 상태 | 파일 선택 후 | 저장 값 |
| --- | --- | --- | --- |
| 지도에서 사진 추가 | 선택한 권역·시군을 읽기 전용으로 즉시 표시 | 같은 표시를 유지하고 촬영일·메모·파일 목록을 추가 표시 | 현재 지도 선택의 `mapRegionCode`, `mapCityCode`; 표시명은 `placeName`으로 저장 |
| 일반 앨범에서 사진 추가 | 기존 지역 선택 UI 유지 | 기존 장소 입력과 지역 선택 UI 유지 | 기존 선택/입력 규칙 유지 |

## 정적 검토 결과

- `BatchPhotoUploadPanel`은 `showLocationField={false}`일 때 `items.length` 조건 밖에서 `SelectedMapLocation`을 렌더링한다. 따라서 지도 시트는 사진을 고르기 전에도 선택 지역을 보인다.
- `SelectedMapLocation`은 `getKoreaRegion`과 `getKoreaCity`의 카탈로그 레이블을 조합해 `권역 · 시군` 형태로 보여 준다. 지도 시트는 시군 선택 전에는 열리지 않으므로 정상 경로에서 `지역 미선택` 대체 문구가 노출되지 않는다.
- 파일을 고른 뒤에도 같은 `SelectedMapLocation`만 렌더링되며, 별도 위치 입력이나 두 번째 지역 표시가 추가되지 않는다.
- `MapUploadSheet`의 제목 영역에는 `사진 추가` 제목만 남아 있고, `지도를 그대로 둔 채 사진을 기록해요.` 안내문은 없다.
- 일반 앨범 경로의 기본값은 `showLocationField=true`로 유지된다. `PhotoRegionField`와 파일 선택 후의 자유 `placeName` 입력이 지도 시트 변경 때문에 제거되지 않는다.

## 수동 확인 체크

- [ ] 지도에서 권역과 시군(예: 수도권 · 수원시)을 선택한 뒤 사진 추가를 열면, 파일 선택 전부터 동일한 지역명이 보인다.
- [ ] JPEG/PNG 등 파일을 한 장 이상 선택해도 지역명이 한 번만 보이며, 선택한 시군과 일치한다.
- [ ] 다른 시군을 선택한 뒤 시트를 다시 열면 이전 지역명이 남지 않고 새 지역명만 보인다.
- [ ] 지도 시트 제목 아래에 제거 대상 안내 문구가 보이지 않는다.
- [ ] 일반 앨범의 사진 추가에서는 지역 선택과 `장소를 함께 기록할까요? (선택)` 입력이 기존처럼 보이고 업로드된다.
