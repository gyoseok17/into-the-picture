# M8.1 immersive 앨범 fixed modal 위치 QA

작성일: 2026-09-04
상태: 구현 전 진단 완료 · 최종 검증 대기

## 원인과 수정 계약

- immersive 앨범의 전체 폭 정렬에 쓰는 `-translate-x-1/2`는 transform containing block을 만든다. 그 안에 있는 `position: fixed` 라이트박스는 viewport가 아니라 변환된 앨범 섹션을 기준으로 배치되어, 아래로 스크롤한 카드에서 열면 모달도 스크롤 아래에 나타난다.
- `PhotoBundleLightbox`와 같은 viewport modal은 변환된 `<section>`의 형제 위치로 옮겨야 한다. CSS로 transform을 무효화하거나 모달을 별도 스크롤 컨테이너에 맞추는 방식은 사용하지 않는다.

## 최종 체크리스트

- [ ] immersive 스토리에서 어느 스크롤 위치의 폴라로이드를 눌러도 라이트박스가 viewport 중앙에 즉시 표시된다.
- [ ] 일반 사진/비교 연결 사진 모두 이미지·이전/다음·썸네일·비교 오버레이가 기존대로 표시된다.
- [ ] 닫기 버튼, 배경 클릭, Escape가 모두 라이트박스를 닫고 원래 스크롤 위치는 유지한다.
- [ ] immersive 맵의 핀 상세, 사진 추가 시트, 사진 편집 modal, 앨범 비교 선택 dialog, 오류 알림은 변환된 section 안에 남아 있는 fixed/absolute 요소가 없는지 각각 확인한다. 변환 밖으로 이동한 요소는 동작·z-index·상태가 유지돼야 한다.
- [ ] 모바일에서 modal이 safe area와 하단 내비게이션 위에 나타나고 사진 전환/썸네일/오버레이 링크가 모두 조작 가능하다.
- [ ] `tsc -b`와 `git diff --check`를 수행한다.

## 차단 기준

- 라이트박스가 현재 viewport가 아닌 스크롤 아래/앨범 섹션 기준으로 뜬다.
- 수정으로 스토리·맵 modal, 비교 오버레이, 닫기/Escape, 모바일 조작 중 하나라도 회귀한다.
## 최종 소스·타입 검증 (2026-09-04)

### 통과

- `PhotoBundleLightbox`와 `PhotoRecordEditor`는 transformed immersive `<section>`의 닫는 태그 뒤 형제로 이동했다. 두 `fixed inset-0` modal은 이제 viewport 기준으로 중앙/하단에 배치된다.
- `AlbumError`는 `createPortal(..., document.body)`로 렌더링돼 transformed ancestor 영향을 받지 않는다.
- 스토리 preview의 비교 연결 오버레이, 사진 이전/다음·썸네일, 닫기 버튼·배경 클릭·Escape 처리 코드는 위치 이동 전과 동일하게 유지된다.
- 맵의 focus·업로드 시트·방문 이력은 map 내부의 `absolute` surface라 viewport fixed 문제와 별개이며, 이번 이동으로 부모/상태/z-index 경로가 바뀌지 않았다. 앨범 비교 선택 dialog도 section 형제로 유지된다.
- `tsc -b` 통과, `git diff --check` 공백 오류 없음(LF/CRLF 경고만 출력).

### 수동 확인 항목

- 실제 immersive 스토리를 충분히 아래로 스크롤한 뒤 라이트박스·편집 dialog·오류 알림이 현재 viewport에 나타나는지, 모바일 safe area에서 사진 전환·오버레이·닫기 조작이 가능한지 확인한다.
