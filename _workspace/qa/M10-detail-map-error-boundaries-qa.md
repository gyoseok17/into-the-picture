# M10 상세·지도·전역 오류 경계 QA

## 사전 검토 (2026-09-20)

### 유지해야 할 상세 화면 흐름

- 수상작 목록에서 연 상세는 전체 오버레이로 동작하며, `Esc`와 목록 버튼은 기존 목록 위치로 복귀한다.
- 공개 비교 또는 저장한 비교 다이얼로그가 열린 동안에는 상세 오버레이의 `Esc` 닫기가 중지되어야 한다.
- 즐겨찾기 미로그인 안내, 즐겨찾기 저장 실패, 저장 비교 진입, 공개 비교 조회, 혼잡도 로딩·오류·미제공 상태는 기존 상태별 UI를 유지해야 한다.

### 유지해야 할 앨범 지도 흐름

- 권역 선택·같은 권역 재선택/빈 지도 클릭에 따른 전체 지도 복귀, 시·군 선택, 시·군 선택 전 사진 추가 비활성화가 유지되어야 한다.
- 마커 묶음 선택은 대표 기록을 우선하고, 사진 전환·확대·비교 트로피·이전 방문 기록·대표 설정은 기존대로 동작해야 한다.
- 지도 확대 보기와 기존 스토리 확대 보기는 별도 흐름이며, 이번 전역 라우트 오류 처리가 이를 대체해서는 안 된다.

### 오류 경계 대조

- 현재 `router.tsx`에는 `errorElement`가 없다. 렌더 예외는 React Router 기본 오류 화면으로 노출될 수 있다.
- `ErrorState`는 React Query 등 HTTP 요청 실패를 각 화면에서 표시하고 `refetch`를 수행한다. 전역 경계는 이를 가로채거나 대체하지 않고, 렌더 예외에만 작동해야 한다.
- 전역 오류 화면은 다시 시도 시 현재 라우트 재렌더, 홈 이동 시 `/` 이동을 제공해야 하며, 중첩 상세 오버레이·다이얼로그의 일반적인 닫기와 혼동되면 안 된다.

### 최종 검증 예정

- 라우터의 모든 기존 URL/인증 보호가 유지되는지 코드 대조
- 전역 오류 UI의 `다시 시도`, `홈으로 이동` 구현과 ErrorState 분리 확인
- 수상작 상세와 지도 분리 뒤 import/상태 소유·회귀 경로 점검
- `npm run build`, `git diff --check` 실행

## 최종 검증 (2026-09-20)

### 상세 화면 경계

- `ContestDetailPage`는 라우트 파라미터·조회 훅·다이얼로그 표시 상태만 조율한다.
- 목록 진입 상세의 오버레이, 스크롤 잠금, Esc/Tab 처리와 원래 포커스 복귀는 `ContestDetailOverlay`로 이동했다.
- 공개 비교 다이얼로그의 Esc·바깥 클릭·포커스 복귀는 `PublicComparisonDialog`로 이동했다.
- 공개/저장 비교 다이얼로그가 열린 동안 오버레이 Esc를 중지하는 `suspendEscape` 계약이 유지된다.
- 기존 로컬 `DetailPresentation`, `PublicComparisonDialog` 정의는 0건으로 확인했다.

### 앨범 지도 경계 및 회귀 대조

- `PhotoRecordMapView`는 지도 stage, 권역/시군 선택, 마커 선택 상태만 조율한다.
- 선택한 마커의 대표 기록 우선, 사진 전환·트로피·확대·방문 이력·대표 설정은 `MapFocus`로 분리되어 기존 hook/API를 그대로 사용한다.
- 지도 확대 보기의 Esc·닫기·사진 전환·비교 연결 정보는 `MapPhotoLightbox`, 이전 방문 기록과 대표 설정은 `MapVisitHistory`, 시군 선택 및 추가 진입은 `MapRegionPicker`로 분리됐다.
- 마커 묶음·레거시 좌표·권역 매칭과 stage 크기 계산은 React 없는 `photoRecordMapPresentation.ts`로 이동했다. 기존 MapView 내부 중복 helper는 0건이다.
- 컴포넌트에서 HTTP/React Query 캐시를 직접 호출하는 새 경로는 없고, 대표 설정은 기존 `useSetPhotoRecordMapRepresentative` 훅을 통해서만 실행된다.

### 전역 오류 경계 대조

- 루트 `AppShell` 라우트에 `errorElement: <RouteErrorPage />`가 설정되어 예기치 못한 라우트 렌더 예외를 앱 전용 오류 화면으로 처리한다.
- `다시 시도`는 현재 히스토리 위치를 다시 탐색(`navigate(0)`), `홈으로`는 `/` 이동으로 구현됐다.
- 기존 화면 단위 `ErrorState`와 각 `refetch` 재시도는 유지된다. 따라서 HTTP/React Query 실패를 전역 오류가 대체하지 않는다.

### 실행 검증

- `frontend npm run build` 통과: TypeScript와 Vite 생산 빌드 성공.
- `git diff --check` 통과.
- 초기 JavaScript 청크는 820.07 kB 경고가 남아 있다. 이번 경계 분리의 차단 이슈는 아니며, 라우트 코드 분할 후속 작업으로 유지한다.
