# M8.1 application.yml 병합 QA

## 범위

- `application-local.yml` 제거와 `application.yml` 단일화
- `backend/.env` 필수 import, DB·JWT 환경변수 계약, 문서·Git 제외 규칙

## 확인 결과

1. `backend/src/main/resources/application-local.yml`은 제거됐고, 리소스에는 `application.yml`만 남아 있다.
2. `application.yml`은 `file:.env[.properties]`를 import한다. `backend` 모듈에서 Gradle을 실행하는 문서 경로와 일치한다.
3. datasource의 host, port, database, username, password와 JWT secret은 모두 기본값 없는 필수 placeholder다. JWT 개발용 고정값과 local 전용 fallback은 남아 있지 않다.
4. `backend/.env`는 Git ignore 대상이며 Git 추적 파일이 아니다. 실제 값은 확인·기록하지 않았다.
5. `backend/.env.example`, `backend/README.md`, `docs/01-architecture.md`가 새 위치와 단일 YAML 구조를 안내한다.
6. 과거 개발 로그와 `_workspace/` 보고의 `application-local.yml` 언급은 당시 변경 이력이며, 최신 로그에 삭제·병합 항목이 추가돼 있다. 과거 기록은 수정하지 않는 규칙과 일치한다.

## 검증

- `backend/gradlew.bat test --no-daemon`: 성공
- `git diff --check`: 성공
- 전체 기동 검증은 실제 `backend/.env`에 `DB_PORT`, `DB_NAME`이 아직 없어 수행하지 않았다. 두 값은 임의 생성하거나 기록하지 않았다.

## 판정

통과. 단, 실제 로컬 기동 전에는 `backend/.env`에 `DB_PORT`, `DB_NAME`을 포함한 필수 DB 접속값을 채워야 한다.
