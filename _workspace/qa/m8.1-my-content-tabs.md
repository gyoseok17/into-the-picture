# M8.1 마이 콘텐츠 탭 검토

## 변경

- 프로필 카드 아래를 `저장한 수상작`과 `내 앨범` 탭으로 분리했다.
- 기본 탭은 `저장한 수상작`이며, Radix Tabs의 비활성 패널은 마운트하지 않아 두 긴 목록이 한 화면에 이어지지 않는다.
- 저장한 수상작 조회 훅도 해당 패널 안으로 옮겨 앨범을 처음 열 때는 수상작 목록을 렌더·조회하지 않는다.

## 접근성·회귀

- 기존 Radix Tabs의 `tablist`, `tab`, `tabpanel`, 키보드 이동 의미를 사용한다.
- 수상작 탭의 로딩·오류·빈 상태·저장 해제와 앨범의 업로드·정렬·보관 동작은 각 패널 안에서 유지한다.

## 검증

- `frontend npm run build` 통과.
- `git diff --check` 통과.
- 기존 Vite 500KB 청크 경고만 남아 있다.

## 수동 QA

1. 마이를 열었을 때 저장한 수상작이 기본으로 보이는지 확인한다.
2. 내 앨범을 선택하면 앨범만 보이고, 다시 수상작을 선택하면 수상작 목록만 보이는지 확인한다.
3. 키보드 Tab·방향키로 두 탭을 이동하고, 수상작 저장 해제와 앨범 업로드를 각각 확인한다.
