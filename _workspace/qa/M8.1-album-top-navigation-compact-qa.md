# M8.1 앨범 상단 보기 전환부 축약 QA

- 검토일: 2026-09-11
- 범위: `PhotoRecordAlbum` 상단의 스토리·맵·보관함 전환부
- 판정: 통과

## 확인 결과

- 1440px·768px·541px: 레이블을 유지한다. 전환 컨트롤의 `flex-nowrap`과 각 버튼의 `shrink-0`으로 두 줄 배치가 발생하지 않는다.
- 540px·375px·320px: 스토리·맵·보관함의 화면용 레이블이 `sr-only`로 전환되고, 아이콘만 보인다. 세 조작부와 뒤로가기·관리 버튼의 최소 폭을 합산해도 320px의 실제 상단 폭 안에 들어간다.
- 접근성: 스토리·맵·보관함 모두 아이콘 전용 상태에서도 `aria-label`, `title`, 스크린 리더 텍스트를 가진다. 아이콘에는 `aria-hidden`을 적용해 이름이 중복 낭독되지 않는다.
- 상태 회귀: 스토리/맵은 기존 `onLayoutChange`와 활성 스타일을 유지한다. 보관함은 기존 `onArchiveToggle`과 앨범/보관함 상태별 이름을 유지한다. 뒤로가기와 관리 버튼의 동작은 변경되지 않았다.

## 검증

- `npm run build` 통과 (`tsc -b`, `vite build` 포함).
- production CSS에 `@media (max-width: 540px)` 규칙 생성 확인.
- `git diff --check` 통과.
- Vite의 500kB 청크 권고만 기존 비차단 경고로 남는다.

## 권고

- 540px를 경계로 한 전환이므로, 실제 브라우저에서 540px와 541px 폭을 한 번씩 조절해 시각적 전환만 확인하면 된다.
