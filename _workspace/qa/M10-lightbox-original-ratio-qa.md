# M10 스토리 묶음 확대 원본 비율 QA

- 점검일: 2026-09-20
- 범위: `frontend/src/features/photo-record/components/PhotoRecordAlbum.tsx`의 `PhotoBundleLightbox`
- 대상 계약: 스토리 묶음의 확대 사진만 원본 종횡비 전체를 보여 주고, 수상작 비교·썸네일의 고정 비율과 기존 사진 탐색은 바꾸지 않는다.

## 코드 대조

| 점검 항목 | 확인 결과 | 판정 |
| --- | --- | --- |
| 확대 사진 원본 비율 | 큰 사진은 `AspectImage`의 `aspect-[4/3]` 대신 `ImageSource`를 직접 사용한다. `w-auto`, `max-w-full`, `object-contain`으로 가로·세로 원본 비율을 유지하며 잘라내지 않는다. | 통과 |
| 세로 사진 높이 제한 | 확대 사진 영역과 이미지 모두 `max-h-[calc(100dvh-12rem)]`를 적용했다. 상단 제목·비교 정보·썸네일 공간을 남기고, 세로 사진이 화면 밖으로 과도하게 커지지 않는다. | 통과 |
| 가로 사진 폭 제한 | `max-w-full`과 `w-auto`로 모달 본문 폭을 넘지 않는다. 너비가 남는 경우에는 중앙 정렬되고, 원본 비율은 유지된다. | 통과 |
| 수상작 비교 고정 비율 | `ComparisonPlacementPair`와 `ComparisonCropImage`는 저장된 `crop.aspectRatio`를 그대로 사용한다. 이번 변경은 앨범 `PhotoBundleLightbox`만 수정했으므로 비교판의 수상작 기준 비율·크롭 표시에는 영향이 없다. | 통과 |
| 썸네일 고정 비율 | 하단 썸네일은 기존 `AspectImage`의 `aspect-square`, `h-12 w-12`, `overflow-x-auto`, `shrink-0`을 유지한다. 묶음 사진이 많아도 한 줄 가로 스크롤 동작이 바뀌지 않는다. | 통과 |
| 좌·우 클릭 탐색 | 이미지 버튼의 pointer 시작·종료 좌표를 비교해 12px 이내 탭만 처리하며, 왼쪽/오른쪽 반으로 이전·다음 사진을 순환 전환한다. 원본 비율 표시로 클릭 대상은 바뀌지만 버튼이 이미지 영역 전체를 감싸므로 탐색은 유지된다. | 통과 |
| 키보드 탐색 | 다중 사진 묶음에서 `ArrowLeft`, `ArrowRight`가 기존과 같이 `movePhoto(-1/1)`을 호출한다. 단일 사진은 탐색하지 않는다. | 통과 |
| 드래그·스크롤 오인 방지 | 이미지 기본 드래그를 막고, 12px보다 큰 pointer 이동은 사진 전환으로 처리하지 않는다. | 통과 |

## 남은 수동 확인

- 실제 브라우저에서 매우 긴 세로 사진·파노라마 가로 사진 각각을 열어, 이미지 전체가 보이고 필요한 경우 모달 내부 스크롤만 생기는지 확인한다.
- 터치 기기에서 썸네일 가로 스크롤과 큰 사진 좌·우 탭이 동시에 자연스럽게 동작하는지 확인한다.
