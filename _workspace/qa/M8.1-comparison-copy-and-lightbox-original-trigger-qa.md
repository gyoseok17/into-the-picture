# M8.1 수상작 비교 명칭·확대 원본 사진 트리거 QA

## 판정

통과

## 확인 범위

- 비교 기능의 사용자 노출 문구가 `사진 놓기`에서 `수상작 비교`로 통일되었다.
- 앨범 스토리·지도 확대 보기의 비교 정보에서 텍스트 `비교 보기` 대신 수상작 원본 썸네일 버튼이 제공된다.
- 원본 썸네일은 현재 화면 위 인라인 비교 결과 창을 열며, 라우트 이동이나 API 호출 계약 변경은 없다.

## 교차 검토

- `PhotoComparisonLightboxInfo`는 대표 수상작 제목·지역·트로피와 고정 크기 원본 썸네일을 함께 렌더링한다. 다건 연결 때는 썸네일 배지와 기존 결과 창의 선택 목록으로 다른 수상작을 고를 수 있다.
- 원본 썸네일에는 수상작 제목·비교 열기 목적·연결 수를 담은 `aria-label`과 `title`이 있으며, 결과 창을 닫으면 같은 버튼으로 초점이 복귀한다.
- 확대 보기와 결과 창 모두 공통 컴포넌트를 통해 스토리·지도·한 장 사진·여러 장 묶음에 적용된다. `PHOTO_ONLY`의 결과 제목 처리도 기존대로 유지된다.
- `frontend/src`의 사용자 노출 `사진 놓기`, `비교 보기` 문자열은 남지 않았다. `/compare` URL, API 경로, 도메인 컴포넌트 이름은 변경하지 않았다.
