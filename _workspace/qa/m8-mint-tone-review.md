# M8 파스텔 민트 톤 전환 QA 사전 검토

- 검토일: 2026-08-14
- 범위: 홈(`/`), 공통 색상 토큰, 상단·하단 내비게이션
- 코드 변경: 없음

## 확인한 기준

| 항목 | 확인 결과 | 전환 시 기준 |
| --- | --- | --- |
| 대비·가독성 | 현재는 따뜻한 베이지 배경과 짙은 갈색 글자 토큰을 공통 사용한다. | 민트는 배경·secondary·muted에만 은은하게 적용하고, 본문·링크·아이콘은 충분히 짙은 청록 또는 중성 짙은색을 유지한다. 연한 민트 위에 중간 명도의 민트 글자를 쓰지 않는다. |
| 버튼·선택 상태 | 활성 탭·로그인 버튼은 `primary`, 비활성은 `muted-foreground`를 사용한다. | 활성 상태는 배경과 확실히 구분되는 짙은 청록, 흰 글자로 유지한다. 색만 연해져 활성 탭이 안 보이는 경우를 막는다. |
| 홈 히어로 | 히어로 좌측만 고정 베이지(`#ebe7df`)이며, 이미지는 별도 영역이다. | 이 고정색도 토큰 또는 같은 계열의 아주 옅은 민트로 함께 바꿔야 전체 톤이 섞이지 않는다. 이미지 위 흰색 제목은 민트 전환과 무관하게 어두운 사진에서 읽히는지 확인한다. |
| 경계·입력창 | border, input, 검색 밑줄이 낮은 대비로 쓰인다. | 배경 민트가 밝아져도 카드 경계와 검색 포커스 상태가 사라지지 않도록 border와 focus 색을 별도로 확인한다. |
| 모바일 | 360px에서 하단 탭은 고정·반투명 배경이며, 홈은 2열 카드가 유지된다. | 민트 배경의 하단 탭과 페이지 배경이 섞이지 않게 탭 상단 경계 또는 불투명도를 유지하고, 작은 글자(11px 탭 라벨·12px eyebrow)의 대비를 실제 화면에서 확인한다. |
| 데스크톱 | 상단 바는 반투명 배경과 backdrop blur를 사용한다. | 스크롤 중 사진 위에서도 메뉴 글자·활성 pill의 대비가 유지되는지 1280px에서 확인한다. |

## 잠재 이슈와 권고

1. **차단 없음.** 색상 토큰 중심 변경이라 API·기능 계약 영향은 없다.
2. 민트 색을 `background`, `secondary`, `muted`, `accent`, `border`에 일관되게 적용하고, 홈 히어로의 하드코딩 색상은 같은 팔레트로 맞춘다. 페이지별 임의 색상 추가는 피한다.
3. `text-primary/60`, `text-primary/65`, `text-muted-foreground`처럼 투명도를 더한 작은 텍스트는 가장 먼저 대비를 확인한다. 읽기 어려우면 투명도를 낮추기보다 글자 색 자체를 한 단계 진하게 한다.
4. 최종 확인은 최소 360px·768px·1280px에서: 로그인/비로그인 상단 상태, 하단 탭 선택 상태, 홈 검색 focus, 로딩 카드, 이미지 없는 히어로 상태를 확인한다.

## QA 판정

**조건부 진행 가능.** 민트는 장식 색이 아니라 공통 토큰으로 적용하고, 적용 후 위 해상도와 상태별 대비 점검을 완료 조건으로 한다.
