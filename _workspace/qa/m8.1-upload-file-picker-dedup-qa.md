# M8.1 다중 사진 추가: 파일 선택 제어 중복 제거 QA

## 범위

- 대상: `BatchPhotoUploadPanel`의 파일이 없는 상태에서 보이는 파일 선택 진입점.
- 변경 의도: 상단 `사진 고르기`와 빈 상태의 `사진을 골라주세요`가 동시에 노출되는 중복을 없애고, 파일 선택 행동은 한 번만 제공한다.
- 비범위: 파일 형식/20장 제한, EXIF 처리, 업로드 API, 지도 위치 선택 계약.

## 계약

- `items.length === 0`이면 사용자가 누를 수 있는 파일 선택 제어는 정확히 하나다.
- `items.length > 0`이면 파일을 다시 선택(목록 교체)할 수 있는 제어를 정확히 하나 제공한다.
- 업로드 중에는 파일 선택 제어와 숨은 file input 모두 비활성화되어, 추가 선택 및 선택 교체가 일어나지 않는다.
- OS 파일 선택 창에서 취소하면 항목 목록, 업로드 가능 상태, 안내 문구가 변경되지 않는다.

## 회귀 위험

- 빈 상태 제어를 제거하면서 유일한 제어의 `inputRef.current?.click()` 연결까지 제거되지 않아야 한다.
- 숨은 file input은 업로드 중에도 `disabled` 상태를 유지해야 한다. 표시 버튼만 막으면 키보드/프로그램적 변경 경로가 남을 수 있다.
- 재선택은 현재 구현처럼 목록을 교체하는 계약이므로, 취소 시 빈 배열로 초기화되지 않아야 한다.
