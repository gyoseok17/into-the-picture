# M8.1 수상작 비교 내 사진 표기 QA

통과

## 계약 대조

- 공통 `getComparisonPhotoDisplay`가 `placeName`(공백 제거) → 유효한 `takenAt` 날짜 → `내 사진` 순서로 제목을 정한다.
- 장소가 있을 때만 촬영일을 보조 정보로 표시하며, 메모·기기 파일명은 사용자 표기에 사용하지 않는다.
- 날짜는 `YYYY년 M월 D일` 형식으로 표시하고, 레거시의 비어 있거나 형식이 맞지 않는 값은 안전하게 `내 사진`으로 떨어진다.

## 적용 범위 확인

- 생성 화면의 선택 사진, 사진 선택창의 타일·선택 요약, 결과 목록, 저장 결과 상세·비교판 및 `PHOTO_ONLY` 헤더가 공통 헬퍼를 사용한다.
- 장소와 날짜가 모두 있을 때 장소가 제목·날짜가 보조 정보로, 장소가 없고 날짜만 있을 때 날짜가 제목으로 표시되는 구조를 코드로 확인했다.
- 파일명은 이미지 `alt`와 크롭 편집기의 `photoAlt`에만 남아 있다. 이는 시각적 사용자 표기와 분리돼 있으며, 파일명 데이터·접근성 정보의 보존 범위와 맞는다.
- API·DB·URL·일반 앨범/사진 기록 UI 변경은 없다. 비교 도메인 화면과 새 공통 표시 헬퍼 범위에만 적용됐다.

## 권고

- 실제 레거시 데이터에서 `placeName`이 공백만 있는 경우와 잘못된 촬영일 문자열은 자동으로 `내 사진`으로 처리된다. 이 동작은 안전하지만, 필요하면 앨범 편집으로 장소·날짜를 보완할 수 있다는 안내를 추후 추가할 수 있다. 차단 이슈는 아니다.
