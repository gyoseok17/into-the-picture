# M10 스토리 묶음 사진 탐색 QA

## 대상

- 화면: `PhotoRecordAlbum.tsx`의 `PhotoBundleLightbox`
- 진입: 스토리 카드(`PhotoRecordBundleCard`) 선택 → `storyPreview` → 확대 팝업
- 범위: 이전·다음 버튼 제거, 여러 사진 썸네일 탐색과 가로 스크롤 유지

## 정적 교차 검증 (2026-09-20)

### 1장 묶음

- `bundle.photos.length > 1` 조건이 거짓이므로 썸네일 탐색 줄 자체가 렌더링되지 않는다.
- 대표 사진은 그대로 확대 팝업 본문에 표시되고, 닫기와 Escape 동작은 기존처럼 유지된다.

### 여러 장 묶음

- 기존의 `이전`·`다음` 버튼 및 장수 표기 줄이 제거되었고, 더 이상 사진 전환 함수를 호출하는 경로도 없다.
- 썸네일은 각 항목의 `onClick={() => setIndex(itemIndex)}`로 현재 큰 사진을 직접 전환한다.
- 목록 컨테이너는 `flex gap-2 overflow-x-auto`이며 각 썸네일은 `w-12 shrink-0`이다. 따라서 사진 수가 화면 폭을 넘으면 줄바꿈이나 축소 대신 가로 스크롤로 계속 탐색한다.
- 현재 선택한 사진의 테두리(`border-primary`), 비교 연결 트로피 표시는 그대로 유지된다.

### 확대 흐름

- 스토리 카드의 `onOpen`은 `setStoryPreview(bundle)`을 유지한다.
- 팝업의 큰 사진과 썸네일 선택이 같은 `index` 상태를 사용하므로, 썸네일 선택 즉시 큰 사진도 함께 바뀐다.

## 검증

- `frontend/npm run build` 통과.
- `git diff --check` 통과 (CRLF 경고만 출력).

## 판정

**통과.** 요청한 이전·다음 줄은 제거되었고, 1장/여러 장 조건과 가로 스크롤 기반 사진 탐색 및 확대 흐름에 회귀가 없다.

## 수동 확인 권고

- 모바일 좁은 폭에서 8장 이상 묶음을 열어 썸네일 영역을 좌우로 밀고, 마지막 사진 선택 후 첫 사진으로 되돌아가는지 확인한다.
