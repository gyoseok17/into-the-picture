# M8.1 브라우저 EXIF 촬영일 사전 채움 검토

## 구현 범위

- `features/photo-record/lib/extractJpegTakenAt.ts`는 브라우저에서 JPEG APP1 EXIF의 `DateTimeOriginal`, `DateTimeDigitized`, `DateTime` 순으로 촬영일만 읽는다.
- GPS와 다른 EXIF 값은 읽거나 전송하지 않는다.
- 사진을 고르면 촬영일 입력칸을 즉시 채우고, 확인 중·성공·정보 없음·비JPEG·손상·실패·직접 입력 유지 상태를 보인다.

## 보호와 호환성

- 사용자가 촬영일 입력칸을 변경하면 비동기 추출 결과가 덮어쓰지 않는다.
- 빠르게 다른 파일을 고른 경우 이전 파일의 늦은 응답은 순번으로 무시한다.
- 브라우저 추출 실패 또는 빈 촬영일은 기존 `POST /me/photos` 서버 EXIF 보완 경로를 그대로 사용한다.

## 검증

- `frontend npm run build` 통과.
- `git diff --check` 통과.
- 기존 Vite 500KB 청크 경고만 남아 있다.

## 수동 QA

1. EXIF 날짜가 있는 JPEG를 골라 날짜가 미리 채워지는지 확인한다.
2. 날짜 없는 JPEG, PNG/WebP, 손상 JPEG에서 안내와 직접 입력이 가능한지 확인한다.
3. 촬영일을 직접 입력한 뒤 다른 JPEG를 골라도 해당 값이 유지되는지 확인한다.
4. 파일을 빠르게 연속 선택해 마지막 파일의 결과만 반영되는지 확인한다.
