# M8.1 사진 추가 시트 동시 저장 안내 문구 제거 QA

작성일: 2026-08-28
역할: QA·검토 (프로덕션 코드 수정 없음)

## 검토 범위

- 사진 추가 시트의 사진 섹션 보조 문구에서 `한 번에 3장씩 저장`만 제거한다.
- 선택 가능 수량 `최대 20장`과 실제 업로드 동시성(3)은 기능 계약으로 유지한다.

## 정적 검증

- `BatchPhotoUploadPanel.tsx`의 표시 문구는 `최대 20장`으로 남아 있어 파일 선택 한도가 사용자에게 계속 안내된다.
- `CONCURRENCY = 3` 및 `uploadPending()`의 worker 수 계산은 표시 문구와 분리되어 있다. 문구 제거는 업로드 요청 수, 재시도 대상, 성공·실패 상태에 영향을 주지 않는다.
- 20장 초과 선택 시의 제한 안내는 별도로 유지되므로, 사용자가 선택 한도를 오해할 회귀는 없다.
- API 요청 형식, EXIF 촬영일 추출, 사진 변경, 날짜·메모 입력, 쿼리 무효화 계약은 변경 범위 밖이다.

## QA 판정

- 차단 이슈: 없음.
- 권고: 없음. 이 변경은 처리 구현을 감추거나 바꾸지 않고, 내부 동시 처리 세부 사항만 UI에서 제거한다.
- 통합 판정: 통과 (문구 단일 변경에 대한 정적 검토). 기존 업로드 전체 수동 테스트는 기능 로직 변경이 없으므로 재실행 불필요.
