# M8.1 공개 관리 카드 제목·지역 표기 QA

## 판정

통과.

## 데이터 계약 확인

- `PhotoComparison.contest`는 `ContestSummary`를 사용한다.
- `ContestSummary.title`과 `ContestSummary.location`은 타입상 모두 `string`이다.
- 따라서 별도 API·DTO·DB 변경 없이 공개 관리 카드에서 수상작 제목과 지역명을 사용할 수 있다.
- 다만 외부 원본 데이터의 빈 문자열·공백 문자열까지 타입으로 막을 수는 없다. 화면은 빈값을 그대로 렌더링하면 작은 지역명 줄이 비어 보인다.

## 화면 확인

- `ComparisonVisibilityManager`는 이미지 쌍 아래에 수상작 제목을 `text-sm font-semibold`, 지역명을 `text-xs text-muted-foreground`로 표시한다.
- 제목은 한 줄 말줄임 처리되어 긴 제목이 공개 전환 버튼 영역을 밀어내지 않는다.
- 지역명도 한 줄 말줄임 처리되어 카드 높이가 비정상적으로 커지지 않는다.

## 빈 지역명 처리

지역명은 다음 표시 전용 fallback으로 보완됐다.

```ts
const locationLabel = comparison.contest.location?.trim() || '장소 정보 없음'
```

`comparison.contest.location?.trim() || '장소 정보 없음'`으로 공백 문자열까지 대체한다. 이 처리는 프런트 표시 경계에만 두며 API·DB 계약을 바꾸지 않는다.

## 공개 전환 회귀 확인

- `useUpdateComparisonVisibility`와 `PATCH /me/comparisons/{id}/visibility` 호출은 변경되지 않았다.
- 제출 중에는 해당 카드의 버튼만 비활성화되고 다른 카드 조작은 유지된다.
- 현재 상태는 `aria-live`로 알리며, 실패 메시지는 해당 카드의 `role=alert`로 표시된다.
- 성공 시 비교 목록과 수상작 공개 사진 쿼리를 무효화하므로 공개/비공개 전환 결과가 다른 화면에도 반영된다.
