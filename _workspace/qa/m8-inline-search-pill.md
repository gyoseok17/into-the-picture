# M8 키워드 검색 인라인 빠른 도구 QA

- 검토일: 2026-08-14
- 범위: 긴 키워드 검색 결과 화면의 메뉴 → 인라인 검색 입력 타원 전환
- 코드 변경: 없음 (QA 검토)

## 확인한 동작

- `ScrollAssist`의 검색 동작은 열린 메뉴를 닫은 뒤, 메뉴 버튼을 렌더하지 않고 가로 입력창과 검색 아이콘만 담은 타원을 표시하도록 분기되어 있다.
- 수상작의 필터 동작은 기존 사각 필터 패널을 유지한다. 검색 화면 전용 변화라 두 화면의 패널 책임이 섞이지 않는다.
- 검색어 적용은 기존 `keyword` 상태와 `/explore?keyword=` URL 갱신 경로를 사용하고, 상단으로 강제 이동하지 않는다. 결과·무한 스크롤의 현재 위치 보존 의도와 일치한다.
- 입력은 열릴 때 자동 초점을 받고, Enter 제출·Escape 닫기·바깥 클릭 닫기 경로가 `ScrollAssist`에 있다. 모바일 하단 탭 위 safe-area 위치 규칙도 공통 고정 도구를 그대로 사용한다.

## 해결한 차단 이슈

1. 기존 `QuickSearchPanel`을 제거해 미사용 선언 오류를 해소했다. `npm run build`가 통과했다.
2. 인라인 입력에 `focus-visible:ring-2`를 복원해 키보드 초점 표시를 유지했다.

## 권고 사항

1. 360px에서 긴 검색어를 입력해도 검색 아이콘이 밀리지 않는지, 768px·1280px에서 오른쪽 여백과 하단 탭/스크롤바를 가리지 않는지를 실제 화면에서 확인한다.
2. Escape·바깥 클릭 후 메뉴 트리거가 다시 렌더된 뒤 초점이 복귀하는지, Enter 적용 후 URL·결과는 갱신되지만 스크롤 위치는 유지되는지 수동 확인한다.

## 판정

**통합 가능.** 코드 검토, `npm run build`, `git diff --check`를 통과했다. 실제 360px/768px/1280px 화면에서 위치와 키보드 흐름을 한 번 확인하는 것을 권고한다.
