# M8.1 스토리 폴라로이드 비교 연결 트로피 QA

작성일: 2026-09-04
상태: 구현 전 계약 검토 완료 · 최종 검증 대기

## UI 계약

- 스토리 폴라로이드 카드에서 비교에 연결된 사진이 하나 이상인 경우에만 사진 영역의 좌측 상단에 작은 트로피 아이콘을 보인다.
- 트로피는 비교 상태를 알리는 장식/상태 표시이며, 장소명·메모·날짜가 있는 하단 메모 영역을 밀거나 가리지 않는다.
- 비교 연결이 없는 일반 사진에는 아이콘·빈 자리·비교 문구가 남지 않는다.
- 묶음에 여러 사진이 있더라도 카드의 대표 사진과 실제 연결 사진의 관계를 혼동시키지 않는다. 상세(라이트박스)는 현재 선택한 개별 사진의 연결 수상작만 보인다.
- 지도 핀의 비교 배지/연결 링크와 라이트박스의 수상작 결과 링크는 기존 경로(`/compare?contestId=<id>`)와 동작을 유지한다.

## 소스·회귀 체크리스트

- [ ] 스토리 전용 카드에서 기존 `PhotoComparisonBadge` 텍스트 표시가 트로피 아이콘으로 대체된다.
- [ ] 비교가 없는 `bundleComparisons`는 어떤 마크업도 렌더링하지 않는다.
- [ ] 트로피는 카드 이미지 래퍼의 `absolute left/top` 레이어에 있고, 이미지 클릭/카드 열기 및 선택 관리 checkbox를 가로채지 않는다.
- [ ] 아이콘에 `aria-label` 또는 보조 텍스트가 있어 비교 연결 상태를 읽을 수 있고, 순수 장식이면 접근성 트리에서 제외된다.
- [ ] 모바일 320px과 일반 폭에서 트로피가 이미지 밖으로 잘리거나 선택 checkbox·폴라로이드 회전 그림자와 겹치지 않는다.
- [ ] 스토리 라이트박스는 사진 인덱스를 넘길 때 해당 사진의 `PhotoComparisonLinks`만 갱신하며, 링크가 해당 수상작의 기존 비교 결과를 연다.
- [ ] 지도 `PhotoRecordMapView`는 기존 배지와 라이트박스 링크 흐름을 유지한다.
- [ ] `tsc -b`, `git diff --check`를 수행한다. Vite가 샌드박스 상위 경로 권한 때문에 실패하면 코드 오류와 분리해 기록한다.

## 차단 기준

- 일반 사진에도 트로피/빈 배지 공간이 보인다.
- 트로피가 장소·메모·날짜를 가리거나 카드 상호작용을 막는다.
- 묶음의 다른 사진 비교가 현재 라이트박스 사진에 표시되거나 수상작 결과 링크가 사라진다.
## 구현 도착 검증 (2026-09-04)

### 통과

- `StoryComparisonMarker`는 좌측 상단 absolute 레이어의 트로피와 `sr-only` 상태 설명으로 구현됐고, 메모·날짜가 있는 폴라로이드 본문 영역의 흐름을 바꾸지 않는다.
- 일반 사진은 marker 컴포넌트가 `null`을 반환하므로 별도 빈 영역이 생기지 않는다.
- 지도는 기존 `PhotoComparisonBadge`·`PhotoComparisonLinks`를 유지한다. 스토리 라이트박스도 현재 선택한 개별 사진 ID로 링크를 계산해 결과 진입을 유지한다.
- `tsc -b` 통과, `git diff --check` 공백 오류 없음(LF/CRLF 경고만 출력).

### 차단 이슈: 묶음 대표 사진과 연결 상태 불일치

- `PhotoRecordAlbum.tsx:687-697`에서 카드 이미지는 `bundle.photos[0]`인 `record`를 표시하지만, 트로피 조건은 묶음 전체 사진을 합친 `bundleComparisons.length`다.
- 따라서 두 번째 사진만 비교 연결된 묶음에서도 첫 번째 일반 사진의 좌상단에 트로피가 표시된다. 이는 일반 사진 미노출과 개별 사진 연결 표시 계약을 위반한다.
- 수정 기준: marker 조건을 `comparisonsByPhotoId.get(record.id)?.length > 0`으로 바꾸고, 묶음 전체 연결 정보가 필요하면 별도 텍스트/상세 영역에서만 표현한다.

## 차단 보완 재검증 (2026-09-04)

- `PhotoRecordAlbum.tsx:687-698`에서 트로피 조건이 대표 이미지 `record.id`의 `recordComparisons`로 바뀌었다. 묶음의 다른 사진만 연결된 경우 대표 일반 사진에는 트로피가 나타나지 않는다.
- 트로피는 카드 좌측 상단 absolute 레이어이며, 본문 장소·메모·날짜 영역과 선택 관리 checkbox(우측 상단)를 침범하지 않는다. `sr-only` 설명도 유지된다.
- 지도 배지·연결 링크와 개별 사진 기준 라이트박스 링크는 변경되지 않았다.
- `tsc -b` 통과, `git diff --check` 공백 오류 없음(LF/CRLF 경고만 출력).
