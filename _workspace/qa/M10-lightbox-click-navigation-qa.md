# M10 스토리 묶음 확대 좌·우 탐색 QA

- 점검일: 2026-09-20
- 범위: `PhotoRecordAlbum.tsx`의 `PhotoBundleLightbox`
- 대상 계약: 묶음 확대 보기에서 큰 사진의 좌측 클릭은 이전, 우측 클릭은 다음 사진으로 전환한다. 기존 썸네일 가로 스크롤과 닫기 흐름은 유지한다.

## 점검 결과

| 항목 | 코드 대조 결과 | 판정 |
| --- | --- | --- |
| 한 장 묶음 | `hasMultiplePhotos`가 거짓이면 pointer 시작을 기록하지 않고 키보드 좌·우도 무시한다. 썸네일 목록도 렌더링하지 않는다. | 통과 |
| 첫·마지막 경계 | `movePhoto`가 `(현재 + 이동 + 길이) % 길이`를 사용한다. 기존 이전·다음 버튼과 같은 순환 탐색으로 첫 사진의 좌측은 마지막, 마지막 사진의 우측은 첫 사진이다. | 통과 |
| 좌·우 판정 | 큰 사진 버튼 자신의 `getBoundingClientRect()` 기준으로 폭의 절반보다 왼쪽이면 -1, 그 외면 +1을 전달한다. 카드 여백·닫기·비교 정보·썸네일 영역은 판정 대상이 아니다. | 통과 |
| 마우스/이미지 드래그 | `onDragStart`에서 기본 이미지 드래그를 막고, 주 버튼(0)만 시작점으로 인정한다. | 통과 |
| 터치 스와이프 오인 방지 | `pointerdown`과 `pointerup`의 이동 거리가 12px를 넘으면 전환하지 않는다. `pointercancel`도 시작점을 비운다. 따라서 스와이프·스크롤 시 탭으로 오인할 가능성을 줄인다. | 통과 |
| 썸네일·가로 스크롤 | 썸네일은 기존처럼 독립 버튼이며 `overflow-x-auto`, `shrink-0`를 유지한다. 큰 사진의 pointer 처리와 이벤트 영역이 분리되어 있다. | 통과 |
| 닫기·배경 클릭 | 큰 사진 버튼은 dialog `section` 내부에 있어 배경 닫기 이벤트로 전파되지 않는다. 닫기 버튼과 배경 클릭의 기존 닫기 동작도 유지된다. | 통과 |
| 키보드 | 큰 사진에 포커스한 상태에서 좌·우 화살표도 같은 순환 탐색을 수행한다. | 통과 |

## 권고 사항

- 한 장 묶음에서도 큰 사진 영역이 포커스 가능한 `button`으로 남아 있지만 클릭 결과는 의도적으로 무동작이다. 현재 요구사항에는 부합한다. 접근성 문구를 더 엄격히 다듬을 때는 한 장일 경우 비상호작용 컨테이너로 렌더링하거나 `aria-label`을 단순 이미지 설명으로 바꾸는 것을 후속 개선 후보로 둔다.
