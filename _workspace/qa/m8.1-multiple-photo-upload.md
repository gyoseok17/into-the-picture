# M8.1 여러 장 사진 업로드 QA

1. JPEG, PNG, WebP, HEIC/HEIF를 섞어 1장·3장·20장을 선택한다. 21장을 선택하면 앞 20장만 대기열에 남고 안내가 보이는지 확인한다.
2. 네트워크 탭에서 업로드 요청이 동시에 3개를 넘지 않고, 완료한 요청 뒤 다음 대기 항목이 시작되는지 확인한다.
3. 한 항목을 400·500·시간 초과로 실패시켜도 나머지는 계속 저장되는지, 실패 항목만 다시 시도할 수 있는지 확인한다.
4. 재시도 뒤 이미 성공한 사진이 중복 생성되지 않는지, 완료 후 스토리·맵·비교 사진 선택 목록이 갱신되는지 확인한다.
5. 모바일 화면에서 20개 목록을 스크롤하고 업로드 버튼을 연속으로 눌러도 중복 요청이 생기지 않는지 확인한다.
