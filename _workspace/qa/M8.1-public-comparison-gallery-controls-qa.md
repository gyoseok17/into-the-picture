# M8.1 공개 비교 사진 진입점·상태 표기 QA

## 범위

- 비교 결과의 공개 상태 표기를 `공개`·`비공개`로 축약한다.
- 수상작 상세의 공개 비교 사진은 하트 옆 사진 모음 버튼으로만 연다.

## 점검 결과

- `PUBLIC`은 `공개`, `PRIVATE`는 `비공개`로만 보이며, 비공개는 낮은 대비로 구분된다. 두 상태 모두 `aria-label`과 `title`로 현재 상태와 누르면 바뀌는 상태를 설명한다.
- 공개 사진 요청은 사진 모음 버튼을 누른 뒤에만 시작된다. 비로그인도 버튼을 열 수 있고, 로그인 사용자의 본인 비교 ID는 공개 목록에서 제외된다.
- 목록은 본문에 중복 렌더링되지 않는다. 모달 안에서 로딩·오류 재시도·빈 목록·사진 목록 상태를 모두 제공한다.
- 수상작 상세가 이미 오버레이로 열린 경우에도 자식 모달이 Escape와 Tab을 독점한다. 부모 포커스 트랩은 자식 모달 동안 중지되고, 닫으면 사진 모음 버튼으로 포커스를 복원한다.
- 공개 API·DB·권한·사진 URL 계약은 변경하지 않았다.

## 검증

- `npm run typecheck` 통과
- `npm run build` 통과
- `git diff --check` 통과
- Vite의 500KB 청크 경고만 기존 비차단 권고로 남아 있다.

## 판정

통과. 실제 브라우저에서 공개 사진이 있는 수상작과 없는 수상작 각각에 대해 버튼·모달·비공개 전환 뒤 목록 갱신을 한 번씩 확인하면 된다.
