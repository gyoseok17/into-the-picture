# M8.1 지도 사진 추가: 지역 표시 접두어 제거 QA

- 검토일: 2026-08-28
- 역할: QA·검토 (코드 수정 없음)
- 검토 범위: 지도 사진 추가 시트의 읽기 전용 지역 표시 문구

## 계약

지도에서 사진 추가를 열면 파일 선택 여부와 관계없이 선택된 `권역 · 시군` 레이블만 표시한다. 설명용 접두어 `선택한 지역`은 표시하지 않는다. 일반 앨범의 지역 선택 UI 및 업로드 데이터(`mapRegionCode`, `mapCityCode`, `placeName`) 계약은 바뀌지 않는다.

## 정적 검토

- 현재 `BatchPhotoUploadPanel.tsx`의 `SelectedMapLocation`은 지역 레이블 앞에 `선택한 지역` 텍스트를 별도 `span`으로 렌더링한다.
- 지역 레이블 자체는 `mapLocationLabel`이 `getKoreaRegion`과 `getKoreaCity`로 조합하므로, 접두어 `span`만 제거하면 선택 지역 표시·파일 선택 전 노출·업로드 값에는 영향이 없다.
- `SelectedMapLocation`은 `showLocationField=false`일 때 `items.length` 조건 밖에서 렌더링된다. 따라서 접두어 제거 후에도 사진 선택 전 표시 요구는 유지된다.
- 제거 대상은 지도 시트 전용 읽기 전용 표시다. `PhotoRegionField`의 접근성 라벨 `선택한 지역 지우기` 및 일반 앨범 입력 UX는 이 문구 변경 범위 밖이다.

## 수동 확인 체크

- [ ] 지도에서 시군을 선택하고 사진 추가를 열면 파일 선택 전 `권역 · 시군`만 보이고 `선택한 지역`은 보이지 않는다.
- [ ] 사진을 선택한 뒤에도 지역명은 한 번만 보이고, 같은 접두어가 재등장하지 않는다.
- [ ] 지역 미선택 대체 문구와 일반 앨범의 기존 지역 선택 UI가 의도치 않게 바뀌지 않는다.

## 판정

접두어 렌더링 노드만 삭제하는 변경은 계약·저장 값·접근성 이름에 회귀 위험이 낮다. 구현 후 위 수동 항목과 프런트엔드 빌드가 통과하면 QA 통과로 판정할 수 있다.
