# M10 수상작 상세 방문 타이밍 요약 QA

검토 일시: 2026-09-21

## 상태별 검토

| 상태 | 위치 옆 요약 | 기존 상세 섹션 |
| --- | --- | --- |
| `crowdAvailable=false` | `제공하지 않음` | 제공 불가 안내 |
| 조회 중 | `확인 중` | 로딩 UI |
| 조회 실패 또는 예측 없음 | `제공하지 않음` | 재시도 오류 또는 제공 불가 안내 |
| 추천일 있음 | 첫 추천일을 `추천 M.D`로 표시 | 30일 캘린더·날짜별 수치 |
| 추천일 없음 | `향후 30일 여유` | 30일 캘린더 |

`useContestCrowd`의 enabled 조건은 기존처럼 `detail.crowdAvailable`에 의존하므로 미지원 작품에서 불필요한 조회를 만들지 않는다.

## 반응형·의미·접근성

- 요약 컨테이너는 `hidden md:inline-flex`라 모바일에서는 완전히 숨겨져 기존 모바일 상세 구성을 변경하지 않는다.
- 데스크톱에서는 위치와 같은 `flex flex-wrap` 행에 놓여 좁은 PC 폭에도 다음 줄로 자연스럽게 이동한다.
- 요약은 빠른 판단용 첫 추천일만, 기존 `CrowdSection`은 전체 30일 캘린더·재시도·제공 불가 안내를 담당한다. 같은 데이터를 반복해도 역할이 달라 기능 중복은 아니다.
- 요약은 클릭 가능한 제어가 아닌 읽기 전용 텍스트이며, 구분선만 `aria-hidden` 처리되어 접근성 이름을 훼손하지 않는다.
