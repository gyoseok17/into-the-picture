# M8.1 스토리 폴라로이드 테두리 트로피 위치 QA

작성일: 2026-09-04
상태: 구현 전 계약 검토 완료 · 최종 검증 대기

## UI 계약

- 연결된 사진 수 트로피는 스토리 폴라로이드 **전체 카드의 좌상단 흰 테두리**에 놓이며 사진 콘텐츠를 가리지 않는다.
- 묶음 카드의 뒤쪽 종이 stack·회전 그림자보다 위(`z-index`)에 있으나, 선택 관리 checkbox 및 modal보다 낮아야 한다.
- 일반 사진/연결 0장 묶음에는 marker와 빈 여백이 없다. 숫자는 연결된 개별 사진 수이며 비교 레코드 수가 아니다.
- 라이트박스 썸네일별 트로피, 현재 사진의 미니 폴라로이드 결과 링크는 기존 개별 사진 기준을 유지한다.

## 최종 체크리스트

- [ ] marker의 위치 기준이 메모/사진 내부가 아니라 outer polaroid card 또는 white frame이다.
- [ ] 1/2/3장 stack과 각 회전에서 marker가 잘리거나 뒤 종이에 가려지지 않는다.
- [ ] 320px 모바일과 일반 폭에서 사진·장소·메모를 침범하지 않고 checkbox와 겹치지 않는다.
- [ ] 연결 0/1/다수 사진 및 한 사진 다중 비교에서 노출·숫자가 정확하다.
- [ ] 썸네일 marker·현재 사진 mini card·결과 링크·삭제 후 캐시 갱신이 회귀하지 않는다.
- [ ] `tsc -b`, `git diff --check` 통과.

## 차단 기준

- 트로피가 이미지 위를 가리거나 stack 아래로 숨는다.
- 일반 사진에 marker가 남거나 숫자가 연결 사진 수와 다르다.
- 위치 수정으로 썸네일·미니 결과 카드·삭제 뒤 갱신이 깨진다.
## 최종 소스·타입 검증 (2026-09-04)

### 통과

- 트로피 marker는 outer card의 white-frame wrapper(`relative z-10 bg-white`)에 배치되고 top padding으로 확보된 흰 테두리 영역(`pt-9`)에 놓인다. 사진·장소·메모 영역을 침범하지 않는다.
- card stack은 `z-0`, white frame은 `z-10`, marker는 `z-20`이어서 뒤 종이와 회전 그림자보다 위에 보인다. 선택 checkbox는 카드 내부 우측 상단이므로 marker와 분리된다.
- 연결 수는 `getConnectedPhotoCount`가 비교가 하나 이상인 개별 photo만 세므로 다중 비교를 중복 집계하지 않는다. 0이면 marker가 `null`이다.
- 썸네일별 marker, 현재 사진의 미니 폴라로이드 결과 링크, 비교 삭제 뒤 album/map cache invalidate는 기존 개별 사진 기준으로 유지된다.
- `tsc -b` 통과, `git diff --check` 공백 오류 없음(LF/CRLF 경고만 출력).

### 수동 확인 항목

- 실제 320px 화면에서 2~3장 stack의 회전과 marker의 시각 여백, checkbox·미니 폴라로이드 동시 노출을 확인한다.
