# M8.1 지도 사진 추가: 지역 선행 선택 QA

## 범위

- 지도 화면에서 시·군을 선택하기 전에는 `사진 추가`를 실행할 수 없어야 한다.
- 시·군 선택 뒤에만 업로드 시트가 열리고, 그 선택값이 업로드 공통 위치값으로 전달되어야 한다.
- 시트 안에서는 위치를 다시 선택하거나 변경하는 UI가 없어야 한다.
- 지도 외 스토리 앨범의 기존 사진 추가는 위치 입력을 계속 제공해야 한다.

## 코드 기준 사전 점검 (2026-08-28)

### 현재 발견된 차단 이슈

1. `PhotoRecordMapView.tsx`의 `RegionPicker`가 `selectedCityCode` 유무와 무관하게 `onAdd`를 버튼에 연결한다. 따라서 시·군 미선택 상태에서도 업로드 시트가 열린다.
2. `BatchPhotoUploadPanel.tsx`는 모든 사용처에서 `PhotoRegionField`를 표시한다. 지도 시트에서도 위치를 변경할 수 있어, 지도에서 먼저 고른 위치만 사용한다는 흐름과 맞지 않는다.
3. 지도 시트는 `initialLocation`을 `common` 초기값으로 전달하는 부분은 구현되어 있다. 진입 조건과 시트 내부 위치 편집만 분리하면 API/업로드 큐 변경 없이 요구사항을 만족할 수 있다.

## 수정 후 확인할 동작

1. 지도 권역만 선택한 상태에서 `사진 추가`가 비활성 상태이며, 이유(시·군 선택 필요)를 버튼 또는 보조문구로 확인할 수 있다.
2. 지도에서 시·군을 고르면 `사진 추가`가 활성화되고, 클릭 시 지도 위치·권역·시군 선택과 핀 포커스가 유지된 채 시트가 열린다.
3. 지도 시트에는 위치 선택/변경 컨트롤이 보이지 않는다. 파일을 골라 업로드한 요청의 `mapRegionCode`, `mapCityCode`는 지도에서 선행 선택한 값과 정확히 일치한다.
4. 업로드 성공, 실패 후 재시도, 시트 닫기에서 지도 선택 상태가 유지된다. 업로드 중 시트 닫기와 배경 클릭은 계속 막힌다.
5. 스토리 화면의 일반 `사진 추가`에서는 기존 `PhotoRegionField`가 계속 보이고, 지역 미선택 업로드도 기존 동작대로 가능하다.
6. 360px 모바일과 데스크톱에서 비활성 버튼이 눌림/포커스로 시트를 열지 않으며, 활성화·비활성화 상태가 시각적으로 구분된다.

## 계약 및 회귀 위험

- 서버 요청 DTO(`mapRegionCode`, `mapCityCode`)와 업로드 API는 변경하지 않는다.
- 지도 진입 경로만 `시군 선택 필수`라는 UI 정책을 추가한다. 스토리 업로드나 기존 사진 수정의 위치 입력 정책에는 적용하지 않는다.
- 비활성화만 하고 안내를 생략하면 사용자가 사진 추가가 고장 난 것으로 오인할 수 있으므로, 선택 필요 안내가 필수다.

## 구현 반영 후 재점검 (2026-08-28)

- `RegionPicker`의 사진 추가 버튼은 `selectedCityCode`가 없으면 `disabled`가 되고, `onAdd`를 실행하지 않는다. 시·군 선택 뒤에만 활성화된다.
- `MapUploadSheet`는 `BatchPhotoUploadPanel`에 `showLocationField={false}`를 전달한다. 지도 시트 안에서는 위치 입력을 표시하지 않으며, 지도에서 선택한 `initialLocation`만 공통 위치값으로 사용한다.
- `BatchPhotoUploadPanel`의 기본값은 `showLocationField = true`다. 따라서 스토리 화면의 일반 사진 추가에는 기존 위치 입력이 유지된다.
- 지도 필터 상태는 `PhotoRecordMapView` 내부 상태이며, 시트는 같은 컴포넌트의 오버레이로 렌더링된다. 열기·닫기와 성공 완료 콜백에서 필터를 초기화하지 않아 지도 상태가 보존된다.
- `frontend npm run build` 및 `git diff --check` 통과. 기존 Vite 500KB 청크 경고만 남는다.

## 최종 판정

**통과(코드·빌드 기준).** 권고 사항: 시·군 미선택 상태의 이유가 현재 `title` 속성에만 있으므로, 모바일 사용자는 이유를 바로 보기 어렵다. 비활성 버튼 인근에 “시·군 선택 후 추가할 수 있어요” 같은 짧은 안내를 보이면 더 명확하다.
