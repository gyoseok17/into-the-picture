# M10 수상작 상세 지도·방문 타이밍 패널 QA

검토 일시: 2026-09-21

## 검토 결과

### 레이아웃

- 상단 `CrowdTimingSummary`는 제거됐다.
- 지도와 방문 타이밍은 `clear-both space-y-5 md:grid md:grid-cols-2 md:items-start md:gap-8 md:space-y-0` 컨테이너의 두 자식으로 구성됐다.
- 모바일 기본은 블록 흐름과 `space-y-5`이므로 기존처럼 지도 다음 방문 타이밍이 세로로 표시된다.
- `md` 이상에서만 2열이 되어 같은 줄의 독립 패널로 표시된다. 각 `Section`의 제목은 h2를 유지한다.

### 상태별 동작

- 지도 좌표가 없으면 `ContestMap`이 지도 대신 `정확한 위치 정보를 알 수 없어요.` 플레이스홀더를 렌더링한다. 오른쪽 방문 타이밍 패널은 그대로 독립 표시된다.
- 혼잡도 미지원 또는 예측 없음은 기존 `CrowdUnavailableNotice`를 유지한다.
- 혼잡도 조회 오류는 기존 `ErrorState`와 재시도 콜백을 유지한다.
- 조회 중도 기존 `LoadingState`가 오른쪽 패널에서 렌더링된다.

### 접근성·의미

- 위 상태 메시지는 기존 접근 가능한 컴포넌트를 재사용하며 새 아이콘 전용 제어·숨겨진 상호작용을 추가하지 않았다.
- 지도와 혼잡도는 각각 위치와 향후 방문 집중률이라는 별도 정보를 제공하므로 같은 행 배치는 의미 중복이 아니다.
