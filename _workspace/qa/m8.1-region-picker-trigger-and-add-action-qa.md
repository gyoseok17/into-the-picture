# M8.1 권역별 지역 선택 진입 · 사진 추가 배치 QA 사전 검토

작성일: 2026-08-28
역할: 통합 QA (코드 미수정)

## 변경 대상과 현재 계약

- `PhotoRecordMapView`는 지도 권역을 고르면 곧바로 `RegionPicker`에서 해당 권역의 모든 시·군 버튼을 표시한다. 시·군 선택값은 `mapRegionCode`, `mapCityCode`로 지도 마커를 필터링한다.
- `PhotoRegionField`는 사진 추가 폼에서 같은 순서(권역 선택 → 시·군 검색/선택)를 제공한다. 위치 값은 사진 업로드 요청의 공통 메타데이터다.
- 이번 UI 변경은 다음 흐름으로 한정한다.
  1. 지도에서 권역을 누르면 시·군 목록을 즉시 펼치지 않고 `지역 선택` 진입 버튼을 표시한다.
  2. `지역 선택`을 누르면 해당 권역의 시·군 검색·선택 UI를 연다.
  3. 지도 상단 조작줄의 사진 추가 동작을 우측으로 옮긴다.
- 서버의 161개 시·군 목록, `mapRegionCode`/`mapCityCode` 저장·API 계약은 바꾸지 않는다.

## 차단 전 확인 사항

1. **권역을 바꾸면 기존 시·군 선택을 즉시 비워야 한다.** 예를 들어 전주 선택 후 경상을 누른 경우 `mapCityCode=JEONJU`가 남으면 필터 결과가 0건이 되거나 잘못된 요청이 만들어질 수 있다. 새 권역 선택 시 `{ mapRegionCode }`만 저장하고, 시·군은 버튼을 통해 다시 확정해야 한다.
2. **선택 해제 규칙을 유지해야 한다.** 현재는 같은 권역 재클릭 또는 지도 빈 공간 클릭으로 전체 지도로 돌아간다. 시·군 선택 뒤에도 같은 권역 재클릭·빈 공간 클릭이 모두 `mapRegionCode`와 `mapCityCode`를 함께 지워야 한다.
3. **'지역 선택'은 화면 상태이지 별도 저장값이 아니어야 한다.** 버튼을 열고 닫는 상태가 지도 필터/사진 업로드 값과 섞이면, 닫기만 했는데 선택값이 사라지거나 반대로 미확정 도시가 저장될 위험이 있다.
4. **사진 추가 버튼의 실제 파일 입력 연결을 보존해야 한다.** 위치만 옮기고 `label`/숨은 `input[type=file]`의 연결, 업로드 중 disabled, 모바일 갤러리 호출을 깨뜨리지 않아야 한다.

## 수동 QA 체크리스트

### 지도

- [ ] 전체 지도에서 권역을 누르면 해당 권역 색상·마커 필터는 유지되고 시·군 버튼은 즉시 나열되지 않는다.
- [ ] 권역 선택 뒤 `지역 선택`을 누르면 해당 권역의 시·군 검색 UI가 열린다.
- [ ] 검색어 없음/일치/불일치, 긴 시·군명, 동일 명칭 도시를 확인한다.
- [ ] 시·군을 고르면 해당 도시의 마커만 보이고, 마커 클릭 확대·사진 카드·겹친 사진 전환이 유지된다.
- [ ] 같은 권역 재클릭, 지도 빈 공간 클릭, 선택 UI 닫기 각각의 결과가 명확하며 전체 지도 복귀가 가능하다.
- [ ] 권역 A 도시 선택 → 권역 B 선택 → 전체 B 보기 → B 도시 선택을 확인한다.

### 사진 추가

- [ ] 데스크톱과 모바일에서 옮겨진 우측 사진 추가 버튼을 누르면 파일 선택창/모바일 갤러리가 열린다.
- [ ] 1·3·20장 선택, 업로드 중 버튼 disabled, 취소 후 재선택을 확인한다.
- [ ] 사진 추가 폼의 위치 선택이 지도와 같은 161개 선택지 및 코드 계약을 사용한다.
- [ ] 선택한 위치가 업로드 후 지도 마커 위치와 스토리 기록에 동일하게 반영된다.

### 모바일 레이아웃

- [ ] 360×800, 390×844 세로 화면에서 상단 조작줄과 지도 안내 문구가 겹치지 않는다.
- [ ] 지역 선택 UI가 하단 내비게이션과 사진 집중 카드 위에 겹쳐도 마지막 항목·닫기 동작이 가려지지 않는다.
- [ ] 키보드가 열린 상태에서 검색 입력 및 결과 선택이 가능하고, 키보드를 닫아도 선택 상태가 유지된다.
- [ ] 가로 화면 전환 뒤 지도 비율·마커·사진 추가 버튼이 잘리지 않는다.

## 사전 판정

- **차단 없음(구현 전 검토).** 서버·저장 계약 변경 없이 프런트 상태 전환과 배치만 바꾸는 범위로 적절하다.
- 단, 권역 변경 시 도시 코드 초기화와 클릭 이벤트 전파 차단은 구현 완료 뒤 반드시 확인할 차단성 회귀 항목이다.
