# M8.1 사진 확대 수상작 정보 QA

## 범위

- 지도 `MapPhotoLightbox`와 스토리 `PhotoBundleLightbox`에서 사진 위 우측 하단을 가리던 수상작 미리보기를 제거하고, 사진 아래에 간결한 수상작 정보와 비교 진입을 두는 변경을 검토했다.
- 계약: `_workspace/contracts/M8.1-photo-lightbox-contest-info.md`

## 계약 교차 검토

| 경우 | 결과 |
| --- | --- |
| 비교 연결 없음 | `PhotoComparisonLightboxInfo`가 `null`을 반환한다. 사진과 기존 탐색만 표시된다. |
| 비교 연결 1건 | 사진 아래에 트로피, 수상작 제목, `location`, `비교 보기`가 표시된다. |
| 비교 연결 여러 건 | 첫 수상작을 대표로 보여 주고 버튼에 연결 건수를 표시한다. 결과 창에서는 기존 선택 목록으로 다른 비교를 고를 수 있다. |
| `PHOTO_ONLY` | 비교 결과 창은 기존 규칙대로 제목을 `내 사진`으로 표시하며, 확대 화면의 연결 정보와 결과 선택·닫기 흐름은 동일하다. |

## 동작·반응형·접근성

- 지도와 스토리 모두 이미지 컨테이너에는 수상작 오버레이를 렌더링하지 않아 사진이 가려지지 않는다.
- `비교 보기`는 `PhotoComparisonResultDialog`를 현재 라이트박스보다 높은 레이어에 열며 라우트 이동·API 호출·DB 변경이 없다.
- 결과 창은 Escape 캡처 단계에서 먼저 닫히고, 닫은 뒤 `비교 보기` 버튼으로 초점이 돌아간다. 따라서 라이트박스는 유지된다.
- 두 라이트박스 본문에 `max-h-[calc(100dvh-2rem)] overflow-y-auto`가 적용돼 짧은 모바일 뷰포트에서도 수상작 정보·탐색 조작이 잘리지 않고 스크롤된다.
- 사진 원본을 담은 `AspectImage`의 4:3 영역은 유지된다.

## 대체 경로 확인

- `PhotoComparisonOverlay`의 사용처는 프런트 소스에서 발견되지 않았다. 지도·스토리 라이트박스는 공통 `PhotoComparisonLightboxInfo`만 사용하므로 두 화면의 표시·중첩 동작이 일치한다.
