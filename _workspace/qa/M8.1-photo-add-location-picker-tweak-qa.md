# M8.1 사진 추가 장소 선택 UI 조정 QA

작성일: 2026-09-07
역할: 통합 QA

## 확인 범위

- 사진 추가 시트 우측 닫기(X) 제거
- 사진 추가의 장소 선택을 지도 그림 없이 권역 → 시·군 선택으로 변경
- 지도 화면의 시·군 선택과 공통 UI 재사용 여부

## 결과

| 항목 | 판정 | 근거 |
| --- | --- | --- |
| 사진 추가 X 제거 | 통과 | PhotoAddSheet 헤더에서 닫기 버튼이 제거됐다. |
| 장소 선택 UI | 통과 | PhotoRegionField가 지도 SVG 대신 권역 버튼과 시·군 검색/칩을 표시한다. |
| 지도와 시·군 선택 일관성 | 통과 | 지도 RegionPicker와 사진 추가 PhotoRegionField가 공통 RegionCityPicker를 사용한다. |
| 선택 후 폼 복귀 | 통과 | 시·군 선택 시 상위 onChange가 장소 값을 반영하고 LocationPickerDialog를 닫는다. |
| 지도 사전 선택 | 통과 | 지도 onAdd(regionFilter) → PhotoAddSheet.initialLocation → 업로드 패널 초기값 전달 경로가 유지된다. |
| 취소 경로 | 통과 | 배경 클릭과 Escape로 사진 추가 시트를 닫을 수 있고, 업로드 중에는 두 경로가 모두 비활성화된다. 장소 선택 다이얼로그의 X는 선택 취소용으로 유지된다. |

## 검증

- frontend/npm run build 통과. 기존 Vite 청크 크기 경고만 발생.
- git diff --check 통과.
- npm run typecheck은 기존 스크립트의 allowImportingTsExtensions/emit 설정 충돌로 실패했으나, build의 tsc -b 단계는 통과했다.

## 통합 판정

**통과.** Escape 닫기 보완 후 X 제거로 인한 접근 불가 경로가 없다.
