# M10 수상작 상세 PC 레이아웃 QA

검토 일시: 2026-09-21

## 변경 검토

### 반응형 범위

- 수상작 이미지의 PC 배치는 `md:float-left`, `md:w-[42%]`, `md:max-w-[34rem]`, `md:mr-8`로 한정됐다.
- 이미지는 모바일 기본 `aspect-[4/3]`을 유지하고, `md`부터 `aspect-[5/4]`가 적용된다.
- 제목 확대(`md:text-2xl`)와 헤더 상단 보정(`md:pt-1`)도 모두 `md` 접두사이므로 모바일 레이아웃·버튼 배치에는 적용되지 않는다.

### 사진 과대 문제

- PC에서 이미지 폭은 콘텐츠의 42%, 최대 34rem으로 제한된다.
- `fit="contain"`을 유지해 원본 비율 왜곡·잘림 없이 제한된 프레임 안에서 표시된다.

### 저장 버튼 접근성

- 시각 텍스트를 제거하고 아이콘 버튼(`size="icon"`)으로 변경했다.
- 하트 아이콘은 `aria-hidden`이고, `sr-only` 텍스트가 상태별 접근성 이름을 제공한다: 저장 전 `저장`, 저장 후 `저장 해제`.
- 비로그인 안내 `title`과 비활성화 조건도 그대로 유지된다.

### 기능·라우트 회귀

- 라우트는 기존 `/contests/:id`를 유지한다.
- 하트 저장, 공개 비교 사진 열기, 저장 후 앨범 비교 진입(`/me/album?contestId=<id>`), 목록 복귀 흐름의 이벤트·링크는 변경되지 않았다.
- 목록에서 연 상세의 overlay/ESC/포커스 복귀 처리는 `ContestDetailOverlay`로 유지된다.

## 검증

- `frontend`: `npm run build` 통과
- `git diff --check` 통과
- 기존 Vite 500 kB 청크 경고만 발생; 이번 변경의 차단 이슈는 없다.

## 잔여 확인

- float 레이아웃은 실제 PC 폭에서 정보·키워드·위치 섹션이 의도한 흐름으로 감싸지는지 한 번 육안 확인이 필요하다. 코드상 모바일 회귀나 기능 차단 요인은 발견하지 못했다.
