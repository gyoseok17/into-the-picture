# M8.1 사진 기록 앨범 프런트엔드 결과

## 변경 범위

- `frontend/src/pages/MyPage.tsx`: 기존 삭제 중심 `내 사진` 목록을 사진 기록 앨범으로 교체했다.
- `frontend/src/features/photo-record/`: 사진 기록 타입, API 호출, React Query 훅, 앨범 UI를 분리했다.
- 앨범 변경 뒤 `user-photos`, `comparisons` 쿼리를 무효화해 비교 사진 선택과 결과 표시가 오래된 상태로 남지 않게 했다.

## 설계 결정

- 사진 기록 API 응답의 `contestId`, `displayMode`만 앨범에서 소비한다. 앨범은 수상작 이름·이미지를 따로 가져오지 않는다.
- 보관은 삭제가 아닌 `PATCH { archived: true }`이고, 보관함에서 `false`로 복원한다.
- 기록 수정은 빈 날짜·장소·메모를 `null`로 보내 기존 값도 비울 수 있다. 촬영일이 없으면 카드에는 `촬영일 미상`을 보이고 시간 정렬은 업로드 시각을 대체 기준으로 쓴다.
- 연결 사진의 `PHOTO_ONLY`는 비교 결과 목록·상세에서 수상작 이미지를 숨기고 내 사진만 표시한다.

## 검증

- `frontend/npm run build`, `git diff --check` 통과.
- 직접 추가 미리보기, 편집, 정렬, 보관·복원, 실제 삭제·409 안내, 비교 캐시 연동을 수동 QA 항목으로 남겼다.

## 남은 위험

- 실제 브라우저에서 JPEG EXIF 자동 추출은 서버 통합 실행 후 확인이 필요하다. 프런트는 촬영일을 비워 서버가 추출하도록 요청한다.
