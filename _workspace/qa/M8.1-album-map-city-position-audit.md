# M8.1 앨범 지도 시·군 마커 전수 좌표 감사

## 범위와 결론

- 대상: `koreaRegions`의 선택지 161개 전체와 `albumMapCityPositions`의 161개 좌표.
- 기준: 사용자가 제공한 시·군 경계 참고도와 `album-map-korea-six-regions.png`의 6권역 일러스트를 함께 대조했다. 이 지도는 투영지도가 아니므로 위경도 직선 환산이 아니라 **같은 권역 안의 북·남·동·서 상대 관계**와 **도형 내부 여부**를 우선했다.
- 결과: 161개 모두 위치 코드가 있고, 최종 좌표는 161/161이 해당 권역의 실제 채움 영역 검사에 통과했다. 상대 위치가 뭉치거나 뒤바뀐 충청·전라·경상 중심의 좌표를 보정했다.
- 주의: 울릉은 원본 일러스트에 별도 섬 도형이 없어 울진 동쪽의 **대리 위치**를 사용한다. 신안·진도·완도·거제·남해·통영은 실제 섬 전체를 표현하지 않고 해당 권역 해안 가까이의 대표 위치로 둔다. 이 7개는 실제 해안선 정밀도를 주장하지 않는다.

좌표 형식은 `left %, top %`이며, 위쪽일수록 북쪽, 오른쪽일수록 동쪽이다. `유지`는 현재값을 그대로 사용한다.

2. 각 권역의 최북·최남·최서·최동 시·군을 표시해 참고도의 상대 순서와 대조한다. 특히 전남 서남부는 `영광 → 함평 → 무안 → 목포/신안`, `함평 → 영암 → 해남`의 북남 관계를 확인한다.
3. 마커 중심이 배경색이 아니라 해당 권역 채움 또는 허용된 해안·섬 대리 위치 위에 있는지 렌더링으로 확인한다.
4. 실제 SVG를 교체하면 이 좌표표를 그대로 재사용하지 않는다. 새 SVG 위에서 같은 감사를 다시 하고, 울릉 등 별도 도형이 없는 섬은 제품 결정을 먼저 정한다.
