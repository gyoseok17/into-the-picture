# M8.1 backend `.env` relocation QA

## Scope

- Move local backend secrets and connection values from repository-root `.env` to `backend/.env`.
- Make the `local` Spring profile import the backend-local file.
- Do not inspect or record any secret values.

## Verified

1. Repository-root `.env` is absent and `backend/.env` exists.
2. `backend/.env` is ignored by Git and is not tracked.
3. `application-local.yml` imports `file:.env[.properties]`, which resolves correctly when the documented local command is run from `backend` (`./gradlew bootRun`). The import is intentionally non-optional, so a missing local file fails configuration loading clearly.
4. `backend/.env.example` is tracked and contains only key names/placeholders, including the DB and JWT keys required by local startup.
5. The common application configuration still contains no JWT fallback value; the existing 32-byte JWT validation remains the effective protection.
6. Production/non-local profiles do not import `application-local.yml`; they continue to use deployment-provided configuration.

## Remaining startup prerequisite

1. The copied `backend/.env` currently lacks `DB_PORT` and `DB_NAME`, although both are required by the no-fallback datasource URL. Local startup will therefore fail until the owner supplies these two values in `backend/.env`.

## Final recheck (2026-09-07)

- `backend/README.md` now consistently directs local users to `backend/.env` and tells them to copy `backend/.env.example`.
- `backend/.env.example` is present with placeholders only; it is intentionally new and must be included when the implementation change is committed.
- No real secret, database password, token, or connection string was read or recorded in this review.

## Decision

**Pass for the relocation change.** The file location, import path, documentation, Git exclusion, missing-file handling, and production isolation are correct. Local boot verification remains intentionally pending until the owner adds `DB_PORT` and `DB_NAME` to their ignored `backend/.env`; no arbitrary values were created.
