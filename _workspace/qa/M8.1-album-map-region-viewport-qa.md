# M8.1 앨범 지도 권역 중심 확대 QA

- 점검일: 2026-09-10
- 범위: 여섯 권역 선택의 전체 도형 framing, SVG·marker 좌표계, 상태 우선순위와 반응형 회귀

## 경계·확대 수치 검증

`albumMapRegionViewport.ts`는 화면 컴포넌트가 아닌 지도 전용 라이브러리에 여섯 권역의 0–100 bounds를 둔다. 전라·경상의 분리 도서 path를 포함한 bounds이며, SVG를 교체할 때 이 한 catalog만 다시 보정하면 된다.

12% 여백과 1~2.2 scale clamp를 실제 계산식으로 대조했다. 아래 visible range는 확대 후 stage에서 보이는 정규화 좌표 범위이며, 각 선언 bounds를 모두 포함한다.

| 권역 | scale | visible range (left / top) | 판정 |
| --- | ---: | --- | --- |
| 수도권 | 2.000 | 8.0~58.0 / 5.0~55.0 | 통과 |
| 강원 | 1.695 | 31.5~90.5 / -4.0~55.0 | 통과 |
| 충청 | 1.724 | 16.0~74.0 / 20.0~78.0 | 통과 |
| 전라 | 1.786 | 2.0~58.0 / 45.0~101.0 | 통과 |
| 경상 | 1.818 | 38.0~93.0 / 33.0~88.0 | 통과 |
| 제주 | 2.200 (상한) | 11.3~56.7 / 66.8~112.2 | 통과 |

좌표 범위가 0~100 밖으로 보이는 경우는 stage 밖을 클립하는 것이 아니라, 해당 축의 지도 끝까지 여유가 남는다는 뜻이다. 모든 도형 bounds 자체는 visible range에 포함된다.

## 좌표계·상태·레이어 검증

- SVG와 marker가 동일한 transformed stage wrapper에 있으므로, 권역 frame·marker focus 모두에서 좌표계가 분리되지 않는다. 기존 2:3 stage 규칙도 유지된다.
- 권역 선택 후 도시를 골라도 region viewport를 유지한다.
- marker focus(1.38)가 권역 frame보다 우선하며, focus 닫기는 선택 권역 frame으로 복귀한다.
- 같은 권역 재선택·지도 빈 곳 클릭은 region/city/focus를 모두 해제해 전체 지도 scale 1로 돌아간다.
- 지역 선택/사진 추가 panel과 빈 상태는 transformed stage 밖의 기존 overlay이며, RegionPicker open 시 `z-30`, MapFocus `z-20`, marker `z-2` 순서를 유지한다. 상호 가림 회귀가 없다.
- 모바일·desktop 모두 stage 크기는 viewport의 2:3 계산을 유지하고, 확대 계산은 viewport 폭·높이에 독립적인 정규화 bounds에서 동작한다.

## Transform-origin 재검증 및 이전 계산 정정 (2026-09-10)

이전 범위 계산은 CSS 기본 `transform-origin: center`를 명시적으로 검증하지 않은 한계가 있었다. 이 항목부터는 그 가정을 폐기하고, 수정된 현재 코드의 inline `transformOrigin: '0 0'`과 CSS transform 행렬을 직접 계산한 결과만 최종 판정 근거로 삼는다.

변환은 `translate(50 - S*C) scale(S)`이고 top-left origin에서 CSS 적용 결과는 다음과 같다.

`P' = S × P + (50 - S × C)`

따라서 선택 중심 `P = C`는 항상 `P' = 50`이다. 여섯 권역과 실제 최종 mapped bounds를 재계산했다.

| 권역 | center → 화면 | mapped bounds (left / top) | 판정 |
| --- | --- | --- | --- |
| 수도권 | 50.000, 50.000 | 12.000~88.000 / 12.000~88.000 | 통과 |
| 강원 | 50.000, 50.000 | 11.017~88.983 / 10.169~89.831 | 통과 |
| 충청 | 50.000, 50.000 | 10.345~89.655 / 31.034~68.966 | 통과 |
| 전라 | 50.000, 50.000 | 10.714~89.286 / 17.857~82.143 | 통과 |
| 경상 | 50.000, 50.000 | 12.727~87.273 / 10.909~89.091 | 통과 |
| 제주 | 50.000, 50.000 | 25.800~74.200 / 37.900~62.100 | 통과 |

- marker focus도 같은 helper와 top-left origin을 사용한다. 좌표 catalog 161개를 1.38배 focus 행렬에 대입해 모두 정확히 `(50,50)`으로 이동함을 확인했다.
- focus 닫기는 focusedGroup만 해제하므로 기존 권역 frame을 복원한다. blank/same-region click은 filter와 focus를 모두 지워 full map으로 복귀한다.
- `npm run typecheck`, `npx vite build`, `git diff --check`를 독립 실행해 통과했다. Vite 500kB 청크 권고만 비차단 상태다.

정정 후 최종 판정: 통과. 이전 origin 가정의 검증 공백은 `transformOrigin: '0 0'` 명시와 실제 행렬 재계산으로 해소됐다.
