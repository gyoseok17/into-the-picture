# M8.1 Supabase 직접 접속 설정 보고

## 변경 범위

- Git 제외 대상인 `backend/.env`의 DB 호스트, 포트, 데이터베이스명, 사용자명만 사용자가 제공한 Supabase 직접 접속 정보로 갱신했다.
- 비밀번호, JWT, 외부 연동 키는 읽거나 변경하거나 기록하지 않았다.

## 설계 결정

- `application.yml`의 필수 환경변수 계약은 유지했다. 연결 식별값만 `.env`에서 공급하므로 프로젝트별 로컬 설정 경계가 바뀌지 않는다.

## 검증

- `backend/gradlew.bat bootRun` 실행 뒤 `localhost:8080` TCP listen을 확인했다.
- 백엔드가 8080에서 실행 중이다.

## 남은 위험

- 실제 DB 비밀번호의 유효성이나 데이터 조회는 이 작업 범위에서 검사하지 않았다.
