# M10.1 수상작 신안군 지도 코드 정규화 — 백엔드 결과

## 변경

- `ContestLocationOverrides`의 `염전체험` 수상작 도시 코드를 이전 `SHINAN`에서 정식 `SINAN`으로 바꿨다.
- 새 Flyway `V22__normalize_contest_sinan_map_city_code.sql`이 이미 적용된 V16 데이터의 `SHINAN`을 `SINAN`으로 갱신한다.
- V16은 수정하지 않았다. 신규 DB는 sync 정적 보정표로, 기존 DB는 V22로 같은 `SINAN` 값을 가진다.

## 검증

- sync 단위 테스트가 `염전체험 → JEOLLA / SINAN` 저장을 검증한다.
- `backend\\gradlew.bat test --no-daemon` 통과.

## 영향·안전성

- 대상은 `contest_work.map_city_code = 'SHINAN'`인 기존 수상작 행뿐이다.
- API URL·DTO·사진 앨범 데이터는 변경하지 않는다.
