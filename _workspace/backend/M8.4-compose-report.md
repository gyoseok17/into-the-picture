## Design decision

- Use immutable version tags such as `m8.3` for deployment instead of `latest`, so an EC2 restart cannot silently change the application version.
- Keep the `:-m8.3` Compose fallback for a clear first-run default, while `.env.example` explicitly pins the same version.
