# M8.1 비교 사진 표시 구도 백엔드 결과

## 변경 범위

- `photo_record`의 수상작 비교 기록에 표시 구도(비율, 확대, 가로·세로 이동)를 추가했다.
- 생성·사진 교체·구도 수정·내 비교 목록·수상작 공개 비교 목록에 같은 `crop` 계약을 연결했다.
- V15 마이그레이션은 기존 모든 기록을 기본 구도(4:3, 1배율, 중앙)로 채운다.

## 설계 결정

- 업로드 원본을 자르거나 별도 파일을 만들지 않고, 비교 기록에 표시 메타데이터만 저장한다. 앨범 원본과 비교용 표시를 분리해 데이터 손실과 중복 파일을 막는다.
- 수상작 원본의 실제 비율은 이미지가 로드되는 프런트에서 계산해 `aspectRatio`로 보낸다. 서버에는 원본 이미지의 가로·세로 메타데이터가 없으므로 추측하지 않는다.
- `offsetX`, `offsetY`는 해상도 독립적인 `-1~1` 정규화 값이며, 같은 값이 PC·모바일·공개 갤러리에서 같은 의도를 뜻한다.
- 공개 목록에는 `id`, 공개 파일 URL, 생성 시각, `crop`만 노출한다. 개인 앨범의 장소·메모·촬영일·파일명·소유자 정보는 계속 제외한다.

## 권한과 호환성

- 구도 변경은 `findOwnedRecord`를 거치므로 소유자만 가능하다.
- 공개 파일 조회는 기존대로 수상작 ID와 PUBLIC 상태를 먼저 서버에서 검증한다.
- 사진 교체는 공개 상태와 수상작 비율을 유지하되, 새 사진의 확대·위치는 중앙 기본값으로 재설정한다. 교체 요청에 `crop`이 있으면 그 값을 사용한다.
- 이전 API 요청에서 `crop`을 보내지 않아도 동작한다.

## 검증

- 서비스 단위 테스트로 구도 저장, 범위 밖 값 거부, 공개 목록의 구도 노출을 확인했다.
- Gradle 테스트 결과는 통합 QA가 최종 확인한다.
