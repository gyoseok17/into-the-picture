# M9 백엔드 — 수상작 위치 무결성 결과

## 변경 범위

- `contest_work`에 `map_region_code`, `map_city_code`를 추가했다.
- V16이 기존 수상작 95건에 승인된 명시 코드를 적용한다. ID 42는 승인대로 `CAPITAL / INCHEON`이다.
- 외부 공모전 동기화에도 같은 95건 정적 보정표를 적용해, 빈 DB에서 sync가 Flyway보다 먼저 실행되어도 동일한 코드가 저장된다.
- 상세 API는 `mapRegionCode`, `mapCityCode`를 추가로 반환한다.

## 데이터 안전성

- 새 컬럼은 nullable로 추가하며 사진·즐겨찾기·비교 데이터는 변경하지 않는다.
- V16은 제목이 일치하는 기존 행만 갱신한다. sync 정적 보정표가 신규 행을 보완한다.
- 명시된 네 건 외의 기존 좌표는 변경하지 않는다.
