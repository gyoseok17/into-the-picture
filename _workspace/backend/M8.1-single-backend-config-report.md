# M8.1 백엔드 단일 환경설정 보고

## 변경 범위

- `application-local.yml`의 `.env` import와 datasource 설정을 `application.yml`로 이동했다.
- 기본 `local` 프로필 활성화와 local 전용 JWT fallback 경로를 제거했다.
- `backend/.env.example`, 백엔드 README, 아키텍처·인증 문서를 단일 YAML 계약에 맞췄다.

## 설계 이유

Supabase를 포함한 모든 환경이 같은 DB·JWT 환경변수 계약을 쓰므로, 프로필별 YAML 중복 없이 한 파일에서 설정 조립 책임을 맡는다.

## 검증 예정

- `backend/gradlew.bat test --no-daemon`
- `git diff --check`
- 실제 기동은 `backend/.env`의 필수 DB 값이 있는 환경에서 확인한다. 비밀값은 이 보고서에 기록하지 않는다.
